## Bitsocial Grafana

This directory contains the Grafana dashboards and provisioning files for `stats.bitsocial.net`.

### Dashboards

- **Bitsocial Stats** (`bitsocial-stats.json`, served at `/`): network overview with headline health numbers, 5chan activity, the peer map, service uptime, and network provider uptime. Per-provider latency charts sit in collapsed rows.
- **5chan Stats** (`5chan-stats.json`, served at `/5chan`): board-level view with a sortable table of every official 5chan board, activity charts, and a collapsed availability history.

A text panel at the top of each dashboard links the two shared views. The peer map draws countries from the GeoJSON bundled with Grafana, so it needs no third-party map tiles or API key.

### Regenerating dashboards

The checked-in dashboards are generated by [`scripts/build-dashboards.mjs`](./scripts/build-dashboards.mjs) from the current official 5chan directory files and the monitor configuration in [`stats/monitor/config.js`](../monitor/config.js):

```bash
yarn build:stats-dashboards
```

The generation step fetches the active directory files and defaults from `https://github.com/bitsocialnet/lists/tree/master/5chan-directories` (skipping hidden files such as `/trash/`), refreshes the monitor snapshot from those responses, and rebuilds the dashboard JSON so board names, board counts, and service/provider totals stay aligned with what the monitor checks. Edit the generator rather than the generated JSON.

The `upstream/` directory keeps the exported plebbit reference dashboards the original port was based on. The generator no longer reads them.

### Running locally

Boot the full local stack with:

```bash
cp stats/.env.example stats/.env
$EDITOR stats/.env
yarn stats:up
```

Useful local URLs:

- Grafana login: `http://127.0.0.1:3300/login`
- Public summary dashboard: `http://127.0.0.1:3300/public-dashboards/e9277bcc0c421ddcacd29f591466678c`
- Public 5chan dashboard: `http://127.0.0.1:3300/public-dashboards/fa6f2225e0ea98e116fb6f85d84e0186`
- Prometheus targets: `http://127.0.0.1:9091/targets`
- Monitor JSON API: `http://127.0.0.1:3301/`

Local Grafana admin credentials come from `stats/.env` and are reused by the `grafana-bootstrap` job.
