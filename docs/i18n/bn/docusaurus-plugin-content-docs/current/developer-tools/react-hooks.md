# React Hooks

`@bitsocial/bitsocial-react-hooks` React অ্যাপগুলোকে Bitsocial প্রোটোকলের জন্য একটি হুক-ভিত্তিক API দেয়: ফিড, মন্তব্য, কমিউনিটি, লেখকের প্রোফাইল, অ্যাকাউন্ট এবং প্রকাশনা, কোনো কেন্দ্রীয় সার্ভার ছাড়াই। [5chan](/apps/5chan/) এবং [Seedit](/apps/seedit/) এর ওপর ভিত্তি করেই তৈরি।

লাইব্রেরিটির নিজস্ব ডকুমেন্টেশন সাইট আছে, যা প্রতিটি রিলিজের সঙ্গে হালনাগাদ হয়: **[hooks.bitsocial.net](https://hooks.bitsocial.net/)**।

## ইনস্টলেশন

```bash
npm install @bitsocial/bitsocial-react-hooks
```

প্যাকেজটি React 16.8 এবং তার পরবর্তী সংস্করণ সমর্থন করে।

## কোথা থেকে শুরু করবেন

- [কুইকস্টার্ট](https://hooks.bitsocial.net/docs/quickstart/): আপনার প্রথম কমিউনিটি ফিড রেন্ডার করুন।
- [ধারণাসমূহ](https://hooks.bitsocial.net/docs/concepts/): ফিড, স্থানীয় অ্যাকাউন্ট, শেয়ার করা স্টেট এবং প্রকাশনা কীভাবে একসঙ্গে কাজ করে।
- [API রেফারেন্স](https://hooks.bitsocial.net/docs/api/feeds-hooks/): প্রতিটি হুক, তার অপশন ও রিটার্ন ভ্যালুসহ।
- [প্লেগ্রাউন্ড](https://hooks.bitsocial.net/#playground): সিমুলেটেড কনটেন্টের ওপর চলা লাইভ উদাহরণ সম্পাদনা করুন।
- [AI দিয়ে তৈরি করুন](https://hooks.bitsocial.net/docs/ai/): কোডিং এজেন্টদের জন্য `llms.txt` এবং প্রতিটি পৃষ্ঠার Markdown সংস্করণ।
