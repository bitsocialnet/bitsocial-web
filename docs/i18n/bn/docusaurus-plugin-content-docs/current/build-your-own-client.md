# নিজের Bitsocial ক্লায়েন্ট তৈরি করুন

প্রতিটি ব্যবহারের ক্ষেত্রে একটি করে অফিসিয়াল অ্যাপ থাকলে Bitsocial জেতে না। Bitsocial তখনই জেতে,
যখন অনেকগুলো ক্লায়েন্ট একই প্রোটোকল ভাগ করে নেয় এবং ইন্টারফেস, সংস্কৃতি, ডিসকভারি, ডিফল্ট সেটিং ও
ব্যবসায়িক মডেলে একে অপরের সঙ্গে প্রতিযোগিতা করে।

5chan এবং Seedit হলো প্রাথমিক প্রমাণ, কোনো সীমা নয়। যেকোনো নির্মাতার উচিত কোনো প্ল্যাটফর্ম মালিকের
অনুমতি না নিয়েই একটি নতুন ইমেজবোর্ড, ফোরাম, প্রোফাইল ক্লায়েন্ট, মোবাইল-ফার্স্ট সোশ্যাল অ্যাপ,
বিশেষায়িত কমিউনিটি টুল, বা এমন একটি কেন্দ্রীভূত ক্লায়েন্ট প্রকাশ করতে পারা যার নিচে Bitsocial চলে।

## নির্মাতারা কী কী বদলাতে পারেন

একটি Bitsocial ক্লায়েন্ট পুরো নেটওয়ার্ক ফর্ক না করেই পণ্যের সিদ্ধান্তে প্রতিযোগিতা করতে পারে:

- ইন্টারফেস ও ভিজ্যুয়াল ভাষা
- অনবোর্ডিং ফ্লো
- কমিউনিটির ডিফল্ট সেটিং
- মডারেশনের সারফেস
- ডিসকভারি মডেল
- মিডিয়া অভিজ্ঞতা
- মোবাইল, ডেস্কটপ বা কম-ব্যান্ডউইথের সীমাবদ্ধতা
- মনিটাইজেশন ও ব্যবসায়িক মডেল

সবার সাধারণ স্তরটি হলো প্রোটোকল। পণ্যের স্তরটি প্রতিযোগিতার জন্য উন্মুক্ত।

## শেখার দ্রুততম উপায়

যে অ্যাপগুলো ইতিমধ্যেই আছে, সেগুলো দিয়ে শুরু করুন:

- বেনামী ইমেজবোর্ড কমিউনিটির জন্য [5chan](https://5chan.app) দেখুন।
- Reddit-ধাঁচের আলোচনার জন্য [Seedit](https://seedit.app) দেখুন।
- ক্লায়েন্ট-সাইড ইন্টিগ্রেশনের জন্য [Bitsocial React hooks](https://hooks.bitsocial.net/docs/quickstart/) ডকুমেন্টেশন পড়ুন।
- নোড ও কমিউনিটি পরিচালনার জন্য [Bitsocial CLI](/developer-tools/cli/) ডকুমেন্টেশন পড়ুন।

দ্রুত এগোতে চাইলে প্রথমে কোনো বিদ্যমান অ্যাপে অবদান রাখুন। আপনি যে ইন্টারফেস, সংস্কৃতি বা কমিউনিটি
মডেল চান তা যদি সেখানে না মেলে, তাহলে আলাদা একটি ক্লায়েন্ট বানান।

## প্রথম সংস্করণটি সংকীর্ণ রাখুন

সেরা প্রথম সংস্করণ কোনো সর্বজনীন সোশ্যাল অ্যাপ নয়। এটি এমন একটি ক্লায়েন্ট, যার একটি স্পষ্ট দর্শক
আছে এবং টিকে থাকার একটি শক্ত কারণ আছে।

ভালো শুরুর জায়গাগুলোর মধ্যে আছে:

- একটি নির্দিষ্ট সংস্কৃতির জন্য পরিচ্ছন্নতর ইমেজবোর্ড ক্লায়েন্ট
- মোবাইল-ফার্স্ট ফোরাম ক্লায়েন্ট
- কঠোর ডিফল্ট সেটিংসহ একক-কমিউনিটির অ্যাপ
- ক্রিয়েটর কমিউনিটির ক্লায়েন্ট
- শুধু-পঠনযোগ্য ডিসকভারি ক্লায়েন্ট
- মডারেশন বা অপারেটর কনসোল
- কোনো নির্দিষ্ট ভাষা, অঞ্চল বা ডিভাইস শ্রেণির জন্য অপ্টিমাইজ করা ক্লায়েন্ট

ছোট ক্লায়েন্টগুলোও কাজের, কারণ Bitsocial তাদের ব্যবহারকারীদের কোনো ব্যক্তিগত ডেটাবেসে আটকে না রেখে
একই নেটওয়ার্কের ভেতরে বেড়ে উঠতে দেয়।

## বাস্তবায়নের পথ

বাস্তবসম্মত তিনটি পথ আছে:

1. আপনার ভাবনা 5chan বা Seedit-এর কাছাকাছি হলে কোনো বিদ্যমান ক্লায়েন্ট ফর্ক করুন।
2. [Bitsocial React hooks](https://hooks.bitsocial.net/) দিয়ে নতুন একটি React ক্লায়েন্ট বানান।
3. নোড API এবং পাবলিক RPC অবকাঠামোর উপরে নিজের ইন্টিগ্রেশন তৈরি করুন।

পাবলিক RPC তৃতীয় পথটিকে অনেক বেশি বাস্তবসম্মত করে তোলার কথা। একজন ব্যবহারকারী হোস্ট করা,
নন-কাস্টোডিয়াল RPC প্রদানকারীর মাধ্যমে শুরু করতে পারেন, তারপর সেলফ-হোস্টিং বা প্রতিদ্বন্দ্বী কোনো
প্রদানকারীর কাছে সরে যেতে পারেন।

## ডিজাইনের নীতি

আপনার কমিউনিটির জন্য যে ক্লায়েন্টটি থাকা উচিত, সেটিই বানান, তারপর সামঞ্জস্যপূর্ণ ক্লায়েন্টগুলোকে
প্রকাশ্যে প্রতিযোগিতা করতে দিন।
