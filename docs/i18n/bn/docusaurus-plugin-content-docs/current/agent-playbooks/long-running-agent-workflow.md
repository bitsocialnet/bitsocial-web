# দীর্ঘ-চলমান এজেন্টের কাজ

কাজ পরে আবার শুরু করা বা হস্তান্তরের প্রয়োজন হলে, কিংবা একটি রান এতটাই দীর্ঘ হলে যে কনটেক্সট কম্প্যাকশনে বাকি কাজের হিসাব হারিয়ে যেতে পারে, তখন টেকসই টাস্ক স্টেট ব্যবহার করুন। ছোট টাস্কের জন্য কোনো বোর্ড বা প্রগ্রেস ফাইলের দরকার নেই। ভাগাভাগি করা কাজের জন্য টাস্ক-নির্দিষ্ট একটি `docs/agent-runs/<slug>/`-এ সংক্ষিপ্ত `feature-list.json` ও `progress.md` রাখুন, সুবিধাজনক হলে বিদ্যমান টেমপ্লেট ব্যবহার করে।

অনুরোধ করা ফলাফল, বর্তমান ব্রাঞ্চ/ওয়ার্কট্রি, ফাইলের মালিকানা, সম্পন্ন পরিবর্তন, ফলাফলসহ চেক, নিজের মালিকানাধীন প্রসেস/সেশন, এবং পরবর্তী অমীমাংসিত ধাপ লিখে রাখুন। ক্রেডেনশিয়াল বা যথেচ্ছ সোর্স ডাম্প জমা রাখবেন না। কোনো ফিচারকে তখনই সম্পন্ন হিসেবে চিহ্নিত করুন, যখন তার গ্রহণযোগ্যতার মানদণ্ড যাচাই করা হয়েছে।

আবার শুরু করার সময় সম্পাদনার আগে Git-এর অবস্থা, সর্বশেষ প্রগ্রেস এবং প্রাসঙ্গিক সোর্স দেখে নিন। সামঞ্জস্যপূর্ণ নিজস্ব রিসোর্স পুনরায় ব্যবহার করুন; পরবর্তী চেকের জন্য দরকার হলে তবেই ডেভ সার্ভার চালু করুন। অপরিবর্তিত পূর্ণ পাস পুনরাবৃত্তি না করে [verification.md](https://github.com/bitsocialnet/bitsocial-web/blob/master/docs/agent-playbooks/verification.md) অনুসারে প্রভাব বুঝে চেক বেছে নিন।

সম্পর্কিত যেসব কাজ অন্য এজেন্টকে দেওয়া হয়, সেগুলোর পরিধি সুনির্দিষ্ট রাখুন এবং খেয়াল রাখুন যেন একটির সঙ্গে আরেকটি না মেলে। ভারী চেক ও ব্রাউজার সেশনের দায়িত্ব থাকে একটিই এজেন্টের। কোনো সম্পন্ন স্লাইস, বাধা বা হস্তান্তরের ফলে পরবর্তী অবদানকারীর যা জানা দরকার তা বদলে গেলে টেকসই স্টেট হালনাগাদ করুন; যান্ত্রিকভাবে প্রতিটি কমান্ড লগ করবেন না।
