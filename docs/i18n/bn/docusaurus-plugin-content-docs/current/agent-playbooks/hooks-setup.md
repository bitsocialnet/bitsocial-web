# এজেন্ট হুক

কমিট করা লাইফসাইকেল হুকগুলো কেবল সফলভাবে সম্পাদিত JavaScript/TypeScript ফাইলগুলোকে ইনস্টল করা oxfmt দিয়ে ফরম্যাট করে। ভাগ করা লজিক থাকে `scripts/agent-hooks/format.mjs`-এ; প্রতিটি নেটিভ র‍্যাপার কাজটি এর ওপরই ছেড়ে দেয়।

| অ্যাপ | নেটিভ কনফিগারেশন | ইভেন্ট |
|---|---|---|
| Codex | `.codex/hooks.json` | `PostToolUse`, `apply_patch` |
| Claude Code | `.claude/settings.json` | `PostToolUse`, `Edit|Write|MultiEdit` |
| Cursor | `.cursor/hooks.json` | `afterFileEdit` |

Claude আলাদা কোনো `.claude/hooks.json` পড়ে না। প্রজেক্ট ট্রাস্ট এবং হুক সক্রিয় থাকবে কি না, তা এখনও প্রতিটি অ্যাপ নিজেই নিয়ন্ত্রণ করে; ট্রাস্ট এড়িয়ে না গিয়ে অ্যাপটির বর্তমান সেটিংস দেখে নিন। `.codex/config.toml` রিপোজিটরির কনফিগারেশন, কোনো হুক কমান্ড রেজিস্ট্রি নয়।

ফরম্যাটারটি ইভেন্ট/পেলোড, সম্পাদনার সাফল্য, ফাইল এক্সটেনশন, এবং সিমলিংকসহ ফাইলটি রিপোজিটরির ভেতরেই আছে কি না, তা যাচাই করে। নির্ভরতা অনুপস্থিত থাকলে বা ইনপুট অপ্রাসঙ্গিক হলে কোনো কাজই হয় না। কমান্ডগুলো Corepack-এর নেটওয়ার্ক অ্যাক্সেস বন্ধ রেখে আর্গুমেন্ট অ্যারে ব্যবহার করে; হুক কোনো নির্ভরতা ইনস্টল করে না, বিল্ড/রিভিউ চালায় না, বা Git-এ কোনো পরিবর্তন ঘটায় না।

[verification.md](https://github.com/bitsocialnet/bitsocial-web/blob/master/docs/agent-playbooks/verification.md) অনুযায়ী চেকগুলো স্পষ্টভাবে নিজে চালান। ওয়ার্কফ্লো বদলানোর পরে `yarn ai-workflow:sync`, `yarn ai-workflow:check` ও `yarn ai-workflow:test` চালান। ফিক্সচারগুলো অস্থায়ী ফাইল এবং নকল ফরম্যাটার ইনভোকেশন ব্যবহার করে; প্রতিটি অ্যাপ তার কনফিগারেশন লোড করেছে কি না, তা এগুলো প্রমাণ করে না। আপগ্রেডের পরে অ্যাপটি রিলোড করে তার ক্যাটালগ দেখে নিন।

Impeccable ডিজাইন স্কিল ও এর এক্সিকিউটেবল হেল্পারগুলো `.agents/skills/impeccable`-এর অধীনে চাহিদামতো পাওয়া যায়। এর আগের Codex হুকটি একটি অনুপস্থিত ডিরেক্টরির দিকে নির্দেশ করত; ডিজাইন ওয়ার্কফ্লো এখন কেবল তখনই চলে, যখন এর স্কিলটি নির্বাচিত হয়, আর সর্বদা-চালু কোনো ডিজাইন হুক নেই। ডিজাইনের কাজের আনুষঙ্গিক ধাপ হিসেবে স্কিলটি প্রজেক্টের হুক পুনরায় কনফিগার করতে পারবে না।
