# React Hooks

`@bitsocial/bitsocial-react-hooks` fournit aux applications React une API de hooks pour le protocole Bitsocial : flux, commentaires, communautés, profils d'auteur, comptes et publication, sans serveur central. [5chan](/apps/5chan/) et [Seedit](/apps/seedit/) reposent sur cette bibliothèque.

La bibliothèque possède son propre site de documentation, mis à jour à chaque version : **[hooks.bitsocial.net](https://hooks.bitsocial.net/)**.

## Installation

```bash
npm install @bitsocial/bitsocial-react-hooks
```

Le package prend en charge React 16.8 et les versions ultérieures.

## Par où commencer

- [Démarrage rapide](https://hooks.bitsocial.net/docs/quickstart/) : affichez votre premier flux de communauté.
- [Concepts](https://hooks.bitsocial.net/docs/concepts/) : comment s'articulent les flux, les comptes locaux, l'état partagé et la publication.
- [Référence de l'API](https://hooks.bitsocial.net/docs/api/feeds-hooks/) : chaque hook avec ses options et ses valeurs de retour.
- [Bac à sable](https://hooks.bitsocial.net/#playground) : modifiez des exemples en direct qui s'exécutent sur du contenu simulé.
- [Développer avec l'IA](https://hooks.bitsocial.net/docs/ai/) : `llms.txt` et une version Markdown de chaque page pour les agents de programmation.
