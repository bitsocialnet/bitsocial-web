# Bitsocial మరియు Mirage

[Mirage](https://mirage.foundation/) కమ్యూనిటీలు, థ్రెడ్ పోస్ట్‌లు, ఓట్లు ఉన్న Reddit తరహా చర్చా
నెట్‌వర్క్. ఇది కంపెనీ డేటాబేస్‌కు బదులుగా సొంత బ్లాక్‌చెయిన్‌పై నడుస్తుంది; అది CometBFT
కన్సెన్సస్‌తో కూడిన Cosmos SDK చెయిన్. Bitsocialకు అత్యంత దగ్గరి ఉత్పత్తి [Seedit](/apps/seedit/),
Bitsocial నెట్‌వర్క్‌పై ఉన్న Reddit తరహా యాప్; కాబట్టి ఈ పోలిక ప్రధానంగా ఒక్కొక్కటీ కమ్యూనిటీలను ఎలా
హోస్ట్ చేస్తుంది, ఎలా సొంతం చేసుకుంటుంది, ఎలా మోడరేట్ చేస్తుంది అన్నదాని గురించే.

## Mirage ఎలా పనిచేస్తుంది

- **నోడ్‌లు.** Mirage నోడ్ అంటే ఒక వాలిడేటర్, ఒక PostgreSQL డేటాబేస్, ఒక ఇండెక్సర్, ఒక HTTP API,
  వెబ్ ఫ్రంట్‌ఎండ్ ఉన్న ఒకే Docker కంటైనర్. ప్రతి నోడ్ ఒక వాలిడేటర్ కూడా.
  [డిప్లాయ్ గైడ్](https://github.com/MirageFoundation/mirage-node/blob/dev/docs/guides/deploy.md)
  ప్రకారం, ఒక నోడ్‌ను నడపడానికి amd64పై Ubuntu సర్వర్, ఆపరేటర్ ఖాతాలో 10,000,000 MIRAGE టోకెన్‌లు
  అవసరం.
- **పోస్ట్ చేయడం.** బ్రౌజర్ ప్రతి చర్యపై వినియోగదారు secp256k1 కీతో సంతకం చేస్తుంది, ఉచిత
  వినియోగదారులు చిన్న proof of work కూడా లెక్కిస్తారు. నోడ్ ఆ చర్యను చెయిన్ లావాదేవీలో చుట్టి ఫీజు
  చెల్లిస్తుంది.
- **చదవడం.** ప్రతి నోడ్ ఇండెక్సర్ చెయిన్ డేటాను తన సొంత డేటాబేస్‌లోకి కాపీ చేసి, HTTP API ద్వారా
  ఫీడ్‌లను అందిస్తుంది. నోడ్‌లు సుమారు ఒక వారం బ్లాక్‌లను ఉంచుకుంటాయి, కాబట్టి దీర్ఘకాల పోస్ట్
  చరిత్ర ప్రతి నోడ్ డేటాబేస్‌లో ఉంటుంది; కొత్త నోడ్ తన సింక్ పాయింట్‌కు ముందున్న చరిత్ర లేకుండానే
  మొదలవుతుంది.
- **ఖాతాలు.** ఖాతా అంటే 12 పదాల సీడ్ ఫ్రేజ్ నుండి తీసిన కీ, అదే సీడ్ ఏ నోడ్‌పైనైనా పనిచేస్తుంది.
  యూజర్‌నేమ్‌లు చెయిన్‌పై నమోదవుతాయి, నెట్‌వర్క్ అంతటా ప్రత్యేకంగా ఉంటాయి.
- **కమ్యూనిటీలు.** చెల్లుబాటయ్యే ప్రతి పేరూ ఇప్పటికే ఒక కమ్యూనిటీ, దాన్ని ఎవరూ సొంతం చేసుకోరు.
  ఒక్కొక్కటీ పది మంది వరకు వినియోగదారులున్న చెల్లింపు క్యూరేటర్ బృందాలు ఒక కమ్యూనిటీ మోడరేటెడ్
  వ్యూను నిర్వహిస్తాయి; పాఠకులు ఒక బృందం వ్యూను, నోడ్ డిఫాల్ట్ వ్యూను లేదా సెన్సార్ చేయని వ్యూను
  ఎంచుకుంటారు. [Mirage FAQ](https://mirage.talk/faq) చూడండి.
- **టోకెన్.** MIRAGE టోకెన్ సబ్‌స్క్రిప్షన్‌లకు చెల్లిస్తుంది, రచయితలకు, నోడ్‌లకు రివార్డులు
  ఇస్తుంది, వాలిడేటర్లకు పాలనలో బరువును ఇస్తుంది. సబ్‌స్క్రైబర్లు proof of workను దాటవేస్తారు,
  ఎక్కువ పరిమితులు పొందుతారు.

## అవి ఎక్కడ భిన్నంగా ఉంటాయి

### కమ్యూనిటీ ఎవరి సొంతం

Seeditలో కమ్యూనిటీని సృష్టించిన వ్యక్తి దాని కీ జతను కలిగి ఉంటారు, దాని నోడ్‌ను నడుపుతారు లేదా ఆ
పనిని అప్పగిస్తారు, దాన్ని మోడరేట్ చేస్తారు. Mirageలో కమ్యూనిటీ ఎవరి సొంతమూ కాదు: పోటీపడే క్యూరేటర్
బృందాలు ఒకే పేరుకు మోడరేటెడ్ వ్యూలను అందిస్తాయి, అత్యధిక చెల్లింపు సబ్‌స్క్రైబర్లు ఎంచుకున్న బృందం
వ్యూనే డిఫాల్ట్ వ్యూ అవుతుంది.

### స్పామ్ నియంత్రణ

Mirage మొత్తం నెట్‌వర్క్‌కు ఒకే నియమాన్ని వర్తింపజేస్తుంది: ఉచిత వినియోగదారులు proof of workతో
చెల్లిస్తారు, దాని కష్టం వచ్చే పరిమాణాన్ని బట్టి సర్దుబాటు అవుతుంది; సబ్‌స్క్రైబర్లు దాన్ని
దాటవేస్తారు. Bitsocialలో ప్రతి కమ్యూనిటీ క్యాప్చాల నుండి అనుమతి జాబితాలు, చెల్లింపుల వరకు తన సొంత
ఛాలెంజ్‌ను ఎంచుకుంటుంది. [కస్టమ్ యాంటీ-స్పామ్ సవాళ్లు](/custom-challenges/) చూడండి.

### మౌలిక సదుపాయాలు

Mirageకు బ్లాక్‌చెయిన్ అవసరం. వాలిడేటర్లు ప్రతి చర్యపై కన్సెన్సస్‌కు వస్తారు, ప్రతి నోడ్ పూర్తి
సర్వర్ స్టాక్‌ను నడుపుతుంది, పెద్ద టోకెన్ స్టేక్‌ను ఉంచుకోవాలి. Bitsocialకు చెయిన్ లేదు: కమ్యూనిటీ
నోడ్ డెస్క్‌టాప్ యాప్ నుండి లేదా `bitsocial-cli` నుండి సాధారణ వినియోగదారు హార్డ్‌వేర్‌పై నడుస్తుంది,
పాఠకులు కంటెంట్‌ను పంచుకోవడంలో సాయపడగలరు.

### నెట్‌వర్క్ అంతటా నియంత్రణ

Mirageలో వాలిడేటర్ స్టేక్ బరువుతో కూడిన ఆన్-చెయిన్ పాలన ఉంది. అది కష్టాన్ని, ధరలను, టోకెన్
ఉద్గారాన్ని మార్చగలదు, టోకెన్‌లను మింట్ లేదా బర్న్ చేయగలదు, అడ్మిన్‌లను నియమించగలదు; ఆ అడ్మిన్‌లు
చేసే తొలగింపులను రిఫరెన్స్ ఇండెక్సర్ ఏ పోస్ట్‌కైనా వర్తింపజేస్తుంది. చెయిన్ కోడ్ పాలనకు
[ఖాతాలను తొలగించడానికి](https://github.com/MirageFoundation/mirage-node/blob/142a2e4e2542b6a3c9cc6d71591c282e5e5a9503/blockchain/x/core/module/module.go#L2572-L2573),
[ఏ చిరునామా నుండైనా టోకెన్‌లను పంపడానికి](https://github.com/MirageFoundation/mirage-node/blob/142a2e4e2542b6a3c9cc6d71591c282e5e5a9503/blockchain/x/core/module/module.go#L2656)
కూడా అనుమతిస్తుంది. 2026 అక్టోబర్‌లో నాలుగు వాలిడేటర్లు చెయిన్ బ్లాక్‌లను ఉత్పత్తి చేశారు, ఆ
నాలుగింటినీ ప్రాజెక్ట్ సొంత రన్‌బుక్‌లే నిర్వహించాయి.

Bitsocialకు ప్రోటోకాల్ స్థాయి అడ్మినిస్ట్రేటర్ లేరు. కమ్యూనిటీ యజమానులు తమ సొంత కమ్యూనిటీలను మోడరేట్
చేస్తారు, ఏమి చూపించాలో యాప్‌లు ఎంచుకుంటాయి.
[లోకల్ మోడరేషన్, గ్లోబల్ బ్యాన్స్ కాదు](/local-moderation/) చూడండి.

### బ్రౌజర్

Mirage వెబ్ క్లయింట్ ఒక నోడ్‌కు HTTP క్లయింట్: బ్రౌజర్ చర్యలపై సంతకం చేస్తుంది కానీ పీర్-టు-పీర్
నెట్‌వర్క్‌లో చేరదు. Bitsocial యాప్‌లు బ్రౌజర్ ట్యాబ్‌లోనే పీర్-టు-పీర్ నోడ్‌ను నడపగలవు.
[బ్రౌజర్ పీర్-టు-పీర్](/browser-p2p/) చూడండి.
