# Bitsocial మరియు బ్లాక్‌చెయిన్ సోషల్ నెట్‌వర్క్‌లు

Lens, DeSo, Steem ఒక్కొక్కటీ సోషల్ కార్యకలాపాలను బ్లాక్‌చెయిన్‌పై ఉంచుతాయి. ఖాతాలు, ఫాలోలు,
పోస్ట్‌లు లేదా వాటి చుట్టూ ఉండే నియమాలు వాలిడేటర్లు క్రమబద్ధీకరించి నిల్వ చేసే లావాదేవీలుగా మారతాయి.
Bitsocial ఏ బ్లాక్‌చెయిన్‌నూ వాడదు: సోషల్ మీడియాకు ప్రతి పోస్ట్‌కు గ్లోబల్ క్రమం అవసరం లేదు, కాబట్టి
Bitsocial కన్సెన్సస్, గ్యాస్, స్టేకింగ్‌లను వదిలేస్తుంది. ఆ తర్కం కోసం
[పీర్-టు-పీర్ ప్రోటోకాల్](/peer-to-peer-protocol/) చూడండి.

## వాటిలో ఉమ్మడిగా ఉన్నవి

- **ప్రతి రైట్‌కూ ఎవరో ఒకరు చెల్లిస్తారు.** Lens గ్యాస్ వసూలు చేస్తుంది, దాన్ని యాప్‌లు స్పాన్సర్
  చేయవచ్చు; DeSo ప్రతి చర్యపై ఫీజు వసూలు చేస్తుంది; Steem స్టేక్ చేసిన టోకెన్‌లను బట్టి చర్యలను
  రేషన్ చేస్తుంది.
- **చెయిన్ అందరికీ ఒకే స్పామ్ విధానాన్ని నిర్ణయిస్తుంది.** ఫీజులు, స్టేక్, ఖాతా ఖర్చులు ప్రతి
  కమ్యూనిటీ ఎంచుకునేవిగా కాకుండా నెట్‌వర్క్ అంతటా వర్తిస్తాయి.
- **ఆన్-చెయిన్ రికార్డులు శాశ్వతం.** యాప్‌లు కంటెంట్‌ను దాచగలవు, కానీ చెయిన్ నుండి తొలగించలేవు.
- **బ్రౌజర్‌లు API క్లయింట్‌లు.** వెబ్ యాప్‌లు లావాదేవీలపై సంతకం చేసి, వేరొకరు నడిపే నోడ్, ఇండెక్సర్
  లేదా API ద్వారా చదువుతాయి.

## Lens

[Lens](https://lens.xyz/) Lens Chainపై నడుస్తుంది; ఇది ZKsync ZK Stackతో నిర్మించిన Ethereum లేయర్
2, డేటా లభ్యత కోసం Availను వాడుతుంది.
[2026 జనవరి నుండి Lens బాధ్యతలను Mask Network చూసుకుంటోంది](https://lens.xyz/news/mask-network-to-steward-the-next-chapter-of-lens).

- **చెయిన్‌పై:** ఖాతాలు స్మార్ట్ కాంట్రాక్టులు, యూజర్‌నేమ్‌లు నేమ్‌స్పేస్‌లలోని NFTలు; గ్రాఫ్‌లు,
  గ్రూపులు, ఫీడ్‌లు, వాటి నియమాలు కూడా కాంట్రాక్టులే.
- **చెయిన్ బయట:** పోస్ట్ టెక్స్ట్, మీడియా ఒక URI వద్ద ఉన్న JSON ఫైల్‌లో ఉంటాయి, సాధారణంగా IPFS ముందు
  ఉండే Lens స్టోరేజ్ సేవ అయిన Groveలో. రియాక్షన్‌లు, బుక్‌మార్క్‌లను Lens API ఉంచుకుంటుంది, యాప్‌లు
  ఆ API ద్వారా చదువుతాయి.
- **స్పామ్, ద్వారాలు:** లావాదేవీలకు GHOలో గ్యాస్ అవసరం, దాన్ని యాప్‌లు రేట్ పరిమితులతో స్పాన్సర్
  చేయవచ్చు. ఫీడ్, గ్రూప్ నియమాలు టోకెన్ హోల్డింగ్‌లను లేదా చెల్లింపులను తప్పనిసరి చేయవచ్చు.
- **చెయిన్ నిర్వహణ:** [L2BEAT](https://l2beat.com/scaling/projects/lens) Lens Chainను Stage 0
  validiumగా రేట్ చేస్తుంది; దానికి లావాదేవీలను చేర్చడానికి నిరాకరించగల కేంద్రీకృత ఆపరేటర్ ఉంది.

## DeSo

[DeSo](https://docs.deso.org/) సోషల్ యాప్‌ల కోసం నిర్మించిన లేయర్-1 బ్లాక్‌చెయిన్. ఇది 2024 జూలైలో
proof of work నుండి proof of stakeకు మారింది.

- **చెయిన్‌పై:** ప్రొఫైల్‌లు, పోస్ట్‌లు, లైక్‌లు, ఫాలోలు, డైరెక్ట్ మెసేజ్‌లు అన్నీ ప్రతి ఫుల్ నోడ్
  నిల్వ చేసే లావాదేవీలే. చిత్రాలు, వీడియోలు చెయిన్ బయట హోస్ట్ అవుతాయి; రిఫరెన్స్ నోడ్ Google Cloud
  Storage, Cloudflare Streamలను వాడుతుంది.
- **స్పామ్:** ప్రతి చర్యకు DESOలో ఫీజు చెల్లించాలి. కొత్త వినియోగదారులు సాధారణంగా ఫోన్ ధ్రువీకరణ
  తర్వాత ఒక నోడ్ నుండి స్టార్టర్ DESO పొందుతారు.
- **మోడరేషన్:** ప్రతి నోడ్ బ్లాక్‌లిస్ట్ లేదా గ్రేలిస్ట్ చేయడం ద్వారా తాను ఏమి చూపించాలో
  నిర్ణయిస్తుంది, కానీ
  [కంటెంట్ ఆన్-చెయిన్‌లోనే ఉంటుంది](https://docs.deso.org/deso-blockchain/content-moderation).
- **కమ్యూనిటీలు:** డాక్యుమెంటేషన్ కమ్యూనిటీ లేదా ఫోరమ్ ప్రిమిటివ్‌ను వివరించదు; "కమ్యూనిటీ" అంటే ఒక
  యాప్ క్యూరేట్ చేసే ఫీడ్.
- **నోడ్‌ను నడపడం:** [వాలిడేటర్ గైడ్](https://docs.deso.org/deso-validators/run-a-validator) ప్రకారం
  వాలిడేటర్లకు కనీసం 32 GB RAM, 200 GB డిస్క్ అవసరం.

## Steem

[Steem](https://steem.com/) రచయితలకు, క్యూరేటర్లకు టోకెన్‌లలో చెల్లించే సోషల్ బ్లాక్‌చెయిన్; దాని
ప్రధాన బ్లాగింగ్ యాప్ [Steemit](https://steemit.com/). 2020లో Steem నుండి Hive విడిపోయింది;
[Hive వైట్‌పేపర్](https://hive.io/whitepaper.pdf) ప్రకారం, Steemit Inc.ను Justin Sunకు విక్రయించిన
తర్వాత ఆ ఫోర్క్ జరిగింది.

- **చెయిన్‌పై:** టెక్స్ట్ పోస్ట్‌లు, కామెంట్‌లు, ఓట్లు, వాటి ఎడిట్ చరిత్ర; ప్రతి మూడు సెకన్లకు ఒక
  బ్లాక్ ఉత్పత్తి చేసే 21 మంది ఎన్నికైన విట్‌నెస్‌లు వీటిని క్రమబద్ధీకరిస్తారు. చిత్రాలు చెయిన్ బయట
  హోస్ట్ అవుతాయి.
- **స్పామ్:** చర్యలు Resource Creditsను వినియోగిస్తాయి, అవి స్టేక్ చేసిన STEEMతో పాటు పెరుగుతాయి.
  ఖాతా సృష్టించడానికి STEEM ఖర్చవుతుంది; ఈమెయిల్ చిరునామా, ఫోన్ నంబర్ ధ్రువీకరించిన వినియోగదారుల
  తరఫున Steemit దాన్ని చెల్లిస్తుంది.
- **కమ్యూనిటీలు:** అవి కన్సెన్సస్ బయట
  [ఒక ఇండెక్సర్ అర్థం చేసుకునే కస్టమ్ ఆపరేషన్‌లు](https://github.com/steemit/hivemind/blob/master/docs/communities.md).
  మోడరేటర్లు పోస్ట్‌లను మ్యూట్ చేయగలరు, అది వాటిని యాప్‌లలో దాస్తుంది కానీ ఆన్-చెయిన్‌లోనే
  ఉంచుతుంది.
- **రివార్డులు:** ద్రవ్యోల్బణం రివార్డులకు నిధులు సమకూరుస్తుంది, స్టేక్ బరువుతో కూడిన ఓట్లు వాటిని
  ఎలా పంచాలో నిర్ణయిస్తాయి, కాబట్టి పెద్ద హోల్డర్లు ఏది దృష్టిని ఆకర్షిస్తుందో నిర్దేశిస్తారు.
