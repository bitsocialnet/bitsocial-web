# అనువాదాలు

about సైట్ `about/public/translations/{lang}/default.json`లో i18next JSONను వాడుతుంది. Docusaurus సోర్స్ అనువాదాలు విడిగా `docs/i18n/`లో ఉంటాయి.

## About సైట్ కీలు

`.agents/skills/translate/SKILL.md`ను వాడండి. ప్రస్తుత లొకేల్‌లను డిస్క్ నుండి కనుగొనండి, ప్లేస్‌హోల్డర్‌లు, మార్కప్, సాంకేతిక పదాలు, బ్రాండ్ పేర్లను అలాగే ఉంచండి. పెద్ద అభ్యర్థనల కోసం చైల్డ్ ఏజెంట్లు స్వతంత్ర మ్యాప్‌లను రూపొందించవచ్చు, కానీ ప్రతి లొకేల్ రైట్‌ను ఒకే పేరెంట్ వరుసగా వర్తింపజేస్తుంది; అప్‌డేటర్‌కు రైటర్ లాక్ లేదు.

ఈ టాస్క్‌కే చెందిన ప్రత్యేకమైన మ్యాప్ పాత్‌ను వాడండి. `node scripts/update-translations.js --key <key> --map <map.json> --include-en --dry`తో ప్రివ్యూ చేసి, ఆ తర్వాత అవే ఆర్గ్యుమెంట్‌లు, `--write`తో వర్తింపజేయండి. రాసిన తర్వాత కవరేజ్/విలువలను ధృవీకరించి, ఈ టాస్క్‌కు చెందిన తాత్కాలిక మ్యాప్‌లను మాత్రమే తొలగించండి.

అభ్యర్థించిన తొలగింపుల కోసం `--delete` వాడండి. అనుమతి పొందిన `--audit --write`కు ముందు `--audit --dry` ఫలితాలను పరిశీలించండి; డైనమిక్ అనువాద కీలకు సోర్స్‌ను మాన్యువల్‌గా సమీక్షించడం అవసరం. సాంకేతిక పదం, బ్రాండ్ లేదా ప్లేస్‌హోల్డర్ కోసం మాత్రమే ఇంగ్లీష్‌ను ప్రతి లొకేల్‌లోకి కాపీ చేయండి.

## Docusaurus పేజీలు

`scripts/translate-docs.py` అన్ని పేజీలు/లొకేల్‌ల కోసం ఒక బల్క్ రైటర్, దీనికి ఫైల్‌వారీ ఫిల్టర్ లేదు; చిన్న అనువాద సవరణ కోసం దీన్ని వాడవద్దు. `scripts/check-docs-translations.py` రీడ్-ఓన్లీ వెరిఫైయర్, ఇది `--locales`, `--paths`లకు మద్దతిస్తుంది.

కోడ్ ఫెన్స్‌లు, లింక్‌లు, ఇన్‌లైన్ కోడ్, కాంట్రాక్ట్ చిరునామాలు, హెడింగ్‌లు, పట్టికలు, అడ్మొనిషన్‌లను ఇంగ్లీష్ సోర్స్‌కు అనుగుణంగా ఉంచండి. వెరిఫైయర్ ఎర్రర్‌లను పరిష్కరించండి; బ్రాండ్-పేరు `frontmatter-untranslated` హెచ్చరికలు ఆశించదగినవే. `docs/AGENTS.md`ను అనుసరించండి; డాక్స్ థీమ్ లేదా i18n ప్రవర్తనను మార్చేటప్పుడు స్టాటిక్ అవుట్‌పుట్, Pagefind అనుగుణంగా ఉండేలా రూట్ ద్వారా బిల్డ్ చేయండి.

## ఐచ్ఛిక అర్థపరమైన సమీక్ష

ఎంచుకున్న i18next కీల కోసం `scripts/jev/translation-README.md`ను వాడండి. డాక్యుమెంటేషన్ పేజీల కోసం ముందుగా `node scripts/jev/docs-translations.mjs --locales it,de --paths browser-p2p.md` నడపండి. దీనికి లొకేల్/పేజీని స్పష్టంగా ఎంచుకోవడం అవసరం; ఇది నిర్మాణాత్మక వెరిఫైయర్‌ను నడుపుతుంది, లైవ్ ఇన్‌ఫరెన్స్ ప్రారంభించే వరకు అర్థపరమైన సమీక్షను ధృవీకరించబడనిదిగా నివేదిస్తుంది. టాస్క్‌కు ప్రొవైడర్ అనుమతి, బడ్జెట్ ఉన్నప్పుడు మాత్రమే `--live` జోడించండి; భాగస్వామ్య ప్రైవేట్ మెషిన్ కాన్ఫిగరేషన్ క్రెడెన్షియల్‌లను, పిన్ చేసిన మోడల్‌ను అందిస్తుంది. ఎన్విరాన్‌మెంట్ వేరియబుల్‌లు, `--model` ఆ సెటప్‌ను భర్తీ చేయగలవు. ఈ ఆదేశం అనువాదాలను ఎప్పుడూ సవరించదు.

పేజీ అడాప్టర్ మొత్తం పేజీ కాంటెక్స్ట్‌ను కాపాడుతుంది, ప్రతి పేజీని 24 KBకి, ప్రతి రన్‌ను 30 జతలకు పరిమితం చేస్తుంది. పెద్ద పేజీల కోసం `translations.mjs --pairs` కోసం స్పష్టంగా సమలేఖనం చేసిన సోర్స్/అనువాద పేరా జతలను సిద్ధం చేయండి; ఇండెక్స్ ఆధారంగా పేరాలను ఆటోమేటిక్‌గా జత చేయవద్దు. అర్థపరమైన ఫలితాలు సలహా మాత్రమే: నివేదించిన సమస్యలను, అనిశ్చితిని పరిశీలించండి, నిర్ణయాత్మక కోడ్/లింక్/చిరునామా తనిఖీలను కొనసాగించండి.
