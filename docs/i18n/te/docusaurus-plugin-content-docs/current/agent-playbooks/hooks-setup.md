# ఏజెంట్ హుక్‌లు

కమిట్ చేసిన లైఫ్‌సైకిల్ హుక్‌లు విజయవంతంగా సవరించిన JavaScript/TypeScript ఫైల్‌లను ఇన్‌స్టాల్ చేసిన oxfmt ద్వారా ఫార్మాట్ చేయడం మాత్రమే చేస్తాయి. భాగస్వామ్య లాజిక్ `scripts/agent-hooks/format.mjs`లో ఉంటుంది; ప్రతి నేటివ్ ర్యాపర్ పనిని దానికే అప్పగిస్తుంది.

| యాప్ | నేటివ్ కాన్ఫిగరేషన్ | ఈవెంట్ |
|---|---|---|
| Codex | `.codex/hooks.json` | `PostToolUse`, `apply_patch` |
| Claude Code | `.claude/settings.json` | `PostToolUse`, `Edit|Write|MultiEdit` |
| Cursor | `.cursor/hooks.json` | `afterFileEdit` |

Claude విడిగా ఉండే `.claude/hooks.json`ను చదవదు. ప్రాజెక్ట్ ట్రస్ట్‌ను, హుక్‌లు ప్రారంభించబడ్డాయా లేదా అనేదాన్ని ఇప్పటికీ ప్రతి యాప్ తానే నియంత్రిస్తుంది; ట్రస్ట్‌ను దాటవేయకుండా దాని ప్రస్తుత సెట్టింగ్‌లను పరిశీలించండి. `.codex/config.toml` రిపాజిటరీ కాన్ఫిగరేషన్, హుక్ ఆదేశాల రిజిస్ట్రీ కాదు.

ఫార్మాటర్ ఈవెంట్/పేలోడ్‌ను, సవరణ విజయవంతమైందా అనేదాన్ని, ఫైల్ ఎక్స్‌టెన్షన్‌ను, సిమ్‌లింక్‌లతో సహా ఫైల్ రిపాజిటరీ లోపలే ఉందా అనేదాన్ని ధృవీకరిస్తుంది. డిపెండెన్సీలు లేకపోయినా లేదా ఇన్‌పుట్ సంబంధం లేనిదైనా ఏ పనీ జరగదు. ఆదేశాలు Corepack నెట్‌వర్క్ యాక్సెస్‌ను నిలిపివేసి ఆర్గ్యుమెంట్ అరేను వాడతాయి; హుక్‌లు డిపెండెన్సీలను ఇన్‌స్టాల్ చేయవు, బిల్డ్‌లు/రివ్యూలను నడపవు, Gitను మార్చవు.

[verification.md](https://github.com/bitsocialnet/bitsocial-web/blob/master/docs/agent-playbooks/verification.md) ప్రకారం తనిఖీలను స్పష్టంగా నడపండి. వర్క్‌ఫ్లోను మార్చిన తర్వాత `yarn ai-workflow:sync`, `yarn ai-workflow:check`, `yarn ai-workflow:test` నడపండి. ఫిక్స్చర్‌లు తాత్కాలిక ఫైల్‌లను, నకిలీ ఫార్మాటర్ ఇన్‌వోకేషన్‌లను వాడతాయి; ప్రతి యాప్ తన కాన్ఫిగరేషన్‌ను లోడ్ చేసిందని అవి నిరూపించవు. అప్‌గ్రేడ్‌ల తర్వాత యాప్‌ను రీలోడ్ చేసి, యాప్ కేటలాగ్‌ను పరిశీలించండి.

Impeccable డిజైన్ నైపుణ్యం, దాని ఎగ్జిక్యూటబుల్ హెల్పర్‌లు `.agents/skills/impeccable` కింద అవసరమైనప్పుడు వాడుకోవడానికి అందుబాటులోనే ఉంటాయి. దాని పాత Codex హుక్ లేని డైరెక్టరీని సూచించేది; ఇప్పుడు డిజైన్ వర్క్‌ఫ్లో దాని నైపుణ్యాన్ని ఎంచుకున్నప్పుడు నడుస్తుంది, ఎప్పుడూ-ఆన్‌లో ఉండే డిజైన్ హుక్ ఏదీ లేదు. డిజైన్ పనిలో యాదృచ్ఛిక దశగా ఈ నైపుణ్యం ప్రాజెక్ట్ హుక్‌లను మళ్లీ కాన్ఫిగర్ చేయకూడదు.
