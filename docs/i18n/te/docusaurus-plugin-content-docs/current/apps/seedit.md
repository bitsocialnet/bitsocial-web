# Seedit

Seedit అనేది Bitsocial ప్రోటోకాల్‌పై నిర్మించబడిన పాత-శైలి Redditకి సర్వర్‌లెస్, అడ్మిన్‌లెస్ మరియు పూర్తిగా వికేంద్రీకృత ప్రత్యామ్నాయం. ఇది వినియోగదారులకు వారి సంఘాలపై పూర్తి యాజమాన్యాన్ని ఇస్తుంది - ఎవరైనా ఒకదాన్ని సృష్టించవచ్చు మరియు `/s/funny` వంటి ఒకే చిన్న రూట్ కోసం బహుళ సంఘాలు పోటీపడవచ్చు.

## డౌన్‌లోడ్‌లు

| వేదిక       | లింక్                                                  |
| ----------- | ------------------------------------------------------ | -------------------- |
| వెబ్        | [seedit.app](https://seedit.app)                       |
| వెబ్ (ENS)  | బ్రేవ్ బ్రౌజర్ లేదా IPFS కంపానియన్ ద్వారా `seedit.eth` |
| డెస్క్‌టాప్ | Mac, Windows మరియు Linux కోసం అందుబాటులో ఉంది          |
| మొబైల్      | Android                                                | కోసం అందుబాటులో ఉంది |

## సంఘాలు ఎలా పని చేస్తాయి

Seedit సబ్‌రెడిట్‌ల మాదిరిగానే కమ్యూనిటీలుగా కంటెంట్‌ను నిర్వహిస్తుంది. ప్రతి సంఘం దాని సృష్టికర్త స్వంతం మరియు కేంద్రీకృత పరిపాలన లేకుండా పనిచేస్తుంది. `/s/funny` వంటి ఒకే [డైరెక్టరీ](/directories/) రూట్ కోసం బహుళ సంఘాలు పోటీ పడవచ్చు, ఆ రూట్ ప్రస్తుత విజేతను తెరుస్తుంది. సబ్‌స్క్రిప్షన్‌లు, పోస్ట్ లింక్‌లు ఎల్లప్పుడూ ఖచ్చితమైన సంఘాన్నే సూచిస్తాయి.

### సంఘాన్ని సృష్టిస్తోంది

కొత్త సంఘాన్ని సృష్టించడానికి రెండు మార్గాలు ఉన్నాయి:

1. **డెస్క్‌టాప్ క్లయింట్** — మీ సంఘాన్ని సెటప్ చేయడానికి మరియు కాన్ఫిగర్ చేయడానికి డెస్క్‌టాప్ అప్లికేషన్‌లో అంతర్నిర్మిత GUIని ఉపయోగించండి.
2. **bitsocial-cli** — కమాండ్ లైన్ నుండి కమ్యూనిటీలను సృష్టించడానికి మరియు నిర్వహించడానికి CLI సాధనాన్ని అమలు చేయండి.

### డిఫాల్ట్ సంఘం జాబితా

కొత్త ఖాతాలు [bitsocialnet/lists](https://github.com/bitsocialnet/lists) రిపోజిటరీలోని `seedit-default-subscriptions.json`లో నిర్వచించబడిన, ఖచ్చితమైన సంఘాలతో కూడిన డిఫాల్ట్ జాబితాకు సబ్‌స్క్రైబ్ అవుతాయి. డైరెక్టరీ అభ్యర్థులు అదే రిపోజిటరీలోని `seedit-directories/seedit-<code>-directory.json` ఫైల్‌లలో జాబితా చేయబడతారు. మీ సంఘాన్ని ఈ రెండు జాబితాల్లో దేనికైనా జోడించడానికి, మీ సంఘం వివరాలతో పుల్ రిక్వెస్ట్ సమర్పించండి.
