# 5chan

5chan అనేది Bitsocial ప్రోటోకాల్‌పై నడిచే సర్వర్‌లెస్, అడ్మిన్‌లెస్ మరియు పూర్తిగా వికేంద్రీకృత ఇమేజ్‌బోర్డ్. ఇది సుపరిచితమైన ఇమేజ్‌బోర్డ్ డైరెక్టరీ నిర్మాణాన్ని అనుసరిస్తూనే వికేంద్రీకృత యాజమాన్యాన్ని పరిచయం చేస్తుంది — ఎవరైనా ఒక బోర్డును సృష్టించవచ్చు, ఒకే డైరెక్టరీ స్లాట్ కోసం బహుళ బోర్డులు ఓటింగ్ విధానం ద్వారా పోటీ పడవచ్చు.

## డౌన్‌లోడ్‌లు

| ప్లాట్‌ఫారమ్ | లింక్                                         |
| ------------ | --------------------------------------------- |
| వెబ్         | [5chan.app](https://5chan.app)                |
| డెస్క్‌టాప్  | Mac, Windows మరియు Linux కోసం అందుబాటులో ఉంది |
| మొబైల్       | Android కోసం అందుబాటులో ఉంది                  |

## బోర్డులు ఎలా పనిచేస్తాయి

క్లాసిక్ డైరెక్టరీ లేఅవుట్‌ను (ఉదా., `/b/`, `/g/`) ఉపయోగించి 5chan కంటెంట్‌ను బోర్డులుగా నిర్వహిస్తుంది. ఒక కేంద్ర అడ్మిన్ ప్రతి బోర్డును నియంత్రించే సంప్రదాయ ఇమేజ్‌బోర్డ్‌లకు భిన్నంగా, ఏ వినియోగదారైనా తమ స్వంత బోర్డును సృష్టించి పూర్తిగా స్వంతం చేసుకోవడానికి 5chan అనుమతిస్తుంది. బహుళ బోర్డులు ఒకే డైరెక్టరీ స్లాట్‌ను లక్ష్యంగా చేసుకున్నప్పుడు, ఆ స్థానం కోసం అవి పోటీ పడతాయి; [డైరెక్టరీలు](/directories/) చూడండి.

### బోర్డును సృష్టించడం

కొత్త బోర్డును సృష్టించడానికి, మీరు `bitsocial-cli`ని పీర్-టు-పీర్ నోడ్‌గా నడపాలి. దీనివల్ల మీ బోర్డు ఏ కేంద్ర సర్వర్‌పైనా ఆధారపడకుండా వికేంద్రీకృత పద్ధతిలో హోస్ట్ అవుతుంది.

### డైరెక్టరీ కేటాయింపులు

ప్రతి డైరెక్టరీకి సంబంధించిన అభ్యర్థి బోర్డులు [bitsocialnet/lists](https://github.com/bitsocialnet/lists) రిపోజిటరీలోని `5chan-directories/5chan-<code>-directory.json` ఫైల్‌లో జాబితా చేయబడతాయి, ఒక బోర్డు ఆ ఫైల్‌కు పుల్ రిక్వెస్ట్ పంపడం ద్వారా డైరెక్టరీలో చేరుతుంది. 5chan [`@bitsocial/pubsub-voting`](https://github.com/bitsocialnet/pubsub-voting)తో ప్రతి డైరెక్టరీకి ఒక ఓటింగ్ పోటీని కూడా నిర్వహిస్తుంది: ప్రతి 5chan Pass హోల్డర్‌కు ఒక ఓటు ఉంటుంది, జాబితాలో లేని బోర్డుకు ఓటు వేస్తే దాన్ని నామినేట్ చేసినట్లవుతుంది. ఈ పోటీలు ప్రస్తుతం Base Sepolia టెస్ట్‌నెట్‌లో నడుస్తున్నాయి, అక్కడ ఫలితాలు చూపబడతాయి కానీ జాబితా క్రమాన్ని మార్చవు.

## అంతర్గత విషయాలు

లోపలి పొరలో, తన నెట్‌వర్క్ పరస్పర చర్యల కోసం 5chan భాగస్వామ్య Bitsocial ప్రోటోకాల్ క్లయింట్ లేయర్‌ను ఉపయోగిస్తుంది.
5chan.appలోని వెబ్ యాప్ డిఫాల్ట్‌గా బ్రౌజర్‌లోనే ఒక Helia నోడ్‌ను నడుపుతుంది, కాబట్టి ఒక సాధారణ ట్యాబ్ కూడా
నెట్‌వర్క్‌లో పీర్‌గా చేరుతుంది: అది ఇతర పీర్‌ల నుండి బోర్డులను లోడ్ చేసి pubsub ద్వారా ప్రచురిస్తుంది, కంటెంట్ మార్గంలో ఎక్కడా కేంద్రీకృత
IPFS గేట్‌వే ఉండదు. ఇందులో ఏమి ఇమిడి ఉందో, బ్రౌజర్ నోడ్ ఇప్పటికీ ఏమి చేయలేదో తెలుసుకోవడానికి [బ్రౌజర్ పీర్-టు-పీర్](/browser-p2p/) చూడండి.
