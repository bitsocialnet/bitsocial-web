# React Hooks

`@bitsocial/bitsocial-react-hooks` React యాప్‌లకు Bitsocial ప్రోటోకాల్ కోసం హుక్స్ APIని అందిస్తుంది: ఫీడ్‌లు, వ్యాఖ్యలు, కమ్యూనిటీలు, రచయిత ప్రొఫైల్‌లు, ఖాతాలు మరియు ప్రచురణ, ఇవన్నీ ఏ కేంద్రీయ సర్వర్ లేకుండానే. [5chan](/apps/5chan/) మరియు [Seedit](/apps/seedit/) దీనిపైనే నిర్మించబడ్డాయి.

ఈ లైబ్రరీకి ప్రతి విడుదలతో నవీకరించబడే సొంత డాక్యుమెంటేషన్ సైట్ ఉంది: **[hooks.bitsocial.net](https://hooks.bitsocial.net/)**.

## ఇన్‌స్టాలేషన్

```bash
npm install @bitsocial/bitsocial-react-hooks
```

ఈ ప్యాకేజీ React 16.8 మరియు ఆ తర్వాతి వెర్షన్‌లకు మద్దతు ఇస్తుంది.

## ఎక్కడ ప్రారంభించాలి

- [త్వరిత ప్రారంభం](https://hooks.bitsocial.net/docs/quickstart/): మీ మొదటి కమ్యూనిటీ ఫీడ్‌ను రెండర్ చేయండి.
- [భావనలు](https://hooks.bitsocial.net/docs/concepts/): ఫీడ్‌లు, స్థానిక ఖాతాలు, భాగస్వామ్య స్థితి మరియు ప్రచురణ ఒకదానితో ఒకటి ఎలా కలిసి పనిచేస్తాయి.
- [API సూచన](https://hooks.bitsocial.net/docs/api/feeds-hooks/): ప్రతి హుక్, దాని ఎంపికలు మరియు రిటర్న్ విలువలతో సహా.
- [ప్లేగ్రౌండ్](https://hooks.bitsocial.net/#playground): అనుకరణ కంటెంట్‌పై నడిచే లైవ్ ఉదాహరణలను సవరించండి.
- [AIతో నిర్మించండి](https://hooks.bitsocial.net/docs/ai/): కోడింగ్ ఏజెంట్‌ల కోసం `llms.txt` మరియు ప్రతి పేజీకి Markdown వెర్షన్‌లు.
