# Bitsocial Chain

Bitsocial Chain は、Bitsocial アプリのために提案されている Ethereum L2 appchain の経済レイヤーです。
チェーン専用の現行サイトは [chain.bitsocial.net](https://chain.bitsocial.net) です。

ピアツーピアのソーシャル層があることで、コミュニティ、アイデンティティ、コンテンツは中央のプラット
フォームのデータベースの外へ出られます。Bitsocial Chain が足そうとしているのは、そうしたアプリを
資金面で干上がらせにくくする、共有の命名・収益化・決済のプリミティブです。

## 何を支えるためのものか

- `.bso` のような分散型 Bitsocial ドメイン
- アワードと投げ銭
- 持続する収益化のレール
- アプリをまたぐ共有の流動性
- 銀行やプラットフォームが締め上げにくい金融の仕組み
- スタック全体を 1 社が所有することに依存しないネットワーク効果

前面に出したいのはトークンの仕組みではありません。有用なソーシャルアプリをより長続きさせ、より資金を
集めやすくし、中央集権的な決済事業者や命名事業者への依存を減らすことが目的です。

## 現在の概念実証

Bitsocial Chain の最初の概念実証は、ネイティブな `.bso` の名前に絞っています。ソーシャルコンテンツを
オンチェーンに置かないまま、Ethereum L1 の履歴から名前レジストリを導出できることを示すものです。

- 利用者は登録・更新・移転・失効の意図を、通常の Ethereum L1 トランザクションとして送ります
- 誰でも導出ノードを動かして、同じ `.bso` レジストリの状態を再構築できます
- リゾルバーが `.bso` の名前を、クライアントがピアツーピアプロトコル上ですでに使っている Bitsocial の
  公開鍵へ対応づけます
- 投稿、投票、モデレーション、フィード、コミュニティのコンテンツはオフチェーンかつピアツーピアのまま
  です

この概念実証は、本番の Stage 2 ローンチではありません。証明システム、チャレンジゲーム、監査済みの
コード、本番デプロイ、最終的な価格設定、最終的なガバナンスは、まだどれもありません。長期的な姿勢は、
既定で透明であり、設計上プライバシーと両立するというものです。コアのチェーンは公開ですが、将来の
投げ銭、決済、アワード、流動性については、ソーシャル上のアイデンティティとウォレットの履歴が恒久的に
結びつくことを強いるべきではありません。

## なぜ重要なのか

コミュニティとアイデンティティを分散化することは必要ですが、ソーシャルメディアのすべてを分散化するには
それだけでは足りません。

ソーシャルアプリが少数の中央集権的な経済レールに依存したままなら、圧力をかけられ、締め出され、資金面で
干上がらせられやすい状態が続きます。Bitsocial Chain は、この 2 つ目の依存の層に対する提案された答えです。

## アプリとの関係

Bitsocial Chain は Bitsocial アプリの下に位置するべきものであり、アプリを置き換えるものではありません。

利用者から見える結果は、次のようになるはずです。

- コミュニティはピアツーピアのままである
- アプリはそれぞれの持ち味を保つ
- 利用者は実用的な命名と収益化の機能を手にする
- クリエイターとコミュニティは、クライアントをまたいで支援を受け取れる
- 中央集権的なプラットフォーム所有者を作り直すことなく、エコシステム全体で価値が動く

## なぜ Twitter/X 代替の後に来るのか

現在のマスタープランでは、Bitsocial Chain を Twitter/X 代替の後に置いています。そのアプリはチェーンを必要としないからです。プロフィールはノンカストディアルな RPC を通じてプロフィールノードとして動作し、`.bso` 名は Ethereum メインネット上の暫定レジストリ（[BSIP-13](https://bsips.bitsocial.net/bsip-13)）から始めて、後でチェーンに移行できます。

Bitsocial Chain は、早くローンチするために分散性を犠牲にすべきではありません。Ethereum そのもの以上の信頼の前提を加えるべきではなく、アップグレードキーも、セキュリティカウンシルも、検閲や停止ができるオペレーターも置きません。そのための有力な設計であるネイティブロールアップは、まだ日程の決まっていない Ethereum のアップグレードに依存しています。チェーンがその基準を満たせるようになるまで、Twitter/X 代替がチェーンの利用者となるユーザー基盤を育てます。

## 設計原則

Bitsocial Chain は立ち上がった製品ではなく、まだ提案段階のインフラであるため、計画は節度を保つべきです。

- アプリとコミュニティが先。ネットワーク層は、実在するソーシャル製品をより強くするものであるべきです。
- 実用的な機能が先。名前、アワード、投げ銭、決済は、抽象的な金融アーキテクチャよりも説明しやすいもの
  です。
- 誇大宣伝よりも実際の貢献を。経済のプリミティブは、参加、構築、コミュニティへの支援に報いるべきです。
- キュレーションは認められます。アプリはランキング、既定値、発見性を調整して、持続するコミュニティを
  優先できます。
- 正確な仕組みはまだ未確定です。このページは Bitsocial Chain の役割を説明するものであり、最終的な
  経済設計についての確定した約束ではありません。
