# 長時間にわたるエージェント作業

作業の再開や引き継ぎが必要な場合、または 1 回の実行が長く、コンテキストの圧縮によって残りの作業を見失うおそれがある場合は、永続的なタスク状態を使います。小さなタスクにはボードも進捗ファイルも不要です。共有する作業では、タスク専用の `docs/agent-runs/<slug>/` に簡潔な `feature-list.json` と `progress.md` を置き、役立つ場合は既存のテンプレートを使います。

求められている成果、現在のブランチとワークツリー、ファイルの担当、完了した変更、実行したチェックとその結果、所有しているプロセスとセッション、次に取り組む未解決のステップを記録します。認証情報や無差別なソースのダンプは保存しないでください。機能を完了とマークするのは、その受け入れ基準が検証されたときだけです。

再開時は、編集の前に Git の状態、最新の進捗、関連するソースを確認します。互換性のある所有済みのリソースは再利用し、開発サーバーは次のチェックで必要な場合にだけ起動します。何も変わっていないフルパスを繰り返すのではなく、[verification.md](https://github.com/bitsocialnet/bitsocial-web/blob/master/docs/agent-playbooks/verification.md) に従って影響に応じたチェックを選んでください。

関連する委任作業は、範囲を限定し、互いに重ならないようにします。重いチェックとブラウザセッションは 1 つのエージェントが担当します。完了したスライス、ブロッカー、引き継ぎによって次の担当者が知るべきことが変わったときに永続的な状態を更新し、すべてのコマンドを機械的に記録することはしないでください。
