# Bitsocial と Urbit

[Urbit](https://urbit.org/) は個人サーバーのネットワークです。各利用者は船と呼ばれる常時稼働のコンピューターを持ちます。船は Urbit 独自の言語 (Nock と Hoon) で書かれた Urbit 独自のオペレーティングシステム (Arvo) を動かし、Urbit ID によって識別されます。主なソーシャルアプリは [Tlon Messenger](https://tlon.io/) で、Urbit を開発するために 2013 年に設立された企業 Tlon が作っています。

Urbit はコンピューティングスタック全体を置き換えることを目指しているため、Bitsocial よりはるかに広範なプロジェクトです。それでも、そのソーシャル層は Bitsocial に近いモデルを採用しています。コミュニティは所有者のノード上に存在し、何を受け入れるかはそのノードが決めます。両者が異なるのは、誰がサーバーを動かさなければならないかと、スパムをどう締め出すかです。

## Urbit の仕組み

- **Urbit ID。** すべての船は Urbit ID を持ちます。これは `~sampel-palnet` のような発音できる名前として表示される数値です。レイヤー 1 の ID は NFT で、その所有権とネットワーク用の公開鍵は Ethereum 上の Azimuth コントラクトに記録されます。手数料を下げるために 2021 年に追加されたレイヤー 2 の ID は「ナイーブロールアップ」を使います。そのトランザクションはまとめて Ethereum に投稿されますが、所有権は Azimuth コントラクトには保存されず、各船がローカルで計算します。[Urbit ID のドキュメント](https://docs.urbit.org/urbit-id/what-is-urbit-id) と [Get on Urbit](https://docs.urbit.org/get-on-urbit) によれば、Tlon は誰でも無料で使える roller を運用しています。
- **固定された階層。** アドレス空間には 256 の銀河、65,536 の恒星、そして日常的に使う約 40 億の惑星があります。銀河は恒星を発行し、恒星は惑星を発行し、各惑星は自分のデバイス用に衛星を発行できます。彗星は、船が自分自身のために生成する無料の ID で、ブロックチェーンには一切記録されません。銀河の所有者は Galactic Senate を構成し、Galactic Senate は Azimuth コントラクトのアップグレードについて投票し、Urbit Foundation の理事会を選出します。
- **ネットワーク。** 船同士は暗号化されたパケットをピアツーピアでやり取りします。2026 年 7 月以降、ネットワークプロトコルは [Directed Messaging](https://urbit.org/blog/directed-messaging) になっています。これは旧来の Ames プロトコルをコンテンツ中心に書き直したものです。[Directed Messaging の論文](https://urbitsystems.tech/article/v03-i01/directed-messaging) によれば、ピアの発見は銀河が担います。各銀河は配下の船がどこにいるかを把握し、2 つの船が直接通信できるようになるまで、あるいはファイアウォールがそれを妨げている間はずっと、それらの船にパケットを中継します。
- **グループ。** Tlon Messenger では、グループは作成者の船がホストします。[Tlon の FAQ](https://tlon.io/posts/faq) によれば、メンバーはホストにメッセージを送り、ホストがそれを各メンバーの船に配布し、各メンバーの船はそれぞれ自分のコピーを保持します。ホストはロール、チャンネル、参加を管理します。グループは公開、非公開、秘密のいずれかにでき、[個々の船や ID の階級全体をアクセス禁止にできます](https://github.com/tloncorp/tlon-apps/blob/develop/desk/sur/groups.hoon)。チャンネルはチャット、ノートブック、または画像やリンクのコレクションです。
- **ホスティング。** Tlon でサインアップすると、新しい利用者には Tlon が運用する船が与えられ、その鍵は Tlon が預かります。利用者は船とそのマスターチケット (master ticket) をエクスポートして、別の場所で動かすことができます。たとえば [Native Planet](https://www.nativeplanet.io/) のデバイス上や、Linux、macOS、Windows 上の Vere ランタイムです。船はまだ大きなファイルを直接保存できないため、Tlon Messenger は画像などのメディアを S3 互換のクラウドストレージに置きます。

## どこが違うのか

### 誰がサーバーを動かさなければならないか

Urbit では、すべての参加者がサーバーです。Tlon のアプリは利用者自身の船のフロントエンドであり、グループを読むことさえ船を経由します。自分で船を動かさない人は船を借りることになり、そこでホスティング事業者が再び登場します。Tlon はホストしている利用者の鍵を保持し、保守のために限定的なアクセスを維持していますが、利用者は船を丸ごと持って移ることができます。

Bitsocial では、常時稼働のノードが必要なのはコミュニティ所有者だけです。読む人や投稿する人はブラウザタブの中でピアツーピアノードを動かすことができ、そのアカウントはアプリが保持する鍵ペアです。[ブラウザ ピアツーピア](/browser-p2p/) を参照してください。それでもホストされたノードを使う場合、Bitsocial の設計は、アイデンティティの管理権を手放すことなく稼働の維持だけを委任できるようにすることを目指しています。[アイデンティティとコミュニティの所有権](/identity-and-ownership/) を参照してください。

### コミュニティのホスト

両者が最も近いのはここです。Tlon のグループも Bitsocial のコミュニティも、所有者のノード上に存在します。誰が投稿できるかを決め、モデレーションを適用し、その結果を配布するのはホストであり、どちらのプロトコルもホストの上にモデレーターを置きません。どちらでもホストはオンラインである必要があります。Tlon の FAQ には、ホストがオフラインになると「グループもホストと一緒にダウンする」とあり、Bitsocial のコミュニティもノードがオフラインの間は新しい投稿を受理できません。

両者はコンテンツの保存方法が異なります。各メンバーの船はグループの履歴のコピーを保持するため、ホストが停止している間も、メンバーはすでに受け取った内容を読めます。Bitsocial の読者は、コミュニティの最新の状態をコミュニティのノードか、そのコミュニティをシードするピアから取得するため、オフラインのコミュニティもピアが持っている間は読めますが、ネットワークが保持するのは最新の状態だけです。

Tlon のグループにはメンバーリストもあり、ホストはグループを招待制にできます。Bitsocial のコミュニティにはメンバーシップがありません。誰でも読むことができ、誰でもそのチャレンジを条件に投稿を試みることができます。

### スパムとアイデンティティ

Urbit は、アイデンティティを希少にすることでスパムと戦います。惑星の数は固定されており、どの惑星も恒星が発行します。無料の彗星はこの希少性をすり抜けるため、希少性を保ちたいグループは彗星を締め出します。Urbit のドキュメントには一部のグループが彗星を受け入れないと書かれており、Tlon のグループは 1 つの設定で彗星の階級全体をアクセス禁止にできます。彗星が締め出されていれば、アクセス禁止になった利用者が戻ってくるには、恒星の所有者から別の惑星を手に入れる必要があります。評判も階層に沿って機能し得ます。Azimuth には Censures コントラクトがあり、銀河と恒星は ID にフラグを付けられます。希少性はアドレス空間に組み込まれているため、彗星を締め出すどのグループでも同じように機能します。

Bitsocial のアイデンティティは無料の鍵ペアです。各コミュニティは、投稿を受理する前に課す独自のチャレンジを選びます。たとえば CAPTCHA、支払い、トークン残高、許可リストなどで、ほかのコミュニティは別のものを選べます。[カスタムのスパム対策チャレンジ](/custom-challenges/) を参照してください。

### ブロックチェーンとガバナンス

Urbit のアイデンティティ層は Ethereum に依存しています。Azimuth コントラクトはレイヤー 1 の所有権とネットワーク用の鍵を記録し、レイヤー 2 のトランザクションはまとめて Ethereum に投稿され、Galactic Senate は Azimuth を管理するコントラクトをアップグレードできます。同じ 256 の銀河がピアの発見と中継も担うため、固定されたアイデンティティの集合が、ガバナンスとネットワークのルーティングの一部の両方を担っています。

Bitsocial のアイデンティティは、登録を必要としない鍵ペアです。`.bso` 名と `.eth` 名は、その鍵ペアに解決される任意のエイリアスです。ピアの発見は、プロバイダーのアドレスを返すだけの HTTP ルーターを通じて行われます。ルーターは誰でも運用でき、クライアントは設定を変えるだけでルーターを切り替えられます。

### 対象範囲

Urbit は汎用コンピューターです。船は Git のリモート、個人用のナレッジベース、AI エージェントをホストでき、Tlon Messenger は数あるプログラムの 1 つにすぎません。Urbit 向けの開発とは、主に Arvo 用の Hoon アプリを書くことを意味します。Bitsocial は公開コミュニティのためのプロトコルで、[5chan](/apps/5chan/) や [Seedit](/apps/seedit/) などのアプリがあります。既存のスタック (libp2p、IPFS、ブラウザ) を置き換えるのではなくその上で動作し、クライアントは一般的な Web ツールで作られます。[独自のクライアントを作る](/build-your-own-client/) を参照してください。

### プライベートメッセージ

ここは Urbit のほうが優れています。ダイレクトメッセージは船から船へ直接届き、船同士の通信はすべて暗号化され、グループは非公開や秘密にできます。Tlon によれば、メッセージは転送中は暗号化されますが、船の上には暗号化されずに保存されます。Bitsocial は公開コミュニティに焦点を当てており、ネイティブのダイレクトメッセージはまだありません。

## プロジェクトの現状

Urbit は混乱を経験してきました。[CoinDesk の報道](https://www.coindesk.com/tech/2024/08/21/wartime-ceo-urbits-founder-returns-in-shakeup-at-moonshot-software-project) によれば、2024 年 8 月、コア開発を主導する非営利団体 Urbit Foundation はエグゼクティブディレクターを解任しました。創設者の Curtis Yarvin が正式な肩書きなしで戦略を率いるために復帰し、複数のコア開発者が去り、Foundation の資金はあと数か月分しか残っていませんでした。Yarvin は、Azimuth を既存の Ethereum レイヤー 2 (有力候補は Base) に移し、惑星に交換できる代替可能な「ビザ」トークンを発行することを提案しました。2026 年 10 月の時点でも、Urbit の [ID ドキュメント](https://docs.urbit.org/urbit-id/what-is-urbit-id) は依然として、ナイーブロールアップを備えた Ethereum 上の Azimuth を説明しています。2025 年 10 月には Galactic Senate が Foundation の理事会を入れ替え、新しい理事会が新たなエグゼクティブディレクターを任命しました ([発表](https://urbit.org/blog/2025-a-new-epoch-for-the-forever-computer))。

開発は続いています。Directed Messaging は 2026 年 7 月 14 日の 408k リリースで稼働を始めました。2026 年 6 月には Tlon Messenger が [ウェイトリストなしで一般登録を開始](https://urbit.org/blog/this-month-in-urbit-june-2026) し、Tlon は現在、人と AI エージェントが一緒に働く場として自らを打ち出しています。
