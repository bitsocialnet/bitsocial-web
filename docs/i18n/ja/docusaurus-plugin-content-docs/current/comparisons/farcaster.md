# Bitsocial と Farcaster

[Farcaster](https://docs.farcaster.xyz/) は、アイデンティティをブロックチェーン上に置き、ソーシャルデータはその外に置きます。アカウント、アプリキー、ストレージの支払いは、Ethereum のレイヤー 2 である OP Mainnet 上のコントラクトにあります。キャストと呼ばれる投稿は、フォローやリアクションと同様に署名付きのメッセージで、[Snapchain](https://snapchain.farcaster.xyz/) に保存されます。Snapchain はブロックチェーンに似たネットワークで、2025 年に Farcaster の以前の Hub ネットワークに取って代わりました。

## Farcaster の仕組み

- **アカウント。** アカウントは数値の Farcaster ID で、Ethereum アドレスが所有します。そのアドレスは復旧用アドレスを設定することもできます。アプリはオンチェーンに登録された委任アプリキーで投稿します。アプリキーでアカウントを乗っ取ることはできません。
- **ストレージ賃料。** すべてのアカウントはストレージユニットを借ります。料金は現在、1 ユニットあたり年 0.20 ドルです。2025 年 7 月以降に借りたユニットには 100 件のキャストが入り、それを超えると古いキャストから削除されます。レート制限は借りたストレージの量に応じて大きくなります。
- **Snapchain。** バリデーターは Tendermint 型のコンセンサスでメッセージをブロックに並べ、すべてのフルノードがネットワーク全体のデータを保持します。[ノードガイド](https://snapchain.farcaster.xyz/getting-started) によれば、ノードには約 16 GB の RAM と 2 TB のストレージが必要です。
- **名前。** fname と呼ばれるデフォルトのユーザー名は無料で、Farcaster 自身のネームサーバーが発行し、そのサーバーは [fname を取り消せます](https://docs.farcaster.xyz/learn/what-is-farcaster/usernames)。代わりに、Ethereum 上で登録した `.eth` 名を使うこともできます。
- **チャンネル。** トピック別のチャンネルは、Farcaster クライアントの実験的な機能です。チャンネル内のキャストはプロトコルのデータですが、チャンネルのメタデータ、フォロー、モデレーションは [クライアントに保存されます](https://docs.farcaster.xyz/learn/what-is-farcaster/channels)。
- **読み取り。** アプリは、自分で運用する Snapchain ノードか、マネージドプロバイダー (通常は Neynar) を通じて読み取ります。

## どこが違うのか

### ブロックチェーンとバリデーター

Farcaster は、アカウントと支払いを OP Mainnet に、すべてのソーシャルデータの順序付けをブロックチェーンに似たネットワークである Snapchain に依存しています。Snapchain のバリデーターセットは許可制です。ホワイトペーパーは、世界中に分散した約 10 のバリデーターがあれば検閲は難しくなると述べていますが、2026 年 10 月の時点で [バリデーター一覧](https://snapchain.farcaster.xyz/validators) はそれより少なく、鍵の大半は Neynar のものでした。Neynar は 2026 年 1 月に [Farcaster を買収](https://neynar.com/blog/neynar-is-acquiring-farcaster) しています。Bitsocial には、チェーンもバリデーターもコンセンサスもありません。

### 投稿にお金を払う

Farcaster のすべてのアカウントはストレージ賃料を払い、ネットワークがアカウントの履歴をどれだけ保持するかはストレージで上限が決まります。Bitsocial では、プロトコルのレベルで投稿に費用はかかりません。CAPTCHA、支払い、トークン、その他何を求めるかは、各コミュニティが決めます。[カスタムのスパム対策チャレンジ](/custom-challenges/) を参照してください。

### コミュニティ

Farcaster のチャンネルはクライアントの機能です。クライアントがメタデータを保存し、チャンネルのモデレーションを実施するので、あるチャンネルでブロックされたキャストも、ネットワーク上では有効なまま他のアプリで表示されることがあります。Bitsocial では、コミュニティは独自の鍵ペアを持つプロトコルのオブジェクトであり、コミュニティのノードが投稿を受理または拒否します。

### インフラの運用

Farcaster のノードはネットワーク全体を保持するため、ストレージはすべてのアクティビティとともに増えていきます。Farcaster は、その増加がいずれ最大級のクラウドディスクに迫ると見込んでいます。Bitsocial のコミュニティノードは自分のコミュニティだけを保持し、一般向けのハードウェアで動きます。

### ブラウザ

Farcaster のブラウザアプリは、ノードやプロバイダーの HTTP クライアントです。Bitsocial の Web アプリは、タブの中でピアツーピアノードを動かせます。[ブラウザ ピアツーピア](/browser-p2p/) を参照してください。

## 比較

| 論点                 | Farcaster                                                                                 | Bitsocial                                                                                    |
| -------------------- | ----------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 分類                 | オンチェーンのアイデンティティと、バリデーターが順序付けるソーシャルデータ                | ピアツーピアのコミュニティネットワーク                                                       |
| アイデンティティ     | Ethereum アドレスが所有する Farcaster ID と、委任されたアプリキー                         | 利用者とコミュニティの Ed25519 鍵ペア                                                        |
| 投稿の保存場所       | Snapchain。すべてのフルノードに複製され、支払ったストレージの範囲内で保持                 | コミュニティ所有者のノードと、そのコミュニティを読んでシードするピア                         |
| 誰が公開を維持するか | Snapchain のバリデーターとノード運用者                                                    | コミュニティ所有者のノードと補助のシーダー                                                   |
| コミュニティ         | Farcaster クライアントが管理する実験的なチャンネル                                        | 自身のノードが投稿を受理または拒否する第一級のオブジェクト                                   |
| スパム対策           | ストレージ賃料とレート制限、およびアプリ単位のスパムラベル                                | 投稿が受理される前に課される、各コミュニティのチャレンジ                                     |
| モデレーション       | クライアント内のチャンネルホスト、アプリのフィルター、バリデーターレベルでの検閲リスク    | コミュニティ所有者が自分のコミュニティをモデレートし、何を表示するかはアプリが選ぶ           |
| 名前                 | Farcaster が取り消せる無料の fname、または `.eth` 名                                      | 鍵に解決される `.bso` と `.eth` の名前                                                       |
| ブラウザ             | ノードやプロバイダーの HTTP クライアント                                                  | 通常のブラウザタブ内で動くピアツーピアノード                                                 |
| 主なトレードオフ     | 一貫した 1 つのグローバルなデータセットがあるが、賃料、チェーン、少数のバリデーターが伴う | 手数料もチェーンもないが、グローバルなデータセットはなく、古いコンテンツが永続する保証もない |
