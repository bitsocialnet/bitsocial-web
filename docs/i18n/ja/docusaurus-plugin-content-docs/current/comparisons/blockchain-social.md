# Bitsocial とブロックチェーン型ソーシャルネットワーク

Lens、DeSo、Steem は、いずれもソーシャルな活動をブロックチェーンに載せています。アカウント、フォロー、投稿、あるいはそれらを取り巻くルールが、バリデーターが順序付けて保存するトランザクションになります。Bitsocial はブロックチェーンを使いません。ソーシャルメディアにはすべての投稿のグローバルな順序は必要ないため、Bitsocial はコンセンサスもガスもステーキングも省いています。その理由については [ピアツーピアプロトコル](/peer-to-peer-protocol/) を参照してください。

## 共通点

- **書き込みのたびに誰かが支払う。** Lens はガスを課し、アプリがそれを肩代わりできます。DeSo はすべての操作に手数料を課し、Steem はステークされたトークンに応じて操作を割り当てます。
- **チェーンが全員に 1 つのスパム対策方針を課す。** 手数料、ステーク、アカウント費用は、各コミュニティが選ぶのではなく、ネットワーク全体に適用されます。
- **オンチェーンの記録は恒久的。** アプリはコンテンツを非表示にできますが、チェーンから削除することはできません。
- **ブラウザは API クライアント。** Web アプリはトランザクションに署名し、他者が運用するノード、インデクサー、API を通じて読み取ります。

## Lens

[Lens](https://lens.xyz/) は Lens Chain 上で動いています。Lens Chain は ZKsync の ZK Stack で構築された Ethereum のレイヤー 2 で、データ可用性に Avail を使います。Mask Network は [2026 年 1 月から Lens の運営を担っています](https://lens.xyz/news/mask-network-to-steward-the-next-chapter-of-lens)。

- **チェーン上:** アカウントはスマートコントラクトで、ユーザー名はネームスペース内の NFT です。グラフ、グループ、フィードとそのルールもコントラクトです。
- **チェーン外:** 投稿のテキストとメディアは URI 上の JSON ファイルにあり、通常は IPFS の前段に置かれた Lens のストレージサービスである Grove に保存されます。リアクションとブックマークは Lens API が保持し、アプリはその API を通じて読み取ります。
- **スパムと関門:** トランザクションには GHO 建てのガスが必要で、アプリはレート制限付きでそれを肩代わりできます。フィードやグループのルールで、トークンの保有や支払いを条件にすることもできます。
- **チェーンの運用:** [L2BEAT](https://l2beat.com/scaling/projects/lens) は Lens Chain を Stage 0 の validium と評価しており、中央集権的なオペレーターがトランザクションの取り込みを拒否できるとしています。

## DeSo

[DeSo](https://docs.deso.org/) は、ソーシャルアプリ向けに作られたレイヤー 1 のブロックチェーンです。2024 年 7 月にプルーフオブワークからプルーフオブステークへ移行しました。

- **チェーン上:** プロフィール、投稿、いいね、フォロー、ダイレクトメッセージはすべてトランザクションで、すべてのフルノードが保存します。画像と動画はチェーン外でホストされ、リファレンスノードは Google Cloud Storage と Cloudflare Stream を使っています。
- **スパム:** すべての操作に DESO 建ての手数料がかかります。新規利用者は通常、電話番号の認証後にノードからスターター用の DESO を受け取ります。
- **モデレーション:** 各ノードはブラックリストやグレーリストで何を表示するかを決めますが、[コンテンツはチェーン上に残ります](https://docs.deso.org/deso-blockchain/content-moderation)。
- **コミュニティ:** ドキュメントにはコミュニティやフォーラムのプリミティブの記述がなく、「コミュニティ」とはアプリがキュレーションするフィードのことです。
- **ノードの運用:** [バリデーターガイド](https://docs.deso.org/deso-validators/run-a-validator) によれば、バリデーターには少なくとも 32 GB の RAM と 200 GB のディスクが必要です。

## Steem

[Steem](https://steem.com/) は、投稿者とキュレーターにトークンで報酬を支払うソーシャルブロックチェーンで、主なブログアプリは [Steemit](https://steemit.com/) です。2020 年に Hive が Steem から分裂しました。[Hive のホワイトペーパー](https://hive.io/whitepaper.pdf) によれば、このフォークは Steemit Inc. が Justin Sun に売却されたことを受けたものです。

- **チェーン上:** テキストの投稿、コメント、投票とその編集履歴。選出された 21 のウィットネスが 3 秒ごとにブロックを生成して順序付けます。画像はチェーン外でホストされます。
- **スパム:** 操作は Resource Credits を消費し、Resource Credits はステークした STEEM に応じて増えます。アカウントの作成には STEEM がかかり、メールアドレスと電話番号を認証した利用者の分は Steemit が負担します。
- **コミュニティ:** コミュニティは、コンセンサスの外で [インデクサーが解釈するカスタムオペレーション](https://github.com/steemit/hivemind/blob/master/docs/communities.md) です。モデレーターは投稿をミュートでき、そうするとアプリでは非表示になりますが、チェーン上には残ります。
- **報酬:** 報酬の原資はインフレーションで、ステークで重み付けされた投票が配分を決めます。そのため、大口保有者が何に注目が集まるかを左右します。

## 比較

| 論点             | Lens                                                                                   | DeSo                                                               | Steem                                                                      | Bitsocial                                                                            |
| ---------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------ | -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| チェーン         | Ethereum のレイヤー 2 (ZK Stack の validium)                                           | 独自のレイヤー 1、プルーフオブステーク                             | 独自のチェーン、委任型プルーフオブステーク                                 | なし                                                                                 |
| 投稿のコンテンツ | チェーン外の JSON。通常は Grove 上                                                     | テキストはチェーン上、メディアはチェーン外                         | テキストはチェーン上、画像はチェーン外                                     | コミュニティ所有者のノードと、そのコミュニティを読んでシードするピア上               |
| アイデンティティ | スマートコントラクトのアカウント、ユーザー名の NFT                                     | オンチェーンのプロフィールを持つ鍵ペア                             | 階層化された鍵を持つ、名前付きのチェーンアカウント                         | 利用者とコミュニティの Ed25519 鍵ペア                                                |
| コミュニティ     | ルール付きのコントラクトとしてのグループとフィード                                     | コミュニティのプリミティブはない                                   | コンセンサスの外でインデクサーが解釈するコミュニティ                       | 自身のノードが投稿を受理または拒否する第一級のオブジェクト                           |
| スパム対策       | ガス (多くは肩代わり)、トークンや支払いのルール                                        | すべての操作に手数料、電話番号の確認後にスターター資金             | ステークに基づく Resource Credits、有料のアカウント作成                    | 投稿が受理される前に課される、各コミュニティのチャレンジ                             |
| モデレーション   | グループ管理者、オンチェーンのルール、API レベルでの非表示                             | 各ノードが表示内容をフィルタリング                                 | コミュニティのミュート、ステークで重み付けされた低評価、アプリのフィルター | コミュニティ所有者が自分のコミュニティをモデレートし、何を表示するかはアプリが選ぶ   |
| 運用             | チェーンのオペレーターに加え、Lens API と Grove                                        | 少なくとも 32 GB の RAM を備えたバリデーター                       | 選出されたウィットネスに加え、API ノードとインデクサーノード               | 一般向けのハードウェアで動くコミュニティノードと補助のシーダー                       |
| 主なトレードオフ | オンチェーンのルールをプログラムできるが、コンテンツと読み取りは Lens のサービスに依存 | 開かれたデータプールだが、すべての操作に手数料がかかり、永久に残る | 報酬が組み込まれているが、ステークが可視性とガバナンスを左右               | 手数料もステークもないが、グローバルな順序はなく、古いコンテンツが永続する保証もない |
