# 投稿はどこにあり、いつまで残るのか

Bitsocialは全投稿をブロックチェーンや企業データベースに保存しません。各コミュニティのノードが投稿を
保持し、読者とシーダーが配信を助け、永久記録を望む人は保存できます。永久保存は**任意であり、必須では
ありません**。プロトコルは全参加者にネットワーク全体の履歴を保存するよう強制しません。

実際の意味を説明します。「永久に保存されない」は、「消える」または「私を信じて」と誤解されやすいからです。

## 真正性と可用性は別の問題です

投稿には2つの問いがあります。

1. **本物か？** この著者が書き、このコミュニティが受理したか？
2. **まだオンラインか？** 今日、誰かが取得できるか？

Bitsocialは最初の問いに信頼でなく暗号技術で答えます。全投稿は著者の鍵ペアで署名され、受理後は、
正確なバイト列のハッシュであるコンテンツ識別子(CID)下に保存されます。取得者は署名とハッシュを自ら
検証できます。ノード、ルーター、ゲートウェイ、アーカイブは、検証を失敗させずに投稿本文を変えたり、
他人の投稿を偽造したりできません。

2つ目は誰がコピーを保持するかで、保証されないのはここだけです。

## 投稿をオンラインに保つ人

- **コミュニティのノード。** 所有者のノードが投稿を受理し、コミュニティが保持する限りデータベースに
  保存します。コミュニティが稼働中に常に存在する1つのコピーです。
  [ピアツーピアプロトコル](/peer-to-peer-protocol/)を参照してください。
- **読者。** 5chan Electronアプリなどは、実行中に読み込んだコミュニティをシードします。人気のコミュニティは
  人気のtorrent同様、多くのピアから配信されます。ブラウザタブは開いている間、コンテンツをキャッシュ・
  検証できますが、長期ホストではありません。
- **シーダー。** [`bitsocial-seeder`](https://github.com/bitsocialnet/bitsocial-seeder)により、誰でもVPSや
  予備マシンから常時容量を提供できます。最新ページと投稿更新をピン留めするため、家庭用ルーターの背後の
  コミュニティもブラウザから読み込めます。
- **アーカイバー。** 誰でもコミュニティをクロールし、見たものをすべて保存できます。アーカイブはネット
  ワーク上の通常のサービスで、プロトコルの特別な役割ではありません。

## コミュニティは独自の保持期間を選びます

古い投稿の保持期間は、プロトコル規則でなく所有者が決めます。何年分もの履歴を望むコミュニティもあります。
ほかは忘れるよう設計されています。5chanの掲示板はimageboardのように、スレッドが掲示板から落ち、
アーカイブへ移り、所定時間(既定48時間)後に掲示板ノードから削除されます。アーカイブを完全に省くことも
できます。

同じプロトコルが両方を支えるのは、保持が各コミュニティのポリシーであり、全ノードの負担ではないからです。

## なぜすべてを永久保存しないのですか？

全投稿の永久保持を全ノードに求めるネットワークは、何らかの形で支払わねばなりません。

- **ブロックチェーン**は全フルノードに履歴全体を保存させるため、要件は活動とともに増え、投稿には通常
  手数料がかかります。
- **有料ストレージ**は、Farcasterのストレージレンタルのように、履歴保持の費用を利用者に求め、支払った
  範囲を超える最古の投稿を削除します。[BitsocialとFarcaster](/comparisons/farcaster/)を参照してください。
- **中央サーバー**はすべてを保持しますが、1社が望む間だけで、その会社の規則に従います。

ソーシャルメディアにグローバル台帳は不要です。投稿Aが投稿Bより1ミリ秒前に受理されたかは重要でなく、
大半の古い投稿はめったに読まれません。Bitsocialは、各コミュニティノードが自身のコミュニティだけを保持
できるため、ノートパソコン、Raspberry Pi、小さなVPSでも安くホストできます。
[なぜブロックチェーンではないのか？](/peer-to-peer-protocol/#why-not-a-blockchain)

## トレードオフ

コピーがなければ投稿は利用不能になり得ます。CIDは不変ですが単なるアドレスです。
コンテンツは、少なくとも1ノードが配信中の間だけ取得できます。コミュニティノードが完全にオフラインに
なり、読者、シーダー、アーカイブのいずれも投稿を保持していなければ、投稿は失われます。

これはグローバル台帳を求めない正直なコストです。主要プラットフォームもすでに負っています。アカウント、
サーバー、企業が消えれば、そこから古い投稿は消えます。違いは、Bitsocialで何かを保持するのに誰かの許可を
要さないことです。

## 大切なものを残す

- **コミュニティノードを自分で動かす。** ノードを稼働させ続ける所有者は、コミュニティ設定が保持する限り、
  そのコミュニティの履歴を保ちます。
- **シードする。** デスクトップアプリを開いたままにするか、`bitsocial-seeder`を実行すると、コミュニティを
  他の人が利用できる状態に保てます。
- **アーカイブする。** 独立したアーカイブは、コミュニティが古いスレッドを手放した後も、読めて検索できる
  状態に保ちます。[5archive.org](https://5archive.org)は5chanの掲示板を、
  [seeditarchive.org](https://seeditarchive.org)はSeeditコミュニティをアーカイブします。どちらもオープン
  ソースなので、誰でもミラーや競合アーカイブを運用できます。

アーカイブ済みの投稿にも署名が残るため、アーカイブが誰かの発言を気付かれずに書き換えることはできません。
読者はアーカイブ投稿の署名を、ライブ投稿と同じ方法で検証できます。
