# React Hooks

`@bitsocial/bitsocial-react-hooks` は、Bitsocial プロトコル向けのフック API を React アプリに提供します。フィード、コメント、コミュニティ、投稿者プロフィール、アカウント、投稿を、中央サーバーなしで扱えます。[5chan](/apps/5chan/) と [Seedit](/apps/seedit/) はこのライブラリの上に構築されています。

このライブラリには専用のドキュメントサイト **[hooks.bitsocial.net](https://hooks.bitsocial.net/)** があり、リリースごとに更新されています。

## インストール

```bash
npm install @bitsocial/bitsocial-react-hooks
```

このパッケージは React 16.8 以降に対応しています。

## どこから始めるか

- [クイックスタート](https://hooks.bitsocial.net/docs/quickstart/): 最初のコミュニティフィードをレンダリングします。
- [コンセプト](https://hooks.bitsocial.net/docs/concepts/): フィード、ローカルアカウント、共有状態、投稿がどのように連携するかを説明します。
- [API リファレンス](https://hooks.bitsocial.net/docs/api/feeds-hooks/): すべてのフックのオプションと戻り値を掲載しています。
- [プレイグラウンド](https://hooks.bitsocial.net/#playground): シミュレートされたコンテンツで動くライブサンプルを編集できます。
- [AI で開発する](https://hooks.bitsocial.net/docs/ai/): コーディングエージェント向けに、`llms.txt` と全ページの Markdown 版を用意しています。
