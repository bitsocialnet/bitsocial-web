# 5chan

5chan は、Bitsocial プロトコル上で動作する、サーバーレスで管理者を置かない、完全に分散化されたイメージボードです。おなじみのイメージボードのディレクトリ構造を踏襲しながら、分散型の所有という仕組みを持ち込んでいます。誰でも板を作成でき、複数の板が投票の仕組みを通じて同じディレクトリスロットを争えます。

## 板の仕組み

5chan は、古典的なディレクトリ構成 (`/b/`、`/g/` など) を使ってコンテンツを板に整理します。すべての板を中央の管理者が仕切る従来のイメージボードとは違い、5chan ではどのユーザーも自分の板を作成し、完全に所有できます。複数の板が同じディレクトリスロットを狙う場合は、その位置を争います。詳しくは[ディレクトリ](/directories/)を参照してください。

### 板を作成する

新しい板を作成するには、`bitsocial-cli` をピアツーピアノードとして実行する必要があります。これにより、板は中央サーバーに頼ることなく、分散した形でホストされます。

### ディレクトリの割り当て

各ディレクトリの候補となる板は、[bitsocialnet/lists](https://github.com/bitsocialnet/lists) リポジトリ内の `5chan-directories/5chan-<code>-directory.json` ファイルに掲載されており、板はそのファイルへのプルリクエストによってディレクトリに参加します。また 5chan は、[`@bitsocial/pubsub-voting`](https://github.com/bitsocialnet/pubsub-voting) を使ってディレクトリごとに投票コンテストを実施しています。5chan Pass の保有者は 1 人 1 票を持ち、まだリストにない板に投票すると、その板を候補として推薦したことになります。コンテストは現在 Base Sepolia テストネット上で行われており、集計結果は表示されますが、リストの順序は変わりません。

## 内部構造

5chan は内部的に、ネットワークとのやり取りに共通の Bitsocial プロトコルのクライアント層を使っています。
5chan.app のウェブアプリはデフォルトでブラウザ内に Helia ノードを動かすため、普通のタブがそのまま
ピアとしてネットワークに参加します。他のピアから板を読み込み、pubsub 経由で公開するので、コンテンツの
経路に中央集権的な IPFS ゲートウェイは入りません。それが何を伴い、ブラウザのノードにはまだ何ができないのかは、[ブラウザ ピアツーピア](/browser-p2p/) を参照してください。
