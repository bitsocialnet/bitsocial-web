# すべてのソーシャルメディアを分散化する

最終形はひとつのアプリではありません。プラットフォームによる所有をプロトコル上の競争に置き換えられる、
クライアント、ノード、サービス、コミュニティの市場です。

フェーズ 5 で Bitsocial は最初の優先カテゴリの先へ進み、できるかぎり多くのソーシャルの形式に
資金を出し始めます。

## まだ作られていないもの

最初の各フェーズは、効果がいちばん大きいカテゴリに集中します。イメージボード、フォーラム、公開 RPC、
Bitsocial Chain、プロフィールノード、フェーズ 3 の Twitter/X 代替、そしてそれらを取り巻く
サービス経済です。

そのあと、ネットワークはロングテールへ広がるべきです。

- ブログ用のクライアント
- クラウドファンディングのアプリ
- クリエイター向けの動画と、実用に耐える [YouTube の代替](https://github.com/bitsocialnet/wetube)
- クリエイターのコミュニティ
- ショート形式メディアの実験
- 地域や言語に特化したソーシャルアプリ
- 最初の 4 フェーズには小さすぎるニッチなクライアント
- 既存のコミュニティを運営しやすくするツール

これらのアプリはオープンソースでもかまいませんし、中央集権型のクライアントでもかまいません。
Bitsocial Forge が作るものもあれば、多くは独立した開発者が作るべきものです。

## 研究中のアイデア

これらのアイデアの一部には、すでにアイデア段階のリポジトリがあります。まだ何も実装されていません。各リポジトリは設計と未解決の問いをまとめており、開発者や出資者が引き継げるようにしています。

- [WeTube](https://github.com/bitsocialnet/wetube)：すべてのチャンネルが作成者の所有するコミュニティになる YouTube の代替。
- [GitCommons](https://github.com/bitsocialnet/gitcommons)：Bitsocial 上に構築する GitHub の代替に向けた調査とアーキテクチャ。
- [Infinipedia](https://github.com/bitsocialnet/infinipedia)：誰のものでもない百科事典。編集グループが競合するバージョンを公開し、読者が選びます。
- [Modelswarm](https://github.com/bitsocialnet/modelswarm)：ピアの群れがオープンウェイトの AI モデルを共有し、すべてのファイルを公開者の署名済みリリースと照合する Hugging Face の代替。

### 検討のうえ見送ったもの

- [Hopium](https://github.com/bitsocialnet/hopium)：ソーシャルトレーディング向けの Fomo の代替。2026年11月に見送り。理由はリポジトリに記録されています。

## 多くの作り手に資金を出す

目標は、新しいソーシャルクライアントが、プラットフォーム規模の勢いを得るより前の段階で
資金を調達できるようにすることです。

その手段には、直接の出資、助成金、コミュニティによる資金提供、成功した Bitsocial サービスからの収益、
あるいはどの開発者を支援すべきかを Bitsocial コミュニティ全体で決める分散型の助成プログラムなどが
含まれます。

大切なのは多元性です。ネットワークは多くの試みに資金を出すべきであり、ひとつの公式アプリが
あらゆるカテゴリを覆うのを待つべきではありません。

## 成功とはどういう状態か

ソーシャルメディアを差し替え可能な層に分解できたとき、Bitsocial は成功したと言えます。

- プロトコル
- コミュニティ
- アイデンティティ
- ホスティング
- 発見
- モデレーション
- 収益化
- アプリ

これらの層が差し替え可能になれば、プロダクトを成立させるためにどこか 1 社がソーシャルグラフ全体を
所有する必要はなくなります。

## 中心にある賭け

成熟した Bitsocial のエコシステムには、公開 RPC、セルフホストのノード、フィードアルゴリズムの市場、
メディアホスト、発見サービス、オープンソースのクライアント、商用のクライアント、コミュニティ資金による
実験が含まれるはずです。

こうしてソーシャルメディアはようやく落ち着くべきところに落ち着きます。誰のものでもない、完全に分散化された
ピアツーピアのソーシャルネットワーク、それが Bitsocial です。
