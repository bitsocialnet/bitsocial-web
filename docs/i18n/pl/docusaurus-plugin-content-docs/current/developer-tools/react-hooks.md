# React Hooks

`@bitsocial/bitsocial-react-hooks` udostępnia aplikacjom React API hooków dla protokołu Bitsocial: kanały, komentarze, społeczności, profile autorów, konta i publikowanie, bez centralnego serwera. Na tej bibliotece zbudowane są [5chan](/apps/5chan/) i [Seedit](/apps/seedit/).

Biblioteka ma własną stronę z dokumentacją, aktualizowaną przy każdym wydaniu: **[hooks.bitsocial.net](https://hooks.bitsocial.net/)**.

## Instalacja

```bash
npm install @bitsocial/bitsocial-react-hooks
```

Pakiet obsługuje React 16.8 i nowsze wersje.

## Od czego zacząć

- [Szybki start](https://hooks.bitsocial.net/docs/quickstart/): wyrenderuj swój pierwszy kanał społeczności.
- [Koncepcje](https://hooks.bitsocial.net/docs/concepts/): jak kanały, konta lokalne, współdzielony stan i publikowanie łączą się w całość.
- [Referencja API](https://hooks.bitsocial.net/docs/api/feeds-hooks/): każdy hook wraz z opcjami i zwracanymi wartościami.
- [Playground](https://hooks.bitsocial.net/#playground): edytuj działające na żywo przykłady, które korzystają z symulowanych treści.
- [Budowanie z AI](https://hooks.bitsocial.net/docs/ai/): `llms.txt` oraz wersje Markdown każdej strony dla agentów programistycznych.
