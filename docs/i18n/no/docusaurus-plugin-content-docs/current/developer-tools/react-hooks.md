# React Hooks

`@bitsocial/bitsocial-react-hooks` gir React-apper et hooks-API for Bitsocial-protokollen: feeder, kommentarer, fellesskap, forfatterprofiler, kontoer og publisering, uten en sentral server. [5chan](/apps/5chan/) og [Seedit](/apps/seedit/) er bygget på dette biblioteket.

Biblioteket har sitt eget dokumentasjonsnettsted, som oppdateres ved hver utgivelse: **[hooks.bitsocial.net](https://hooks.bitsocial.net/)**.

## Installasjon

```bash
npm install @bitsocial/bitsocial-react-hooks
```

Pakken støtter React 16.8 og nyere.

## Hvor du bør begynne

- [Hurtigstart](https://hooks.bitsocial.net/docs/quickstart/): vis din første fellesskapsfeed.
- [Konsepter](https://hooks.bitsocial.net/docs/concepts/): hvordan feeder, lokale kontoer, delt tilstand og publisering henger sammen.
- [API-referanse](https://hooks.bitsocial.net/docs/api/feeds-hooks/): alle hooks med tilhørende alternativer og returverdier.
- [Playground](https://hooks.bitsocial.net/#playground): rediger levende eksempler som kjører på simulert innhold.
- [Bygg med AI](https://hooks.bitsocial.net/docs/ai/): `llms.txt` og Markdown-versjoner av hver side for kodeagenter.
