# Δημιουργήστε τον δικό σας πελάτη Bitsocial

Το Bitsocial δεν επικρατεί έχοντας μία επίσημη εφαρμογή για κάθε περίπτωση χρήσης. Επικρατεί όταν
πολλοί πελάτες μπορούν να μοιράζονται το ίδιο πρωτόκολλο, ανταγωνιζόμενοι στη διεπαφή, την
κουλτούρα, την ανακάλυψη περιεχομένου, τις προεπιλογές και το επιχειρηματικό μοντέλο.

Το 5chan και το Seedit είναι πρώιμες αποδείξεις, όχι ταβάνι. Ένας δημιουργός θα πρέπει να μπορεί να
κυκλοφορήσει ένα νέο imageboard, ένα φόρουμ, έναν πελάτη προφίλ, μια κοινωνική εφαρμογή σχεδιασμένη
πρώτα για κινητά, ένα εργαλείο για μια εξειδικευμένη κοινότητα ή ακόμη και έναν κεντρικοποιημένο
πελάτη που χρησιμοποιεί το Bitsocial από κάτω, χωρίς να ζητήσει άδεια από τον ιδιοκτήτη μιας
πλατφόρμας.

## Τι μπορούν να αλλάξουν οι δημιουργοί

Ένας πελάτης Bitsocial μπορεί να ανταγωνιστεί σε αποφάσεις προϊόντος χωρίς να κάνει fork ολόκληρο το
δίκτυο:

- διεπαφή και οπτική γλώσσα
- ροή υποδοχής νέων χρηστών
- προεπιλογές κοινοτήτων
- επιφάνειες συντονισμού περιεχομένου
- μοντέλο ανακάλυψης
- εμπειρία πολυμέσων
- περιορισμοί κινητών, επιτραπέζιων συσκευών ή χαμηλού εύρους ζώνης
- δημιουργία εσόδων και επιχειρηματικό μοντέλο

Το κοινό επίπεδο είναι το πρωτόκολλο. Το επίπεδο του προϊόντος είναι ανοιχτό στον ανταγωνισμό.

## Ο ταχύτερος τρόπος να μάθετε

Ξεκινήστε από τις εφαρμογές που υπάρχουν ήδη:

- Δοκιμάστε το [5chan](https://5chan.app) για ανώνυμες κοινότητες imageboard.
- Δοκιμάστε το [Seedit](https://seedit.app) για συζητήσεις σε στυλ Reddit.
- Διαβάστε την τεκμηρίωση για τα [Bitsocial React hooks](https://hooks.bitsocial.net/docs/quickstart/) για ενσωμάτωση στην πλευρά του πελάτη.
- Διαβάστε την τεκμηρίωση του [Bitsocial CLI](/developer-tools/cli/) για λειτουργίες κόμβων και κοινοτήτων.

Αν θέλετε να προχωρήσετε γρήγορα, συνεισφέρετε πρώτα σε μια υπάρχουσα εφαρμογή. Αν η διεπαφή, η
κουλτούρα ή το μοντέλο κοινότητας που θέλετε δεν ταιριάζει εκεί, φτιάξτε έναν ξεχωριστό πελάτη.

## Επιλέξτε μια στενά εστιασμένη πρώτη έκδοση

Η καλύτερη πρώτη έκδοση δεν είναι μια καθολική κοινωνική εφαρμογή. Είναι ένας πελάτης με ένα σαφές
κοινό και έναν ισχυρό λόγο ύπαρξης.

Καλά σημεία εκκίνησης είναι:

- ένας πιο καθαρός πελάτης imageboard για μια συγκεκριμένη κουλτούρα
- ένας πελάτης φόρουμ σχεδιασμένος πρώτα για κινητά
- μια εφαρμογή για μία μόνο κοινότητα με αυστηρές προεπιλογές
- ένας πελάτης για κοινότητες δημιουργών
- ένας πελάτης ανακάλυψης μόνο για ανάγνωση
- μια κονσόλα συντονισμού ή διαχείρισης
- ένας πελάτης βελτιστοποιημένος για μια γλώσσα, μια περιοχή ή μια κατηγορία συσκευών

Οι μικροί πελάτες είναι χρήσιμοι επειδή το Bitsocial τους επιτρέπει να μεγαλώσουν μέσα στο ίδιο
δίκτυο, αντί να εγκλωβίζουν τους χρήστες τους σε μια ιδιωτική βάση δεδομένων.

## Δρόμοι υλοποίησης

Υπάρχουν τρεις πρακτικοί δρόμοι:

1. Κάντε fork έναν υπάρχοντα πελάτη, όταν η ιδέα σας είναι κοντά στο 5chan ή στο Seedit.
2. Φτιάξτε έναν νέο πελάτη React με τα [Bitsocial React hooks](https://hooks.bitsocial.net/).
3. Φτιάξτε τη δική σας ενσωμάτωση πάνω από τα API των κόμβων και τη δημόσια υποδομή RPC.

Το δημόσιο RPC αναμένεται να κάνει τον τρίτο δρόμο πολύ πιο πρακτικό. Ένας χρήστης μπορεί να
ξεκινήσει μέσω ενός φιλοξενούμενου παρόχου RPC χωρίς θεματοφυλακή και αργότερα να μετακινηθεί σε
αυτο-φιλοξενία ή σε ανταγωνιστικό πάροχο.

## Αρχή σχεδίασης

Φτιάξτε τον πελάτη που θα έπρεπε να υπάρχει για την κοινότητά σας και έπειτα αφήστε τους συμβατούς
πελάτες να ανταγωνιστούν δημόσια.
