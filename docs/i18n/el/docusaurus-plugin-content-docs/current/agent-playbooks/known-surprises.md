# Γνωστές εκπλήξεις

Αυτό το αρχείο καταγράφει σημεία σύγχυσης που αφορούν ειδικά αυτό το αποθετήριο και έχουν προκαλέσει λάθη σε πράκτορες.

## Κριτήρια καταχώρισης

Προσθέστε μια καταχώριση μόνο αν ισχύουν όλα τα παρακάτω:

- Αφορά ειδικά αυτό το αποθετήριο (δεν είναι γενική συμβουλή).
- Είναι πιθανό να ξανασυμβεί σε μελλοντικούς πράκτορες.
- Έχει συγκεκριμένη αντιμετώπιση που μπορεί κανείς να ακολουθήσει.

Αν δεν είστε βέβαιοι, ρωτήστε τον προγραμματιστή πριν προσθέσετε καταχώριση.

## Πρότυπο καταχώρισης

```md
### [Short title]

- **Date:** YYYY-MM-DD
- **Observed by:** agent name or contributor
- **Context:** where/when it happened
- **What was surprising:** concrete unexpected behavior
- **Impact:** what went wrong or could go wrong
- **Mitigation:** exact step future agents should take
- **Status:** confirmed | superseded
```

### Τα production domains των εφαρμογών στο Vercel μπορούν να ξαναγυρίσουν σε deployments του Git master

- **Ημερομηνία:** 2026-04-28
- **Παρατηρήθηκε από:** Tommaso + Codex
- **Πλαίσιο:** Επαλήθευση των mirrors των εφαρμογών Seedit και 5chan στον κατάλογο εφαρμογών του Bitsocial Web.
- **Τι ήταν απροσδόκητο:** Τα έργα `seedit` και `5chan` στο Vercel είχαν `gitProviderOptions.createDeployments = "enabled"`, οπότε τα pushes στο `master` του GitHub προωθούνταν στα production domains, παρότι η πολιτική του αποθετηρίου προβλέπει ότι τα production mirrors των εφαρμογών σερβίρουν μόνο artifacts εκδόσεων.
- **Επίπτωση:** Τα σήματα επαληθευμένου mirror στον κατάλογο εφαρμογών μπορεί να γίνουν ψευδή, επειδή τα production domains σερβίρουν το τελευταίο commit ανάπτυξης αντί για το ZIP της έκδοσης στο GitHub, του οποίου το hash του `index.html` είναι καταγεγραμμένο στο `about/src/lib/apps-data.ts`.
- **Αντιμετώπιση:** Πριν προσθέσετε ή ανανεώσετε μεταδεδομένα επαλήθευσης mirror, ελέγξτε το έργο στο Vercel με `vercel api /v9/projects/<project-id>` και επιβεβαιώστε ότι ισχύει `gitProviderOptions.createDeployments = "disabled"`. Κάντε deploy τα περιεχόμενα του ZIP της έκδοσης με `vercel deploy --prebuilt --prod` και χρησιμοποιήστε τα `seedit-omega.vercel.app` ή `5chan-omega.vercel.app` για deployments ανάπτυξης.
- **Κατάσταση:** επιβεβαιωμένο

### Το Portless 0.11 επαναχρησιμοποιεί παλαιά κατάσταση proxy εκτός αν ο launcher επιβάλλει HTTPS

- **Ημερομηνία:** 2026-04-28
- **Παρατηρήθηκε από:** Tommaso + Codex
- **Πλαίσιο:** Αναβάθμιση της κανονικής ροής `yarn start` από το παλιό URL proxy `http://bitsocial.localhost:1355` στο `https://bitsocial.localhost`.
- **Τι ήταν απροσδόκητο:** Ακόμη και με εγκατεστημένο το `portless@0.11.1`, το Portless επαναχρησιμοποίησε το υπάρχον HTTP proxy `~/.portless/proxy.port = 1355` και τύπωσε το παλιό URL με `:1355`.

- **Αντιμετώπιση:** Φροντίστε τα scripts εκκίνησης να ξεκινούν ρητά το HTTPS proxy του Portless στη θύρα `443` πριν καταχωρίσουν τις διαδρομές των εφαρμογών, ώστε η ροή εκτέλεσης να απομακρύνεται από την αποθηκευμένη κατάσταση `1355` αντί να την κληρονομεί.

### Η πολυγλωσσική προεπισκόπηση της τεκμηρίωσης μπορεί να εκτινάξει τη χρήση RAM κατά την επαλήθευση

- **Ημερομηνία:** 2026-04-01
- **Παρατηρήθηκε από:** Codex

- **Τι ήταν απροσδόκητο:** Η προεπιλεγμένη λειτουργία προεπισκόπησης της τεκμηρίωσης κάνει πλέον πλήρες πολυγλωσσικό build μαζί με ευρετηρίαση Pagefind πριν σερβίρει, και η διατήρηση αυτής της διεργασίας ζωντανής παράλληλα με πολλές συνεδρίες Playwright ή Chrome μπορεί να καταναλώσει πολύ περισσότερη RAM από έναν συνηθισμένο κύκλο ανάπτυξης με Vite ή με Docusaurus σε μία γλώσσα.
- **Επίπτωση:** Το μηχάνημα μπορεί να μείνει από μνήμη, οι συνεδρίες του προγράμματος περιήγησης μπορεί να καταρρεύσουν, και οι διακοπτόμενες εκτελέσεις μπορεί να αφήσουν πίσω ξεχασμένους servers τεκμηρίωσης ή headless προγράμματα περιήγησης που συνεχίζουν να καταναλώνουν μνήμη.

Κρατήστε μία μόνο συνεδρία Playwright, κλείστε τις παλιές συνεδρίες πριν ανοίξετε νέες και σταματήστε τον server της τεκμηρίωσης μετά την επαλήθευση αν δεν τον χρειάζεστε πια.

### Το P2P στο πρόγραμμα περιήγησης λειτουργεί με ασφαλή WebSockets· το pkc-js απορρίπτει WebRTC και WebTransport από προεπιλογή

- **Πλαίσιο:** Συγγραφή κειμένου για τη σελίδα προορισμού και την τεκμηρίωση σχετικά με το πώς λειτουργεί το P2P του Bitsocial στο πρόγραμμα περιήγησης

Οι λανθασμένοι ισχυρισμοί για την αρχιτεκτονική σε δημόσιες σελίδες ελέγχονται ακριβώς από το κοινό προγραμματιστών στο οποίο απευθύνεται το site.
