# Επαλήθευση

Επιλέξτε ελέγχους με βάση τη συμπεριφορά που άλλαξε και την αβεβαιότητα που παραμένει. Επαναχρησιμοποιήστε επιτυχή τεκμήρια για την ίδια τελική κατάσταση· εκτελέστε ξανά τους ελέγχους μετά από σχετικές αλλαγές ή αποτυχίες. Οι ρητές απαιτήσεις του CI, της έκδοσης ή του χρήστη εξακολουθούν να ισχύουν.

| Αλλαγή                                                  | Κατάλληλοι έλεγχοι                                                                                                                                |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| Μόνο κείμενο/σχόλια/μορφοποίηση                         | Diff, παραπομπές, σχετικά εργαλεία παραγωγής αρχείων· χωρίς build της εφαρμογής                                                                   |
| Πηγαία αρχεία/ρυθμίσεις της ροής εργασίας AI            | `yarn ai-workflow:sync`, `yarn ai-workflow:check`, `yarn ai-workflow:test`· παραγάγετε ξανά τα ευρετήρια LLM όταν έχει αλλάξει το context         |
| Απομονωμένο βοηθητικό αρχείο ή script                   | Στοχευμένη κλήση/fixtures και έλεγχοι σύνταξης ή τύπων/lint για τον κώδικα που επηρεάζεται                                                        |
| Αλλαγή σε κοινό runtime, εξαρτήσεις, build ή ενσωμάτωση | Στοχευμένοι έλεγχοι για ό,τι επηρεάζεται, μαζί με τους σχετικούς ελέγχους build/τύπων/lint παρακάτω                                               |
| Μόνο CSS/θέμα/διάταξη                                   | Οι διαδρομές/viewports/θέματα που επηρεάζονται, στα επιλεγμένα προγράμματα περιήγησης· build όταν άλλαξαν imports, assets ή η επεξεργασία του CSS |
| Κατάσταση/effects/απόδοση στη React                     | Η συμπεριφορά που επηρεάζεται και η σχετική καθοδήγηση για τη React· Doctor όταν τα διαγνωστικά του ξεκαθαρίζουν ένα συγκεκριμένο ζήτημα          |

## Έλεγχοι του έργου

- Το `yarn build:verify` επιλέγει το workspace που επηρεάζεται. Για γνωστό εύρος χρησιμοποιήστε `yarn build:about`, `yarn build:chain`, `yarn build:stats-monitor` ή `yarn docs:build:verify`.
- Το `yarn build` εκτελεί σκόπιμα το πλήρες build παραγωγής του about και της τεκμηρίωσης, μαζί με όλα τα locales της τεκμηρίωσης. Χρησιμοποιήστε το για επικύρωση σε επίπεδο έκδοσης ή για αλλαγές που δικαιολογούν αυτό το εύρος.
- Τα `yarn lint`, `yarn typecheck` και `yarn format:check` καλύπτουν τις υπάρχουσες πύλες του αποθετηρίου· για μια περιορισμένη αλλαγή σε script, χρησιμοποιήστε πρώτα τους στοχευμένους ελέγχους σύνταξης/fixtures/μορφοποίησης που του αντιστοιχούν.
- Οι αλλαγές σε manifest/lockfile απαιτούν `corepack yarn install`, `yarn deps:check-pinned` και `yarn deps:check-hardened`. Το `yarn knip` είναι συμβουλευτικό για εξαρτήσεις/imports.
- Οι έλεγχοι μεταφράσεων της τεκμηρίωσης περιγράφονται στο [translations.md](translations.md)· μην εκτελείτε τον μαζικό εγγραφέα μεταφράσεων για μια στοχευμένη αλλαγή στην τεκμηρίωση.

## Τεκμήρια από το πρόγραμμα περιήγησης και κατοχή συνεδριών

Χρησιμοποιήστε το Chrome για μικρές, απομονωμένες αλλαγές που αφορούν το πρόγραμμα περιήγησης. Προσθέστε Firefox και WebKit για κοινόχρηστο CSS/διάταξη/αποκριτικότητα, APIs που συμπεριφέρονται διαφορετικά ανά πρόγραμμα περιήγησης, εκτεταμένες αλληλεπιδράσεις, εκδόσεις ή ρητά κριτήρια συμβατότητας με πολλά προγράμματα περιήγησης. Συμπεριλάβετε τις διατάξεις για κινητά και τη συμπεριφορά αφής που επηρεάζονται. Μια απλή αλλαγή μεγέθους του viewport δεν αποτελεί εξομοίωση αφής. Επιλέξτε πραγματικές διαδρομές και πραγματικό περιεχόμενο με βάση τον πηγαίο κώδικα, αντί να υποθέτετε ότι τα παραδείγματα είναι διαθέσιμα.

Χρησιμοποιήστε το `playwright-cli` μέσω του `./scripts/pw-session.sh`. Μόνο ένα πρόγραμμα περιήγησης είναι ενεργό σε ολόκληρο το μηχάνημα· οι επιλεγμένες μηχανές εκτελούνται διαδοχικά και κάθε συγκεκριμένη συνεδρία που σας ανήκει κλείνει ακόμη και μετά από αποτυχία. Επαναχρησιμοποιήστε μια εξουσιοδοτημένη συνεδρία που ανήκει σε αυτόν που σας κάλεσε, χωρίς να την κλείσετε. Μη χρησιμοποιείτε ποτέ καθολικό καθαρισμό προγραμμάτων περιήγησης και μη σταματάτε server του οποίου ο κάτοχος δεν είναι σαφής. Για εργασία που αφορά μόνο την τεκμηρίωση δεν χρειάζεται ούτε πρόγραμμα περιήγησης ούτε server.

Για εργασία απόδοσης, συγκρίνετε την ίδια ροή με ισοδύναμο viewport, περιεχόμενο, ρυθμίσεις δικτύου/CPU, λειτουργία build και επιβάρυνση από τη μέτρηση. Ξεχωρίστε τις παρατηρήσεις από τις πιθανολογούμενες αιτίες. Χρησιμοποιήστε το skill για profiling όταν αυτές οι μετρήσεις απαντούν στο πραγματικό αίτημα.

## Τελικά τεκμήρια

Ένας μόνο πράκτορας έχει την ευθύνη της βαριάς επαλήθευσης. Ελέγξτε τα ενεργά φορτία εργασίας και εκτελέστε σειριακά τις εγκαταστάσεις, τα builds/τις πλήρεις σουίτες, το Doctor, την εργασία σε Android/Electron και το profiling στο πρόγραμμα περιήγησης. Αναφέρετε τις εντολές/τα αποτελέσματα και τους συγκεκριμένους περιορισμούς· δεδομένα που λείπουν ή μια μηχανή που παραλείφθηκε δεν αποτελούν επιτυχές αποτέλεσμα. Τα fixtures των εργαλείων επαληθεύουν μορφές και μηχανισμούς, όχι την ανακάλυψη από άκρο σε άκρο μέσα στην εφαρμογή ούτε την ποιότητα των αποφάσεων του μοντέλου.

## Αυτόματοι έλεγχοι React

Το `yarn agent:verify` εκτελεί τα επιλεγμένα builds και στη συνέχεια τα `yarn doctor:check` και `yarn perf:check`. Το `perf:check` περιλαμβάνει τον αυτοέλεγχο συμβατότητας του collector και σκόπιμης παλινδρόμησης, οπότε ούτε το CI ούτε η διαδρομή επαλήθευσης των πρακτόρων χρειάζονται ξεχωριστό πέρασμα `perf:test`. Εγκαταστήστε μία φορά τα καρφιτσωμένα εργαλεία προγράμματος περιήγησης με `yarn perf:install` (`--with-deps` στο CI σε Linux). Χρησιμοποιήστε φίλτρα στόχου/σεναρίου για στοχευμένες επανεκτελέσεις μετά το πλήρες σχετικό πέρασμα. Οι προϋπολογισμοί των σεναρίων ορίζονται ρητά στο `scripts/react-perf/config.mjs`· διατηρήστε τα τεκμήρια και διορθώστε μια παλινδρόμηση πριν εξετάσετε μια τεκμηριωμένη αλλαγή της γραμμής βάσης. Τα συνηθισμένα builds παραγωγής παραλείπουν το Bippy· ξεχωριστές εντολές `build:profile:*` παρέχουν την επίσημη instrumentation της React για profiling.

Στο σενάριο `apps-search` του about, ο ρυθμός ορίζεται από τις οριστικοποιημένες τιμές URL/εισόδου για κάθε χαρακτήρα. Ένα επιτυχές αποτέλεσμα καλύπτει αυτή την ακολουθία οριστικοποιημένων ερωτημάτων, όχι την απόκριση σε γρήγορη πληκτρολόγηση. Χρησιμοποιήστε ξεχωριστή αναπαραγωγή με γρήγορη εισαγωγή όταν αξιολογείτε απώλεια χαρακτήρων ή την απόκριση της εισόδου.
