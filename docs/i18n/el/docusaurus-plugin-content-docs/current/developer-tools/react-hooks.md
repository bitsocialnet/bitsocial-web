# React Hooks

Το `@bitsocial/bitsocial-react-hooks` δίνει στις εφαρμογές React ένα API βασισμένο σε hooks για το πρωτόκολλο Bitsocial: ροές, σχόλια, κοινότητες, προφίλ συγγραφέων, λογαριασμούς και δημοσίευση, χωρίς κεντρικό διακομιστή. Το [5chan](/apps/5chan/) και το [Seedit](/apps/seedit/) είναι χτισμένα πάνω σε αυτό.

Η βιβλιοθήκη έχει δικό της ιστότοπο τεκμηρίωσης, που ενημερώνεται με κάθε νέα έκδοση: **[hooks.bitsocial.net](https://hooks.bitsocial.net/)**.

## Εγκατάσταση

```bash
npm install @bitsocial/bitsocial-react-hooks
```

Το πακέτο υποστηρίζει το React 16.8 και νεότερες εκδόσεις.

## Από πού να ξεκινήσετε

- [Γρήγορη εκκίνηση](https://hooks.bitsocial.net/docs/quickstart/): εμφανίστε την πρώτη σας ροή κοινότητας.
- [Έννοιες](https://hooks.bitsocial.net/docs/concepts/): πώς συνδυάζονται οι ροές, οι τοπικοί λογαριασμοί, η κοινόχρηστη κατάσταση και η δημοσίευση.
- [Αναφορά API](https://hooks.bitsocial.net/docs/api/feeds-hooks/): κάθε hook με τις επιλογές και τις τιμές επιστροφής του.
- [Πεδίο δοκιμών](https://hooks.bitsocial.net/#playground): επεξεργαστείτε ζωντανά παραδείγματα που εκτελούνται σε προσομοιωμένο περιεχόμενο.
- [Ανάπτυξη με AI](https://hooks.bitsocial.net/docs/ai/): το `llms.txt` και εκδόσεις Markdown κάθε σελίδας για πράκτορες προγραμματισμού.
