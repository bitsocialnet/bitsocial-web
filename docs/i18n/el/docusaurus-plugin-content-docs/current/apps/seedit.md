# Seedit

Το Seedit είναι μια εναλλακτική λύση χωρίς διακομιστή, χωρίς διαχειριστή και πλήρως αποκεντρωμένη στο παλιού τύπου Reddit, που βασίζεται στο πρωτόκολλο Bitsocial. Παρέχει στους χρήστες πλήρη ιδιοκτησία των κοινοτήτων τους — ο καθένας μπορεί να δημιουργήσει μία και πολλές κοινότητες μπορούν να διεκδικήσουν την ίδια σύντομη διαδρομή, όπως το `/s/funny`.

## Πώς λειτουργούν οι κοινότητες

Το sedit οργανώνει το περιεχόμενο σε κοινότητες παρόμοιες με subreddits. Κάθε κοινότητα ανήκει στον δημιουργό της και λειτουργεί χωρίς κεντρική διαχείριση. Πολλές κοινότητες μπορούν να διεκδικήσουν την ίδια διαδρομή [καταλόγου](/directories/), όπως το `/s/funny`, η οποία ανοίγει την τρέχουσα νικήτρια. Οι συνδρομές και οι σύνδεσμοι αναρτήσεων δείχνουν πάντα στη συγκεκριμένη κοινότητα.

### Δημιουργία κοινότητας

Υπάρχουν δύο τρόποι για να δημιουργήσετε μια νέα κοινότητα:

1. **Πελάτης επιφάνειας εργασίας** — Χρησιμοποιήστε το ενσωματωμένο GUI στην εφαρμογή επιφάνειας εργασίας για να ρυθμίσετε και να διαμορφώσετε την κοινότητά σας.
2. **bitsocial-cli** — Εκτελέστε το εργαλείο CLI για να δημιουργήσετε και να διαχειριστείτε κοινότητες από τη γραμμή εντολών.

### Προεπιλεγμένη λίστα κοινότητας

Οι νέοι λογαριασμοί εγγράφονται ως συνδρομητές σε μια προεπιλεγμένη λίστα συγκεκριμένων κοινοτήτων, που ορίζεται στο `seedit-default-subscriptions.json` στο αποθετήριο [bitsocialnet/lists](https://github.com/bitsocialnet/lists). Οι υποψήφιες κοινότητες των καταλόγων αναφέρονται στα αρχεία `seedit-directories/seedit-<code>-directory.json` στο ίδιο αποθετήριο. Για να προσθέσετε την κοινότητά σας σε οποιαδήποτε από τις δύο λίστες, υποβάλετε ένα pull request με τα στοιχεία της κοινότητάς σας.
