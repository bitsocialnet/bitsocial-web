# Bitsocial Chain

Το Bitsocial Chain είναι το προτεινόμενο οικονομικό επίπεδο appchain σε Ethereum L2 για τις
εφαρμογές Bitsocial. Ο ειδικός ιστότοπος για την αλυσίδα βρίσκεται σήμερα στο
[chain.bitsocial.net](https://chain.bitsocial.net).

Το peer-to-peer κοινωνικό επίπεδο επιτρέπει σε κοινότητες, ταυτότητες και περιεχόμενο να
κινούνται έξω από μια κεντρική βάση δεδομένων πλατφόρμας. Το Bitsocial Chain προορίζεται να
προσθέσει τα κοινά δομικά στοιχεία ονοματοδοσίας, δημιουργίας εσόδων και πληρωμών που κάνουν
αυτές τις εφαρμογές πιο δύσκολο να αποκοπούν οικονομικά.

## Τι προορίζεται να τροφοδοτεί

- αποκεντρωμένα ονόματα τομέα Bitsocial όπως το `.bso`
- βραβεία και φιλοδωρήματα
- ανθεκτικές υποδομές δημιουργίας εσόδων
- κοινή ρευστότητα ανάμεσα στις εφαρμογές
- χρηματοοικονομικές δομές που είναι πιο δύσκολο να μπλοκαριστούν από τράπεζες ή πλατφόρμες
- φαινόμενα δικτύου που δεν εξαρτώνται από μία εταιρεία που κατέχει ολόκληρη τη στοίβα

Ο στόχος δεν είναι να μπουν μπροστά οι μηχανισμοί του token. Ο στόχος είναι να γίνουν οι χρήσιμες
κοινωνικές εφαρμογές πιο ανθεκτικές, πιο εύκολα χρηματοδοτήσιμες και λιγότερο εξαρτημένες από
κεντρικοποιημένους παρόχους πληρωμών ή ονοματοδοσίας.

## Η τρέχουσα απόδειξη ιδέας

Η πρώτη απόδειξη ιδέας του Bitsocial Chain επικεντρώνεται στα εγγενή ονόματα `.bso`. Δείχνει ότι
ένα μητρώο ονομάτων μπορεί να παραχθεί από το ιστορικό του Ethereum L1 χωρίς να τοποθετηθεί
κοινωνικό περιεχόμενο on-chain:

- οι χρήστες υποβάλλουν προθέσεις καταχώρισης, ενημέρωσης, μεταβίβασης και ανάκλησης μέσω απλών
  συναλλαγών Ethereum L1
- οποιοσδήποτε μπορεί να τρέξει τον κόμβο παραγωγής και να ανακατασκευάσει την ίδια κατάσταση του
  μητρώου `.bso`
- ένας μηχανισμός επίλυσης αντιστοιχίζει ένα όνομα `.bso` στο δημόσιο κλειδί Bitsocial που οι
  πελάτες χρησιμοποιούν ήδη μέσω του peer-to-peer πρωτοκόλλου
- οι δημοσιεύσεις, οι ψήφοι, ο συντονισμός περιεχομένου, οι ροές και το περιεχόμενο των κοινοτήτων
  παραμένουν off-chain και peer-to-peer

Αυτή η απόδειξη ιδέας δεν είναι παραγωγική κυκλοφορία Stage 2. Δεν διαθέτει ακόμη σύστημα
αποδείξεων, μηχανισμό αμφισβήτησης, ελεγμένο κώδικα, ζωντανή εγκατάσταση, τελική τιμολόγηση ή
τελική διακυβέρνηση. Η μακροπρόθεσμη στάση της είναι διαφανής εξ ορισμού και συμβατή με την
ιδιωτικότητα εκ σχεδιασμού: η βασική αλυσίδα είναι δημόσια, ενώ τα μελλοντικά φιλοδωρήματα, οι
πληρωμές, τα βραβεία και η ρευστότητα δεν πρέπει να επιβάλλουν μόνιμες συνδέσεις ανάμεσα στην
κοινωνική ταυτότητα και το ιστορικό του πορτοφολιού.

## Γιατί έχει σημασία

Η αποκέντρωση των κοινοτήτων και των ταυτοτήτων είναι απαραίτητη, αλλά δεν αρκεί για να
αποκεντρωθούν όλα τα μέσα κοινωνικής δικτύωσης.

Αν οι κοινωνικές εφαρμογές εξακολουθούν να εξαρτώνται από λίγες κεντρικοποιημένες οικονομικές
υποδομές, παραμένουν εύκολος στόχος για πιέσεις, αποκλεισμό από πλατφόρμες ή οικονομική ασφυξία.
Το Bitsocial Chain είναι η προτεινόμενη απάντηση σε αυτό το δεύτερο επίπεδο εξάρτησης.

## Σχέση με τις εφαρμογές

Το Bitsocial Chain πρέπει να βρίσκεται κάτω από τις εφαρμογές Bitsocial, όχι να τις αντικαταστήσει.

Το αποτέλεσμα προς το κοινό πρέπει να είναι:

- οι κοινότητες παραμένουν peer-to-peer
- οι εφαρμογές παραμένουν διαφοροποιημένες
- οι χρήστες αποκτούν πρακτικές δυνατότητες ονοματοδοσίας και δημιουργίας εσόδων
- οι δημιουργοί και οι κοινότητες μπορούν να λαμβάνουν στήριξη από διαφορετικούς πελάτες
- η αξία μπορεί να μετακινείται μέσα στο οικοσύστημα χωρίς να αναδημιουργείται ένας κεντρικός
  ιδιοκτήτης πλατφόρμας

## Γιατί έρχεται μετά την εναλλακτική του Twitter/X

Το τρέχον γενικό σχέδιο τοποθετεί το Bitsocial Chain μετά την εναλλακτική του Twitter/X, επειδή αυτή η εφαρμογή δεν χρειάζεται την αλυσίδα. Τα προφίλ λειτουργούν ως κόμβοι προφίλ μέσω μη θεματοφυλακτικού RPC, και τα ονόματα `.bso` μπορούν να ξεκινήσουν σε ένα προσωρινό μητρώο στο mainnet του Ethereum ([BSIP-13](https://bsips.bitsocial.net/bsip-13)) και να μεταφερθούν αργότερα στην αλυσίδα.

Το Bitsocial Chain δεν πρέπει να θυσιάσει την αποκέντρωση για μια νωρίτερη κυκλοφορία. Δεν πρέπει να προσθέτει καμία παραδοχή εμπιστοσύνης πέρα από το ίδιο το Ethereum: κανένα κλειδί αναβάθμισης, κανένα συμβούλιο ασφαλείας και κανέναν χειριστή που να μπορεί να το λογοκρίνει ή να το σταματήσει. Ο κορυφαίος σχεδιασμός γι' αυτό, ένα native rollup, εξαρτάται από μια αναβάθμιση του Ethereum που δεν έχει ακόμη προγραμματιστεί. Μέχρι η αλυσίδα να μπορεί να καλύψει αυτόν τον πήχη, η εναλλακτική του Twitter/X μεγαλώνει τη βάση χρηστών που θα εξυπηρετήσει η αλυσίδα.

## Αρχές σχεδιασμού

Επειδή το Bitsocial Chain παραμένει προτεινόμενη υποδομή και όχι προϊόν που έχει ήδη κυκλοφορήσει,
το σχέδιο πρέπει να παραμείνει πειθαρχημένο:

- Πρώτα οι εφαρμογές και οι κοινότητες. Το επίπεδο του δικτύου πρέπει να κάνει ισχυρότερα τα
  πραγματικά κοινωνικά προϊόντα.
- Πρώτα οι πρακτικές δυνατότητες. Τα ονόματα, τα βραβεία, τα φιλοδωρήματα και οι πληρωμές
  εξηγούνται πιο εύκολα από μια αφηρημένη χρηματοοικονομική αρχιτεκτονική.
- Πραγματική συνεισφορά αντί για hype. Τα οικονομικά δομικά στοιχεία πρέπει να ανταμείβουν τη
  συμμετοχή, το χτίσιμο και τη στήριξη των κοινοτήτων.
- Επιτρέπεται η επιμέλεια. Οι εφαρμογές μπορούν να διαμορφώνουν κατατάξεις, προεπιλογές και
  ανακάλυψη ώστε να ευνοούν ανθεκτικές κοινότητες.
- Οι ακριβείς μηχανισμοί παραμένουν ανοιχτοί. Αυτή η σελίδα εξηγεί τον ρόλο του Bitsocial Chain,
  όχι μια κλειδωμένη υπόσχεση για τα τελικά οικονομικά του.
