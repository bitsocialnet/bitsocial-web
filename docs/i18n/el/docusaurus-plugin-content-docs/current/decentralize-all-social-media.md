# Αποκέντρωση όλων των μέσων κοινωνικής δικτύωσης

Η τελική κατάσταση δεν είναι μία εφαρμογή. Είναι μια αγορά από πελάτες, κόμβους, υπηρεσίες και
κοινότητες που μπορεί να αντικαταστήσει την ιδιοκτησία της πλατφόρμας με ανταγωνισμό πάνω σε ένα
κοινό πρωτόκολλο.

Στη Φάση 5 το Bitsocial προχωρά πέρα από τις πρώτες κατηγορίες προτεραιότητας και αρχίζει να
χρηματοδοτεί όσο το δυνατόν περισσότερες μορφές κοινωνικής δικτύωσης.

## Τι μένει ακόμη να χτιστεί

Οι πρώτες φάσεις επικεντρώνονται στις κατηγορίες με τη μεγαλύτερη μόχλευση: imageboards, φόρουμ,
δημόσιο RPC, Bitsocial Chain, κόμβοι προφίλ, η εναλλακτική του Twitter/X στη Φάση 3 και η οικονομία
υπηρεσιών γύρω από αυτά.

Μετά από αυτό, το δίκτυο πρέπει να επεκταθεί στη μακρά ουρά:

- πελάτες για ιστολόγια
- εφαρμογές συμμετοχικής χρηματοδότησης
- βίντεο δημιουργών και μια αξιόπιστη [εναλλακτική του YouTube](https://github.com/bitsocialnet/wetube)
- κοινότητες δημιουργών
- πειράματα με πολυμέσα σύντομης μορφής
- τοπικές ή γλωσσικά εξειδικευμένες κοινωνικές εφαρμογές
- εξειδικευμένοι πελάτες που είναι πολύ μικροί για τις πρώτες τέσσερις φάσεις
- εργαλεία που κάνουν πιο εύκολη τη λειτουργία των υπαρχουσών κοινοτήτων

Κάποιες από αυτές τις εφαρμογές μπορούν να είναι ανοιχτού κώδικα. Κάποιες μπορούν να είναι
κεντρικοποιημένοι πελάτες. Κάποιες μπορούν να φτιαχτούν από το Bitsocial Forge, και πολλές θα πρέπει
να φτιαχτούν από ανεξάρτητους προγραμματιστές.

## Ιδέες υπό έρευνα

Ορισμένες από αυτές τις ιδέες έχουν ήδη αποθετήρια σε στάδιο ιδέας. Τίποτα σε αυτά δεν έχει
κατασκευαστεί ακόμη. Το καθένα συγκεντρώνει τον σχεδιασμό και τα ανοιχτά ερωτήματα, ώστε δημιουργοί
και χρηματοδότες να μπορούν να το αναλάβουν.

- [WeTube](https://github.com/bitsocialnet/wetube): μια εναλλακτική του YouTube όπου κάθε κανάλι
  είναι μια κοινότητα που ανήκει στον δημιουργό του.
- [Gitcommons](https://github.com/bitsocialnet/gitcommons): έρευνα και
  αρχιτεκτονική για μια εναλλακτική του GitHub χτισμένη πάνω στο Bitsocial.
- [Infinipedia](https://github.com/bitsocialnet/infinipedia): μια εγκυκλοπαίδεια που δεν ανήκει σε
  κανέναν, όπου συντακτικές ομάδες δημοσιεύουν ανταγωνιστικές εκδοχές και οι αναγνώστες επιλέγουν.
- [Hopium](https://github.com/bitsocialnet/hopium): μια εναλλακτική του Fomo για social trading,
  όπου κάθε σύσταση ελέγχεται απέναντι στις on-chain συναλλαγές του δημιουργού της και κάθε token
  έχει ένα δωμάτιο όπου γράφουν μόνο οι κάτοχοί του.

## Χρηματοδότηση πολλών δημιουργών

Ο στόχος είναι οι νέοι κοινωνικοί πελάτες να μπορούν να χρηματοδοτηθούν πριν αποκτήσουν απήχηση σε
κλίμακα πλατφόρμας.

Αυτό μπορεί να περιλαμβάνει άμεση επένδυση, επιχορηγήσεις, χρηματοδότηση από την κοινότητα, έσοδα
από επιτυχημένες υπηρεσίες Bitsocial ή αποκεντρωμένα προγράμματα επιχορηγήσεων, όπου η ευρύτερη
κοινότητα του Bitsocial βοηθά να αποφασιστεί ποιοι προγραμματιστές θα λάβουν στήριξη.

Το σημαντικό είναι η πολυφωνία. Το δίκτυο πρέπει να χρηματοδοτεί πολλές προσπάθειες, αντί να
περιμένει μία επίσημη εφαρμογή να καλύψει κάθε κατηγορία.

## Πώς μοιάζει η επιτυχία

Το Bitsocial πετυχαίνει όταν τα μέσα κοινωνικής δικτύωσης μπορούν να διασπαστούν σε αντικαταστάσιμα
επίπεδα:

- πρωτόκολλο
- κοινότητες
- ταυτότητα
- φιλοξενία
- ανακάλυψη
- συντονισμός περιεχομένου
- δημιουργία εσόδων
- εφαρμογές

Μόλις αυτά τα επίπεδα γίνουν αντικαταστάσιμα, καμία μεμονωμένη εταιρεία δεν χρειάζεται να κατέχει
ολόκληρο τον κοινωνικό γράφο για να λειτουργεί το προϊόν.

## Το βασικό στοίχημα

Ένα ώριμο οικοσύστημα Bitsocial πρέπει να περιλαμβάνει δημόσια RPC, αυτο-φιλοξενούμενους κόμβους,
αγορές αλγορίθμων ροής, παρόχους φιλοξενίας πολυμέσων, υπηρεσίες ανακάλυψης, πελάτες ανοιχτού
κώδικα, εμπορικούς πελάτες και πειράματα χρηματοδοτούμενα από την κοινότητα.

Τα μέσα κοινωνικής δικτύωσης βρίσκουν επιτέλους την ισορροπία τους: ένα πλήρως αποκεντρωμένο,
peer-to-peer κοινωνικό δίκτυο που δεν ανήκει σε κανέναν· το Bitsocial.
