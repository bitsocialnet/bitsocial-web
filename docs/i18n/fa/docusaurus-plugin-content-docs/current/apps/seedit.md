# Seedit

Seedit یک جایگزین بدون سرور، بدون مدیریت و کاملاً غیرمتمرکز برای Reddit به سبک قدیمی است که بر اساس پروتکل Bitsocial ساخته شده است. این به کاربران مالکیت کامل بر جوامع خود را می دهد - هر کسی می تواند یک انجمن ایجاد کند و چندین انجمن می‌توانند بر سر یک مسیر کوتاه یکسان، مانند `/s/funny`، رقابت کنند.

## چگونه جوامع کار می کنند

sedit محتوا را در جوامعی شبیه به subreddits سازماندهی می کند. هر جامعه ای متعلق به خالق خود است و بدون مدیریت متمرکز عمل می کند. چندین انجمن می‌توانند بر سر یک مسیر [دایرکتوری](/directories/) یکسان، مانند `/s/funny`، رقابت کنند که برنده‌ی فعلی را باز می‌کند. اشتراک‌ها و پیوندهای پست‌ها همیشه به همان انجمن مشخص اشاره می‌کنند.

### ایجاد یک جامعه

دو راه برای ایجاد یک جامعه جدید وجود دارد:

1. **کلاینت دسکتاپ** — از رابط کاربری گرافیکی داخلی در برنامه دسکتاپ برای راه اندازی و پیکربندی انجمن خود استفاده کنید.
2. **bitsocial-cli** - ابزار CLI را برای ایجاد و مدیریت جوامع از خط فرمان اجرا کنید.

### لیست انجمن پیش فرض

حساب‌های تازه مشترک یک فهرست پیش‌فرض از انجمن‌های مشخص می‌شوند که در `seedit-default-subscriptions.json` در مخزن [bitsocialnet/lists](https://github.com/bitsocialnet/lists) تعریف شده است. نامزدهای دایرکتوری‌ها در فایل‌های `seedit-directories/seedit-<code>-directory.json` در همان مخزن فهرست شده‌اند. برای افزودن انجمن خود به هر یک از این دو فهرست، یک pull request با جزئیات انجمن خود ارسال کنید.
