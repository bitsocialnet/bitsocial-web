# ترجمه‌ها

سایت about از فایل‌های JSON مربوط به i18next در `about/public/translations/{lang}/default.json` استفاده می‌کند. ترجمه‌های منبع Docusaurus جداگانه در `docs/i18n/` قرار دارند.

## کلیدهای سایت about

از `.agents/skills/translate/SKILL.md` استفاده کنید. زبان‌های فعلی را از روی دیسک پیدا کنید و جانگهدارها، نشانه‌گذاری، اصطلاحات فنی و نام‌های تجاری را حفظ کنید. برای درخواست‌های بزرگ‌تر، فرزندها می‌توانند نگاشت‌های مستقل تولید کنند، اما همه نوشتن‌ها در فایل‌های زبان را یک والد و پشت سر هم اعمال می‌کند؛ به‌روزرسان هیچ قفلی برای نوشتن ندارد.

از مسیری یکتا برای نگاشت استفاده کنید که متعلق به همان وظیفه باشد. با `node scripts/update-translations.js --key <key> --map <map.json> --include-en --dry` پیش‌نمایش بگیرید و سپس با همان آرگومان‌ها و `--write` اعمال کنید. پس از نوشتن، پوشش و مقادیر را راستی‌آزمایی کنید و فقط نگاشت‌های موقتی را حذف کنید که متعلق به همین وظیفه‌اند.

برای حذف‌های درخواست‌شده از `--delete` استفاده کنید. پیش از یک `--audit --write` مجاز، یافته‌های `--audit --dry` را بررسی کنید؛ کلیدهای ترجمه پویا به بازبینی دستی کد منبع نیاز دارند. متن انگلیسی را فقط برای اصطلاح فنی، نام تجاری یا جانگهدار در همه زبان‌ها کپی کنید.

## صفحه‌های Docusaurus

`scripts/translate-docs.py` نویسنده‌ای انبوه برای همه صفحه‌ها و زبان‌هاست و فیلتری برای تک‌فایل ندارد؛ از آن برای ویرایش محدود یک ترجمه استفاده نکنید. `scripts/check-docs-translations.py` راستی‌آزمای فقط‌خواندنی است و از `--locales` و `--paths` پشتیبانی می‌کند.

بلوک‌های کد، لینک‌ها، کد درون‌خطی، آدرس‌های قرارداد، سرتیترها، جدول‌ها و admonitionها را با منبع انگلیسی هم‌راستا نگه دارید. خطاهای راستی‌آزما را برطرف کنید؛ هشدارهای `frontmatter-untranslated` برای نام‌های تجاری قابل انتظارند. هنگام تغییر تم مستندات یا رفتار i18n، از `docs/AGENTS.md` پیروی کنید و ساخت را از ریشه مخزن انجام دهید تا خروجی ایستا و Pagefind هم‌راستا بمانند.

## بازبینی معنایی اختیاری

برای کلیدهای منتخب i18next از `scripts/jev/translation-README.md` استفاده کنید. برای صفحه‌های مستندات، ابتدا `node scripts/jev/docs-translations.mjs --locales it,de --paths browser-p2p.md` را اجرا کنید. این فرمان به انتخاب صریح زبان و صفحه نیاز دارد، راستی‌آزمای ساختاری را اجرا می‌کند و تا وقتی استنتاج زنده فعال نشده، بازبینی معنایی را راستی‌آزمایی‌نشده گزارش می‌کند. `--live` را فقط با مجوز ارائه‌دهنده و بودجه‌ای که برای وظیفه تعیین شده اضافه کنید؛ پیکربندی خصوصی و مشترک ماشین، اعتبارنامه‌ها و یک مدل پین‌شده را فراهم می‌کند. متغیرهای محیطی و `--model` می‌توانند این تنظیمات را بازنویسی کنند. این فرمان هرگز ترجمه‌ها را ویرایش نمی‌کند.

آداپتور صفحه کانتکست کل صفحه را حفظ می‌کند و هر صفحه را به 24 KB و هر اجرا را به 30 جفت محدود می‌کند. برای صفحه‌های بزرگ‌تر، جفت‌پاراگراف‌های منبع و ترجمه را که صراحتاً با هم تطبیق داده شده‌اند برای `translations.mjs --pairs` آماده کنید؛ پاراگراف‌ها را به‌طور خودکار بر اساس شماره ترتیبشان جفت نکنید. نتایج معنایی جنبه مشورتی دارند: مشکلات و عدم‌قطعیت‌های گزارش‌شده را بررسی کنید و بررسی‌های قطعی کد، لینک و آدرس را حفظ کنید.
