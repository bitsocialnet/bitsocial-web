# Bitsocial 与区块链社交网络

Lens、DeSo 和 Steem 都把社交活动放到了区块链上。账号、关注、帖子或围绕它们的规则，变成由验证者排序和存储的交易。Bitsocial 不使用区块链：社交媒体不需要为每条帖子建立全局顺序，所以 Bitsocial 省去了共识、gas 和质押。相关理由参见[点对点协议](/peer-to-peer-protocol/)。

## 共同点

- **每次写入都有人付费。** Lens 收取 gas，应用可以代付；DeSo 对每个操作收费；Steem 按质押的代币配给操作额度。
- **链为所有人设定同一套反垃圾策略。** 费用、质押和账号成本在全网统一适用，而不是由各个社区自行选择。
- **链上记录是永久的。** 应用可以隐藏内容，但无法把它从链上删除。
- **浏览器是 API 客户端。** 网页应用签署交易，并通过他人运营的节点、索引器或 API 读取数据。

## Lens

[Lens](https://lens.xyz/) 运行在 Lens Chain 上，这是一条用 ZKsync 的 ZK Stack 构建的 Ethereum 二层网络，使用 Avail 提供数据可用性。Mask Network [自 2026 年 1 月起负责管理 Lens](https://lens.xyz/news/mask-network-to-steward-the-next-chapter-of-lens)。

- **链上：** 账号是智能合约，用户名是命名空间中的 NFT，社交图、群组、信息流及其规则也都是合约。
- **链下：** 帖子的文字和媒体存放在某个 URI 上的 JSON 文件中，通常位于 Grove，即 Lens 架设在 IPFS 前端的存储服务。回应和书签由 Lens API 保存，应用通过该 API 读取数据。
- **垃圾信息与门槛：** 交易需要以 GHO 支付 gas，应用可以在速率限制下代付。信息流和群组规则可以要求持有代币或付费。
- **链的运营：** [L2BEAT](https://l2beat.com/scaling/projects/lens) 将 Lens Chain 评为 Stage 0 validium，其中心化运营方可以拒绝打包交易。

## DeSo

[DeSo](https://docs.deso.org/) 是为社交应用打造的一层区块链。它在 2024 年 7 月从工作量证明转为权益证明。

- **链上：** 个人资料、帖子、点赞、关注和私信都是交易，由每个全节点存储。图片和视频托管在链下；参考节点使用 Google Cloud Storage 和 Cloudflare Stream。
- **垃圾信息：** 每个操作都要支付 DESO 费用。新用户通常在完成手机验证后从某个节点获得起始 DESO。
- **审核：** 每个节点通过黑名单或灰名单决定显示什么，但[内容仍留在链上](https://docs.deso.org/deso-blockchain/content-moderation)。
- **社区：** 文档没有描述任何社区或论坛的基本构件；所谓“社区”是由应用策划的信息流。
- **运行节点：** 根据[验证者指南](https://docs.deso.org/deso-validators/run-a-validator)，验证者至少需要 32 GB 内存和 200 GB 磁盘。

## Steem

[Steem](https://steem.com/) 是一条以代币奖励作者和策展人的社交区块链，主要的博客应用是 [Steemit](https://steemit.com/)。Hive 于 2020 年从 Steem 分叉出来；据 [Hive 白皮书](https://hive.io/whitepaper.pdf)，这次分叉发生在 Steemit Inc. 被出售给 Justin Sun 之后。

- **链上：** 文字帖子、评论、投票及其编辑历史，由 21 个选举产生的见证人排序，每三秒出一个块。图片托管在链下。
- **垃圾信息：** 操作会消耗 Resource Credits，其数量随质押的 STEEM 增加。创建账号要花费 STEEM；对于验证了邮箱地址和手机号码的用户，Steemit 会代付这笔费用。
- **社区：** 社区是在共识之外[由索引器解释的自定义操作](https://github.com/steemit/hivemind/blob/master/docs/communities.md)。版主可以将帖子设为静音，这会让帖子在应用中隐藏，但仍留在链上。
- **奖励：** 奖励由通胀提供资金，按质押加权的投票决定如何分配，因此大户会左右什么内容能获得关注。

## 对比

| 问题         | Lens                                           | DeSo                                       | Steem                                     | Bitsocial                                              |
| ------------ | ---------------------------------------------- | ------------------------------------------ | ----------------------------------------- | ------------------------------------------------------ |
| 链           | Ethereum 二层网络（ZK Stack validium）         | 自有一层链，权益证明                       | 自有链，委托权益证明                      | 无                                                     |
| 帖子内容     | 链下 JSON，通常在 Grove 上                     | 链上文字；媒体在链下                       | 链上文字；图片在链下                      | 存放在社区所有者的节点以及读取并为其做种的对等点上     |
| 身份         | 智能合约账号；用户名 NFT                       | 带链上个人资料的密钥对                     | 带分级密钥的具名链上账号                  | 用户和社区各自使用 Ed25519 密钥对                      |
| 社区         | 以合约形式存在、带规则的群组和信息流           | 没有社区基本构件                           | 共识之外由索引器解释的社区                | 一等对象，由其节点接受或拒绝帖子                       |
| 垃圾信息控制 | gas（常由应用代付）、代币或付费规则            | 每个操作收费；手机验证后发放起始资金       | 来自质押的 Resource Credits；付费创建账号 | 帖子被接受之前须通过所在社区的挑战                     |
| 审核         | 群组管理员、链上规则、API 层面的隐藏           | 每个节点自行过滤显示内容                   | 社区静音、按质押加权的踩、应用过滤        | 社区所有者审核自己的社区；应用自行决定显示什么         |
| 运行         | 链运营方，加上 Lens API 和 Grove               | 至少配备 32 GB 内存的验证者                | 选举产生的见证人，加上 API 和索引器节点   | 消费级硬件上的社区节点，加上协助做种的节点             |
| 主要取舍     | 可编程的链上规则，但内容和读取依赖 Lens 的服务 | 开放的数据池，但每个操作都要付费且永久保留 | 内置奖励，但质押左右可见度和治理          | 没有费用和质押，但没有全局顺序，旧内容也不保证永久留存 |
