# 让所有社交媒体去中心化

终态不是一个应用，而是一个由客户端、节点、服务和社区组成的市场，用协议层面的竞争取代平台所有权。

第 5 阶段是 Bitsocial 越过最初几类优先方向、开始尽可能资助更多社交形态的阶段。

## 还有什么需要构建

前几个阶段聚焦于杠杆最高的类别：图版、论坛、公共 RPC、Bitsocial Chain、个人资料节点、第 3 阶段的 Twitter/X 替代品，以及围绕它们的服务经济。

在那之后，网络应当向长尾扩展：

- 博客客户端
- 众筹应用
- 创作者视频，以及一个有说服力的 [YouTube 替代品](https://github.com/bitsocialnet/wetube)
- 创作者社区
- 短视频形态的实验
- 面向本地或特定语言的社交应用
- 对前四个阶段来说规模太小的小众客户端
- 让现有社区更容易运营的工具

其中一些应用可以是开源的，一些可以是中心化客户端。一些可以由 Bitsocial Forge 来做，而更多应该由独立开发者来做。

## 研究中的想法

其中一些想法已经有了处于构想阶段的仓库。里面还没有构建任何东西。每个仓库汇集了设计和待解决的问题，方便开发者和出资方接手。

- [WeTube](https://github.com/bitsocialnet/wetube)：一个 YouTube 替代品，每个频道都是归其创作者所有的社区。
- [去中心化 GitHub](https://github.com/bitsocialnet/decentralized-github)：基于 Bitsocial 构建 GitHub 替代品的研究与架构。
- [Infinipedia](https://github.com/bitsocialnet/infinipedia)：一部不属于任何人的百科全书，由编辑小组发布相互竞争的版本，由读者自行选择。

## 资助众多开发者

目标是让新的社交客户端在还没有平台级用户量之前就能拿到资金。

这可以包括直接投资、资助金、社区众筹、来自成功 Bitsocial 服务的收入，或者去中心化的资助计划——由更广泛的 Bitsocial 社区共同决定哪些开发者应当获得支持。

关键在于多元。网络应当资助许多次尝试，而不是等某一个官方应用去覆盖所有类别。

## 成功是什么样子

当社交媒体可以被拆成可替换的层时，Bitsocial 就成功了：

- 协议
- 社区
- 身份
- 托管
- 发现
- 审核
- 变现
- 应用

一旦这些层都可替换，产品要跑得起来，就不再需要任何一家公司拥有整张社交图谱。

## 核心押注

成熟的 Bitsocial 生态应当包含公共 RPC、自托管节点、信息流算法市场、媒体托管方、发现服务、开源客户端、商业客户端，以及由社区出资的实验项目。

社交媒体终于找到它的均衡：一个完全去中心化、点对点、无人拥有的社交网络；Bitsocial。
