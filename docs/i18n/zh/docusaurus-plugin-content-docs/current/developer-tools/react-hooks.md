# React Hooks

`@bitsocial/bitsocial-react-hooks` 为 React 应用提供一套面向 Bitsocial 协议的 hooks API：内容流、评论、社区、作者资料、账户和发布，全程无需中心服务器。[5chan](/apps/5chan/) 和 [Seedit](/apps/seedit/) 都基于它构建。

这个库有自己的文档站点，每次发布新版本都会同步更新：**[hooks.bitsocial.net](https://hooks.bitsocial.net/)**。

## 安装

```bash
npm install @bitsocial/bitsocial-react-hooks
```

该包支持 React 16.8 及更高版本。

## 从哪里开始

- [快速开始](https://hooks.bitsocial.net/docs/quickstart/)：渲染你的第一个社区内容流。
- [核心概念](https://hooks.bitsocial.net/docs/concepts/)：内容流、本地账户、共享状态和发布如何协同工作。
- [API 参考](https://hooks.bitsocial.net/docs/api/feeds-hooks/)：每个 hook 及其选项和返回值。
- [演练场](https://hooks.bitsocial.net/#playground)：编辑在模拟内容上运行的实时示例。
- [用 AI 构建](https://hooks.bitsocial.net/docs/ai/)：为编程智能体准备的 `llms.txt` 以及每个页面的 Markdown 版本。
