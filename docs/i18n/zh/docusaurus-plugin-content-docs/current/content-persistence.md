# 帖子存在哪里，以及保留多久

Bitsocial 不会把每一条帖子都存进区块链或公司数据库。每个社区自己的节点保存其帖子，读者和做种者帮忙提供内容，而任何想留下永久记录的人都可以保存一份。永久保存帖子是**可选的，不是强制的**：协议不会要求每个参与者保存整个网络的历史。

本页说明这在实践中意味着什么，因为“不会永久保存”很容易被误读为“会消失”或“相信我”。

## 真实性与可用性是两个不同的问题

关于一条帖子，有两个不同的问题：

1. **它是真的吗？** 是这位作者写的吗？这个社区接受它了吗？
2. **它还在线吗？** 今天还有人能获取它吗？

Bitsocial 用密码学而不是信任来回答第一个问题。每一条帖子都由作者的密钥对签名；一旦社区接受它，帖子就会存放在一个内容标识符（CID）之下，即其精确字节的哈希。任何获取帖子的人都能自行检查签名和哈希。节点、路由器、网关或存档无法在不使检查失败的情况下修改帖子文本，或伪造别人的帖子。

第二个问题关乎谁保存副本，而这也是唯一不受保证的部分。

## 谁让帖子保持在线

- **社区的节点。** 运营者的节点接受帖子，并在社区保留它们期间将其保存在数据库中。这是在社区运行期间始终存在的一份副本。请参阅[点对点协议](/peer-to-peer-protocol/)。
- **读者。** 5chan 桌面应用等应用会在运行时为其加载的社区做种，因此热门社区会像热门种子一样由许多对等点提供。浏览器标签页在打开时可以缓存并校验内容，但不是长期主机。
- **做种者。** [`bitsocial-seeder`](https://github.com/bitsocialnet/bitsocial-seeder)让任何人都能用 VPS 或闲置机器贡献常在线容量。它会固定社区的最新页面和帖子更新，也让托管在家用路由器后的社区可以从浏览器加载。
- **存档者。** 任何人都可以抓取社区并保存看到的一切。存档是构建在网络之上的普通服务，不是协议中的特殊角色。

## 社区自行选择保留期限

一个社区保存旧帖多久，由其运营者决定，而不是由协议规定。有些社区想保留多年的历史。另一些社区的设计目的就是遗忘：5chan 板块的运作方式类似图片板，主题会从板面落下，移入存档，并在设定时间后从板块节点清除（默认是 48 小时）。社区也可以完全跳过存档。

同一套协议能同时支持这两种方式，因为保留是每个社区设定的政策，而不是每个节点都必须承担的成本。

## 为什么不永久保存一切？

一个要求每个节点永久保存每一条帖子的网络，必须以某种方式为此付费：

- **区块链**要求每个完整节点保存全部历史，因此节点要求会随所有活动增长，发帖通常还要付费。
- **付费存储**，例如 Farcaster 的存储租金，要求用户付费保存自己的历史，并清除超出其付费范围的最旧帖子。请参阅[Bitsocial 与 Farcaster](/comparisons/farcaster/)。
- **中心服务器**保存一切，但只会在某家公司愿意保存、并按该公司规则行事期间如此。

社交媒体不需要全局账本。帖子 A 是否比帖子 B 早一毫秒被接受并不重要，而且大多数旧帖很少有人阅读。Bitsocial 让每个社区节点只保存自己的社区，使笔记本电脑、Raspberry Pi 或小型 VPS 的托管成本足够低。请参阅[为什么不用区块链？](/peer-to-peer-protocol/#why-not-a-blockchain)

## 取舍

如果没有人保存一条帖子的副本，它就可能变得不可用。帖子的 CID 永远不会改变，但 CID 只是一个地址：只有至少一个节点正在提供内容时，内容才可获取。如果一个社区的节点永久下线，而没有读者、做种者或存档者保存其帖子，那么这些帖子就消失了。

这是不要求全局账本的诚实代价。这也是每个大型平台本来就有的代价：当账号、服务器或公司消失时，它们上面的旧帖也会消失。不同之处在于，在 Bitsocial 上，保存某些内容不需要任何人的许可。

## 保留重要内容

- **自行运行社区节点。** 持续运行节点的社区运营者，会在社区设置允许保留的期间保存该社区的历史。
- **做种。** 保持桌面应用打开，或运行 `bitsocial-seeder`，都会让其他人能够访问社区。
- **存档。** 独立存档会在社区删除旧主题后，继续让它们可读、可搜索。[5archive.org](https://5archive.org)存档 5chan 板块，[seeditarchive.org](https://seeditarchive.org)存档 Seedit 社区。两者都是开源的，因此任何人都可以运行镜像或竞争性的存档。

由于每一条已存档的帖子仍然带有签名，存档无法悄悄改写某人说过的话：读者可以像校验在线帖子一样校验已存档帖子的签名。
