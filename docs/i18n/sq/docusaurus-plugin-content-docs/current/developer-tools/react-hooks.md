# React Hooks

`@bitsocial/bitsocial-react-hooks` u jep aplikacioneve React një API hooks-esh për protokollin Bitsocial: feed-e, komente, komunitete, profile autorësh, llogari dhe publikim, pa një server qendror. [5chan](/apps/5chan/) dhe [Seedit](/apps/seedit/) janë ndërtuar mbi të.

Biblioteka ka sajtin e vet të dokumentacionit, që përditësohet me çdo version të ri: **[hooks.bitsocial.net](https://hooks.bitsocial.net/)**.

## Instalimi

```bash
npm install @bitsocial/bitsocial-react-hooks
```

Paketa mbështet React 16.8 dhe versionet më të reja.

## Ku të filloni

- [Nisje e shpejtë](https://hooks.bitsocial.net/docs/quickstart/): shfaqni feed-in tuaj të parë të një komuniteti.
- [Konceptet](https://hooks.bitsocial.net/docs/concepts/): si lidhen me njëri-tjetrin feed-et, llogaritë lokale, gjendja e përbashkët dhe publikimi.
- [Referenca e API-së](https://hooks.bitsocial.net/docs/api/feeds-hooks/): çdo hook me opsionet dhe vlerat që kthen.
- [Playground](https://hooks.bitsocial.net/#playground): redaktoni shembuj interaktivë që ekzekutohen mbi përmbajtje të simuluar.
- [Ndërtoni me AI](https://hooks.bitsocial.net/docs/ai/): `llms.txt` dhe versione Markdown të çdo faqeje për agjentët e programimit.
