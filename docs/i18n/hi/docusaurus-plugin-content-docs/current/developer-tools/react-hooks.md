# React Hooks

`@bitsocial/bitsocial-react-hooks` React ऐप्स को Bitsocial प्रोटोकॉल के लिए एक hooks API देता है: फ़ीड, टिप्पणियाँ, समुदाय, लेखक प्रोफ़ाइल, खाते और प्रकाशन, वह भी किसी केंद्रीय सर्वर के बिना। [5chan](/apps/5chan/) और [Seedit](/apps/seedit/) इसी पर बने हैं।

इस लाइब्रेरी की अपनी दस्तावेज़ीकरण साइट है, जो हर रिलीज़ के साथ अपडेट होती है: **[hooks.bitsocial.net](https://hooks.bitsocial.net/)**।

## इंस्टॉलेशन

```bash
npm install @bitsocial/bitsocial-react-hooks
```

यह पैकेज React 16.8 और उसके बाद के संस्करणों को सपोर्ट करता है।

## शुरुआत कहाँ से करें

- [क्विकस्टार्ट](https://hooks.bitsocial.net/docs/quickstart/): अपनी पहली समुदाय फ़ीड रेंडर करें।
- [अवधारणाएँ](https://hooks.bitsocial.net/docs/concepts/): फ़ीड, स्थानीय खाते, साझा स्टेट और प्रकाशन आपस में कैसे जुड़ते हैं।
- [API संदर्भ](https://hooks.bitsocial.net/docs/api/feeds-hooks/): हर हुक, उसके विकल्पों और रिटर्न वैल्यू के साथ।
- [प्लेग्राउंड](https://hooks.bitsocial.net/#playground): सिम्युलेटेड सामग्री पर चलने वाले लाइव उदाहरणों को संपादित करें।
- [AI के साथ बनाएँ](https://hooks.bitsocial.net/docs/ai/): कोडिंग एजेंटों के लिए `llms.txt` और हर पेज के Markdown संस्करण।
