# React Hooks

O `@bitsocial/bitsocial-react-hooks` oferece aos aplicativos React uma API de hooks para o protocolo Bitsocial: feeds, comentários, comunidades, perfis de autores, contas e publicação, sem um servidor central. O [5chan](/apps/5chan/) e o [Seedit](/apps/seedit/) são construídos sobre ele.

A biblioteca tem seu próprio site de documentação, atualizado a cada versão: **[hooks.bitsocial.net](https://hooks.bitsocial.net/)**.

## Instalação

```bash
npm install @bitsocial/bitsocial-react-hooks
```

O pacote é compatível com o React 16.8 e versões posteriores.

## Por onde começar

- [Início rápido](https://hooks.bitsocial.net/docs/quickstart/): renderize seu primeiro feed de comunidade.
- [Conceitos](https://hooks.bitsocial.net/docs/concepts/): como feeds, contas locais, estado compartilhado e publicação se encaixam.
- [Referência da API](https://hooks.bitsocial.net/docs/api/feeds-hooks/): todos os hooks, com suas opções e valores de retorno.
- [Playground](https://hooks.bitsocial.net/#playground): edite exemplos ao vivo que rodam com conteúdo simulado.
- [Desenvolva com IA](https://hooks.bitsocial.net/docs/ai/): `llms.txt` e versões em Markdown de todas as páginas para agentes de programação.
