# สร้างไคลเอนต์ Bitsocial ของคุณเอง

Bitsocial ไม่ได้ชนะด้วยการมีแอปทางการเพียงแอปเดียวสำหรับทุกกรณีการใช้งาน แต่จะชนะเมื่อมีไคลเอนต์จำนวนมากที่ใช้โปรโตคอลเดียวกันร่วมกันได้ พร้อมกับแข่งขันกันในด้านอินเทอร์เฟซ วัฒนธรรม การค้นพบเนื้อหา ค่าเริ่มต้น และโมเดลธุรกิจ

5chan และ Seedit เป็นเพียงหลักฐานยืนยันในช่วงแรก ไม่ใช่ขีดจำกัดสูงสุด นักพัฒนาควรสามารถปล่อยอิมเมจบอร์ดใหม่ ฟอรัม ไคลเอนต์สำหรับโปรไฟล์ แอปโซเชียลที่เน้นมือถือเป็นหลัก เครื่องมือสำหรับชุมชนเฉพาะกลุ่ม หรือแม้แต่ไคลเอนต์แบบรวมศูนย์ที่ใช้ Bitsocial อยู่เบื้องหลัง ได้โดยไม่ต้องขออนุญาตจากเจ้าของแพลตฟอร์มรายใด

## สิ่งที่นักพัฒนาปรับเปลี่ยนได้

ไคลเอนต์ Bitsocial แข่งขันกันในระดับการตัดสินใจเชิงผลิตภัณฑ์ได้ โดยไม่ต้องฟอร์กทั้งเครือข่าย:

- อินเทอร์เฟซและภาษาทางภาพ
- ขั้นตอนการเริ่มต้นใช้งาน
- ค่าเริ่มต้นของชุมชน
- ส่วนติดต่อสำหรับการกำกับดูแลเนื้อหา
- โมเดลการค้นพบเนื้อหา
- ประสบการณ์ด้านสื่อ
- ข้อจำกัดของมือถือ เดสก์ท็อป หรือแบนด์วิดท์ต่ำ
- การสร้างรายได้และโมเดลธุรกิจ

เลเยอร์ที่ใช้ร่วมกันคือโปรโตคอล ส่วนเลเยอร์ผลิตภัณฑ์เปิดให้แข่งขันกันได้

## วิธีเรียนรู้ที่เร็วที่สุด

เริ่มจากแอปที่มีอยู่แล้ว:

- ลองใช้ [5chan](https://5chan.app) สำหรับชุมชนอิมเมจบอร์ดแบบไม่ระบุตัวตน
- ลองใช้ [Seedit](https://seedit.app) สำหรับการสนทนาสไตล์ Reddit
- อ่านเอกสาร [React hooks ของ Bitsocial](https://hooks.bitsocial.net/docs/quickstart/) สำหรับการผสานรวมฝั่งไคลเอนต์
- อ่านเอกสาร [Bitsocial CLI](/developer-tools/cli/) สำหรับการดูแลโหนดและชุมชน

หากอยากเดินหน้าเร็ว ให้เริ่มจากการมีส่วนร่วมกับแอปที่มีอยู่ก่อน หากอินเทอร์เฟซ วัฒนธรรม หรือโมเดลชุมชนที่คุณต้องการไม่ลงตัวกับแอปเหล่านั้น ค่อยสร้างไคลเอนต์แยกของคุณเอง

## เลือกเวอร์ชันแรกที่โฟกัสแคบ

เวอร์ชันแรกที่ดีที่สุดไม่ใช่แอปโซเชียลที่ครอบคลุมทุกอย่าง แต่คือไคลเอนต์ที่มีกลุ่มผู้ใช้ชัดเจนหนึ่งกลุ่ม และมีเหตุผลหนักแน่นหนึ่งข้อที่ทำให้มันควรมีอยู่

จุดเริ่มต้นที่ดีได้แก่:

- ไคลเอนต์อิมเมจบอร์ดที่สะอาดตากว่าเดิมสำหรับวัฒนธรรมเฉพาะกลุ่มหนึ่ง
- ไคลเอนต์ฟอรัมที่เน้นมือถือเป็นหลัก
- แอปสำหรับชุมชนเดียวที่มีค่าเริ่มต้นเข้มงวด
- ไคลเอนต์สำหรับชุมชนครีเอเตอร์
- ไคลเอนต์สำหรับการค้นพบเนื้อหาแบบอ่านอย่างเดียว
- คอนโซลสำหรับการกำกับดูแลเนื้อหาหรือสำหรับผู้ดูแลระบบ
- ไคลเอนต์ที่ปรับให้เหมาะกับภาษา ภูมิภาค หรือประเภทอุปกรณ์หนึ่งๆ

ไคลเอนต์ขนาดเล็กมีประโยชน์ เพราะ Bitsocial เปิดทางให้พวกมันเติบโตเข้าสู่เครือข่ายเดียวกัน แทนที่จะกักผู้ใช้ไว้ในฐานข้อมูลส่วนตัว

## แนวทางการพัฒนา

มีแนวทางที่ใช้ได้จริงอยู่สามแบบ:

1. ฟอร์กไคลเอนต์ที่มีอยู่ เมื่อไอเดียของคุณใกล้เคียงกับ 5chan หรือ Seedit
2. สร้างไคลเอนต์ React ตัวใหม่ด้วย [React hooks ของ Bitsocial](https://hooks.bitsocial.net/)
3. สร้างการผสานรวมของคุณเองบน API ของโหนดและโครงสร้างพื้นฐาน RPC สาธารณะ

RPC สาธารณะน่าจะทำให้แนวทางที่สามใช้งานได้จริงมากขึ้นอย่างมาก ผู้ใช้เริ่มต้นผ่านผู้ให้บริการ RPC แบบโฮสต์ที่ไม่ถือครองกุญแจของผู้ใช้ได้ แล้วค่อยย้ายไปโฮสต์เองหรือไปใช้ผู้ให้บริการรายอื่นในภายหลัง

## หลักการออกแบบ

สร้างไคลเอนต์ที่ควรมีอยู่สำหรับชุมชนของคุณ แล้วปล่อยให้ไคลเอนต์ที่เข้ากันได้แข่งขันกันอย่างเปิดเผย
