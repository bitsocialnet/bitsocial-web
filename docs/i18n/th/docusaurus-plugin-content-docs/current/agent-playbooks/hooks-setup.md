# Hooks ของเอเจนต์

Lifecycle hooks ที่คอมมิตไว้ทำหน้าที่เพียงจัดรูปแบบไฟล์ JavaScript/TypeScript ที่ถูกแก้ไขสำเร็จ ผ่าน oxfmt ที่ติดตั้งไว้ ตรรกะที่ใช้ร่วมกันอยู่ใน `scripts/agent-hooks/format.mjs` และ wrapper แบบเนทีฟของแต่ละแอปจะส่งต่องานไปยังไฟล์นี้

| แอป | การกำหนดค่าแบบเนทีฟ | อีเวนต์ |
|---|---|---|
| Codex | `.codex/hooks.json` | `PostToolUse`, `apply_patch` |
| Claude Code | `.claude/settings.json` | `PostToolUse`, `Edit|Write|MultiEdit` |
| Cursor | `.cursor/hooks.json` | `afterFileEdit` |

Claude ไม่อ่านไฟล์ `.claude/hooks.json` ที่แยกออกมาต่างหาก แต่ละแอปยังคงควบคุมการให้ความเชื่อถือโปรเจกต์และการเปิดใช้ hooks เอง ให้ตรวจการตั้งค่าปัจจุบันของแอปแทนการข้ามการตรวจความเชื่อถือ `.codex/config.toml` เป็นการกำหนดค่าของ repo ไม่ใช่ทะเบียนคำสั่ง hook

ตัวจัดรูปแบบตรวจสอบอีเวนต์/เพย์โหลด ความสำเร็จของการแก้ไข นามสกุลไฟล์ และการที่ไฟล์อยู่ภายใน repo จริง รวมถึงกรณี symlink หาก dependency ขาดหายหรืออินพุตไม่เกี่ยวข้อง ก็จะไม่มีการทำงานใด ๆ คำสั่งใช้อาร์เรย์อาร์กิวเมนต์โดยปิดการเข้าถึงเครือข่ายของ Corepack ไว้ hooks ไม่ติดตั้ง dependency ไม่รันบิลด์/รีวิว และไม่แก้ไขสถานะของ Git

รันการตรวจอย่างชัดแจ้งตาม [verification.md](https://github.com/bitsocialnet/bitsocial-web/blob/master/docs/agent-playbooks/verification.md) รัน `yarn ai-workflow:sync`, `yarn ai-workflow:check` และ `yarn ai-workflow:test` หลังเปลี่ยนเวิร์กโฟลว์ ฟิกซ์เจอร์ใช้ไฟล์แบบใช้แล้วทิ้งและการเรียกตัวจัดรูปแบบแบบจำลอง จึงไม่ได้พิสูจน์ว่าแต่ละแอปโหลดการกำหนดค่าของตัวเองแล้ว หลังอัปเกรดให้รีโหลดและตรวจดูแค็ตตาล็อกของแอป

สกิลออกแบบ Impeccable และตัวช่วยที่รันได้ของมันยังเรียกใช้ได้เมื่อต้องการภายใต้ `.agents/skills/impeccable` hook ของ Codex ตัวเดิมของสกิลนี้ชี้ไปยังไดเรกทอรีที่ไม่มีอยู่ ปัจจุบันเวิร์กโฟลว์การออกแบบจะทำงานเมื่อสกิลนั้นถูกเลือก โดยไม่มี hook ด้านการออกแบบที่ทำงานตลอดเวลา สกิลนี้ต้องไม่ตั้งค่า hooks ของโปรเจกต์ใหม่เป็นขั้นตอนพ่วงระหว่างงานออกแบบ
