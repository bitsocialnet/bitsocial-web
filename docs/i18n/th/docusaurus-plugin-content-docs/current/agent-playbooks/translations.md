# การแปล

เว็บ about ใช้ไฟล์ JSON ของ i18next ที่ `about/public/translations/{lang}/default.json` ส่วนงานแปลซอร์สของ Docusaurus แยกอยู่ใน `docs/i18n/`

## คีย์ของเว็บ about

ใช้ `.agents/skills/translate/SKILL.md` ค้นหาภาษาที่มีอยู่ในปัจจุบันจากดิสก์ และรักษาตัวยึดตำแหน่ง มาร์กอัป ศัพท์เทคนิค และชื่อแบรนด์ไว้ สำหรับคำขอขนาดใหญ่ เอเจนต์ลูกสามารถสร้างแผนที่การแปลที่เป็นอิสระต่อกันได้ แต่ต้องมีเอเจนต์แม่เพียงตัวเดียวที่เขียนทุกภาษาทีละรายการตามลำดับ เพราะตัวอัปเดตไม่มีล็อกสำหรับผู้เขียน

ใช้พาธแผนที่การแปลที่ไม่ซ้ำกันและเป็นของงานนั้นเอง ดูตัวอย่างผลก่อนด้วย `node scripts/update-translations.js --key <key> --map <map.json> --include-en --dry` แล้วนำไปใช้ด้วยอาร์กิวเมนต์ชุดเดียวกันพร้อม `--write` ตรวจความครอบคลุม/ค่าหลังเขียน และลบเฉพาะแผนที่การแปลชั่วคราวที่งานนี้เป็นเจ้าของ

ใช้ `--delete` สำหรับการลบที่ได้รับการร้องขอ ตรวจสิ่งที่ `--audit --dry` พบก่อนรัน `--audit --write` ที่ได้รับอนุญาต คีย์การแปลแบบไดนามิกต้องรีวิวซอร์สด้วยตนเอง คัดลอกข้อความภาษาอังกฤษไปทุกภาษาเฉพาะกรณีที่เป็นศัพท์เทคนิค แบรนด์ หรือตัวยึดตำแหน่งเท่านั้น

## หน้า Docusaurus

`scripts/translate-docs.py` เป็นตัวเขียนแบบเหมารวมสำหรับทุกหน้า/ทุกภาษา และไม่มีตัวกรองรายไฟล์ อย่าใช้มันกับการแก้ไขงานแปลในขอบเขตแคบ `scripts/check-docs-translations.py` เป็นตัวตรวจสอบแบบอ่านอย่างเดียว และรองรับ `--locales` และ `--paths`

รักษาบล็อกโค้ด ลิงก์ โค้ดแบบอินไลน์ ที่อยู่สัญญา หัวข้อ ตาราง และ admonition ให้ตรงกับต้นฉบับภาษาอังกฤษ แก้ข้อผิดพลาดที่ตัวตรวจสอบรายงาน ส่วนคำเตือน `frontmatter-untranslated` สำหรับชื่อแบรนด์เป็นสิ่งที่คาดไว้ได้ ปฏิบัติตาม `docs/AGENTS.md` และบิลด์ผ่าน root เมื่อเปลี่ยนธีมของเอกสารหรือพฤติกรรม i18n เพื่อให้เอาต์พุตแบบสแตติกและ Pagefind สอดคล้องกัน

## การรีวิวเชิงความหมายแบบเลือกได้

สำหรับคีย์ i18next ที่เลือก ให้ใช้ `scripts/jev/translation-README.md` สำหรับหน้าเอกสาร ให้รัน `node scripts/jev/docs-translations.mjs --locales it,de --paths browser-p2p.md` ก่อน คำสั่งนี้ต้องระบุภาษา/หน้าอย่างชัดเจน จะรันตัวตรวจสอบเชิงโครงสร้าง และรายงานการรีวิวเชิงความหมายว่ายังไม่ได้ตรวจสอบจนกว่าจะเปิดใช้การอนุมานแบบสด เพิ่ม `--live` เฉพาะเมื่องานได้รับอนุญาตและมีงบประมาณสำหรับผู้ให้บริการแล้ว การกำหนดค่าส่วนตัวที่ใช้ร่วมกันบนเครื่องจะจัดหาข้อมูลรับรองการเข้าถึงและโมเดลที่ปักหมุดไว้ ตัวแปรสภาพแวดล้อมและ `--model` สามารถแทนที่การตั้งค่านั้นได้ คำสั่งนี้ไม่แก้ไขงานแปลเลย

อะแดปเตอร์ระดับหน้ารักษาคอนเท็กซ์ของทั้งหน้าไว้ และจำกัดแต่ละหน้าไว้ที่ 24 KB และแต่ละการรันไว้ที่ 30 คู่ สำหรับหน้าที่ใหญ่กว่านั้น ให้เตรียมคู่ย่อหน้าต้นฉบับ/งานแปลที่จับคู่กันอย่างชัดแจ้งสำหรับ `translations.mjs --pairs` อย่าจับคู่ย่อหน้าตามลำดับโดยอัตโนมัติ ผลเชิงความหมายเป็นเพียงคำแนะนำ ให้ตรวจปัญหาและความไม่แน่นอนที่รายงานมา และคงการตรวจโค้ด/ลิงก์/ที่อยู่แบบกำหนดแน่นอนไว้
