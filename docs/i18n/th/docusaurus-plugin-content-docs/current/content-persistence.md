# โพสต์อยู่ที่ใดและอยู่นานแค่ไหน

Bitsocial ไม่ได้เก็บทุกโพสต์ไว้บนบล็อกเชนหรือในฐานข้อมูลของบริษัท โหนดของแต่ละชุมชนเก็บโพสต์ของตน ผู้อ่านและผู้ทำการซีดช่วยให้บริการโพสต์เหล่านั้น และใครก็ตามที่ต้องการบันทึกถาวรก็เก็บไว้ได้ การเก็บโพสต์ตลอดไปเป็น **ทางเลือก ไม่ใช่ข้อบังคับ**: โปรโตคอลไม่ได้บังคับให้ผู้เข้าร่วมทุกคนเก็บประวัติทั้งหมดของเครือข่าย

หน้านี้อธิบายความหมายในทางปฏิบัติ เพราะคำว่า "ไม่ได้เก็บตลอดไป" นั้นเข้าใจผิดได้ง่ายว่า "หายไป" หรือ "เชื่อฉันสิ"

## ความแท้จริงและความพร้อมใช้งานเป็นคนละคำถาม

มีคำถามสองข้อที่แตกต่างกันเกี่ยวกับโพสต์หนึ่งโพสต์:

1. **เป็นของจริงหรือไม่?** ผู้เขียนคนนี้เขียนโพสต์นี้หรือไม่ และชุมชนนี้ยอมรับโพสต์นั้นหรือไม่?
2. **ยังออนไลน์อยู่หรือไม่?** วันนี้ใครสักคนยังดึงโพสต์นั้นมาได้หรือไม่?

Bitsocial ตอบคำถามแรกด้วยการเข้ารหัสลับ ไม่ใช่ด้วยความไว้วางใจ ทุกโพสต์ลงนามด้วยคู่กุญแจของผู้เขียน และเมื่อชุมชนยอมรับแล้ว โพสต์จะถูกเก็บไว้ภายใต้ตัวระบุเนื้อหา (CID): แฮชของไบต์ที่ตรงตามนั้น ทุกคนที่ดึงโพสต์มาได้สามารถตรวจสอบลายเซ็นและแฮชได้ด้วยตนเอง โหนด เราเตอร์ เกตเวย์ หรือคลังเก็บถาวรไม่สามารถเปลี่ยนข้อความของโพสต์หรือปลอมโพสต์ในนามของผู้อื่นได้โดยที่การตรวจสอบไม่ล้มเหลว

คำถามข้อที่สองเกี่ยวกับว่าใครเก็บสำเนาไว้ และนั่นเป็นเพียงส่วนเดียวที่ไม่ได้รับประกัน

## ใครทำให้โพสต์ออนไลน์

- **โหนดของชุมชน** โหนดของเจ้าของรับโพสต์และเก็บไว้ในฐานข้อมูลตราบเท่าที่ชุมชนยังเก็บโพสต์นั้นไว้ นี่คือสำเนาหนึ่งเดียวที่มีอยู่เสมอตราบเท่าที่ชุมชนยังทำงานอยู่ ดู [โปรโตคอลเพียร์ทูเพียร์](/peer-to-peer-protocol/)
- **ผู้อ่าน** แอปเดสก์ท็อป เช่น แอปของ 5chan จะทำการซีดชุมชนที่โหลดไว้ขณะที่แอปกำลังทำงาน ดังนั้นชุมชนยอดนิยมจึงมีเพียร์จำนวนมากให้บริการ เช่นเดียวกับทอร์เรนต์ยอดนิยม แท็บเบราว์เซอร์สามารถแคชและตรวจสอบเนื้อหาได้ขณะที่เปิดอยู่ แต่ไม่ใช่โฮสต์ระยะยาว
- **ผู้ทำการซีด** [`bitsocial-seeder`](https://github.com/bitsocialnet/bitsocial-seeder) ให้ใครก็ตามช่วยเพิ่มความจุที่เปิดตลอดเวลาจาก VPS หรือเครื่องสำรองได้ มันตรึงหน้าล่าสุดและการอัปเดตโพสต์ของชุมชน ซึ่งยังทำให้ชุมชนที่โฮสต์อยู่หลังเราเตอร์ในบ้านโหลดจากเบราว์เซอร์ได้
- **ผู้เก็บถาวร** ใครก็สามารถรวบรวมข้อมูลจากชุมชนและเก็บทุกสิ่งที่เห็นได้ คลังเก็บถาวรเป็นบริการทั่วไปที่สร้างขึ้นบนเครือข่าย ไม่ใช่บทบาทพิเศษในโปรโตคอล

## ชุมชนเลือกระยะเวลาเก็บรักษาเอง

ระยะเวลาที่ชุมชนเก็บโพสต์เก่าเป็นการตัดสินใจของเจ้าของ ไม่ใช่กฎของโปรโตคอล บางชุมชนต้องการประวัติยาวนานหลายปี ชุมชนอื่นถูกออกแบบมาให้ลืม: บอร์ด 5chan ทำงานเหมือนอิมเมจบอร์ด ซึ่งเธรดจะหลุดจากบอร์ด ย้ายไปยังคลังเก็บถาวร แล้วถูกล้างออกจากโหนดของบอร์ดหลังเวลาที่กำหนด (ค่าเริ่มต้นคือ 48 ชั่วโมง) ชุมชนยังสามารถข้ามคลังเก็บถาวรไปทั้งหมดได้

โปรโตคอลเดียวกันรองรับทั้งสองแบบ เพราะการเก็บรักษาเป็นนโยบายที่แต่ละชุมชนกำหนด ไม่ใช่ต้นทุนที่ทุกโหนดต้องจ่าย

## เหตุใดไม่เก็บทุกอย่างตลอดไป?

เครือข่ายที่กำหนดให้ทุกโหนดต้องเก็บทุกโพสต์ตลอดไปต้องจ่ายค่าใช้จ่ายนั้นด้วยวิธีใดวิธีหนึ่ง:

- **บล็อกเชน** ทำให้โหนดเต็มทุกตัวเก็บประวัติทั้งหมด ดังนั้นข้อกำหนดของโหนดจึงเพิ่มขึ้นตามกิจกรรมทั้งหมด และการโพสต์มักมีค่าธรรมเนียม
- **พื้นที่เก็บข้อมูลแบบชำระเงิน** เช่น ค่าเช่าพื้นที่เก็บข้อมูลของ Farcaster ทำให้ผู้ใช้ต้องจ่ายเพื่อเก็บประวัติของตน และล้างโพสต์ที่เก่าที่สุดเกินกว่าที่ผู้ใช้จ่ายไว้ ดู [Bitsocial และ Farcaster](/comparisons/farcaster/)
- **เซิร์ฟเวอร์ส่วนกลาง** เก็บทุกอย่างไว้ แต่เพียงตราบเท่าที่บริษัทหนึ่งยังต้องการเก็บ ภายใต้กฎของบริษัทนั้น

โซเชียลมีเดียไม่ต้องการบัญชีแยกประเภทระดับโลก ไม่สำคัญว่าโพสต์ A จะได้รับการยอมรับก่อนโพสต์ B หนึ่งมิลลิวินาทีหรือไม่ และโพสต์เก่าส่วนใหญ่ก็แทบไม่ถูกอ่าน Bitsocial ให้แต่ละโหนดของชุมชนเก็บเฉพาะชุมชนของตนเอง ซึ่งทำให้การโฮสต์ถูกพอสำหรับแล็ปท็อป Raspberry Pi หรือ VPS ขนาดเล็ก ดู [ทำไมไม่ใช้บล็อกเชน](/peer-to-peer-protocol/#why-not-a-blockchain)

## ข้อแลกเปลี่ยน

หากไม่มีใครเก็บสำเนาของโพสต์ โพสต์นั้นอาจไม่พร้อมใช้งาน CID ของโพสต์ไม่เคยเปลี่ยนแปลง แต่ CID เป็นเพียงที่อยู่: เนื้อหาจะยังดึงได้ก็ต่อเมื่อมีอย่างน้อยหนึ่งโหนดให้บริการอยู่ หากโหนดของชุมชนออฟไลน์ไปตลอดกาล และไม่มีผู้อ่าน ผู้ทำการซีด หรือคลังเก็บถาวรเก็บโพสต์ไว้ โพสต์เหล่านั้นก็หายไป

นั่นคือต้นทุนที่ตรงไปตรงมาของการไม่บังคับให้มีบัญชีแยกประเภทระดับโลก และยังเป็นต้นทุนที่แพลตฟอร์มใหญ่ทุกแห่งมีอยู่แล้ว: โพสต์เก่าหายไปจากแพลตฟอร์มเหล่านั้นเมื่อบัญชี เซิร์ฟเวอร์ หรือบริษัทหายไป ความแตกต่างคือบน Bitsocial การเก็บบางสิ่งไว้ไม่ต้องขออนุญาตจากใคร

## เก็บสิ่งที่สำคัญ

- **รันโหนดของชุมชนด้วยตนเอง** เจ้าของชุมชนที่ทำให้โหนดยังคงทำงานอยู่ก็จะเก็บประวัติของชุมชนไว้ ตราบเท่าที่การตั้งค่าของชุมชนยังเก็บรักษาไว้
- **ทำการซีด** การเปิดแอปเดสก์ท็อปทิ้งไว้ หรือการรัน `bitsocial-seeder` ทำให้ชุมชนยังพร้อมใช้งานสำหรับผู้อื่น
- **เก็บถาวร** คลังเก็บถาวรอิสระทำให้เธรดเก่ายังอ่านและค้นหาได้หลังจากชุมชนเลิกเก็บพวกมัน [5archive.org](https://5archive.org) เก็บถาวรบอร์ด 5chan และ [seeditarchive.org](https://seeditarchive.org) เก็บถาวรชุมชน Seedit ทั้งสองเป็นโอเพนซอร์ส ดังนั้นใครก็สามารถรันมิเรอร์หรือคลังเก็บถาวรคู่แข่งได้

เนื่องจากโพสต์ที่เก็บถาวรทุกโพสต์ยังคงมีลายเซ็น คลังเก็บถาวรจึงไม่สามารถเขียนสิ่งที่ใครบางคนพูดใหม่อย่างเงียบ ๆ ได้: ผู้อ่านสามารถตรวจสอบลายเซ็นของโพสต์ที่เก็บถาวรได้เช่นเดียวกับโพสต์ที่ยังออนไลน์อยู่
