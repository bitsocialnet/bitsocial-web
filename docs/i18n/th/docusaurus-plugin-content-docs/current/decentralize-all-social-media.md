# กระจายอำนาจโซเชียลมีเดียทั้งหมด

สถานะปลายทางไม่ใช่แอปเพียงแอปเดียว แต่คือตลาดของไคลเอนต์ โหนด บริการ และชุมชน ที่แทนที่การเป็นเจ้าของแพลตฟอร์มด้วยการแข่งขันบนโปรโตคอลเดียวกัน

เฟส 5 คือช่วงที่ Bitsocial ก้าวข้ามหมวดหมู่ที่จัดลำดับความสำคัญไว้ในช่วงแรก และเริ่มให้ทุนกับรูปแบบโซเชียลให้ได้มากที่สุดเท่าที่จะทำได้

## สิ่งที่ยังต้องสร้าง

เฟสแรกๆ มุ่งไปที่หมวดหมู่ที่ให้ผลตอบแทนสูงสุด ได้แก่ อิมเมจบอร์ด ฟอรัม RPC สาธารณะ Bitsocial Chain โหนดโปรไฟล์ ทางเลือกแทน Twitter/X ในเฟส 3 และระบบเศรษฐกิจของบริการที่รายล้อมสิ่งเหล่านี้

หลังจากนั้น เครือข่ายควรขยายไปสู่กลุ่มปลายหางยาว:

- ไคลเอนต์สำหรับเขียนบล็อก
- แอประดมทุนจากมวลชน
- วิดีโอสำหรับครีเอเตอร์ และ [ทางเลือกแทน YouTube](https://github.com/bitsocialnet/wetube) ที่น่าเชื่อถือ
- ชุมชนของครีเอเตอร์
- การทดลองกับสื่อรูปแบบสั้น
- แอปโซเชียลเฉพาะท้องถิ่นหรือเฉพาะภาษา
- ไคลเอนต์เฉพาะกลุ่มที่เล็กเกินกว่าจะอยู่ในสี่เฟสแรก
- เครื่องมือที่ทำให้การดูแลชุมชนที่มีอยู่แล้วง่ายขึ้น

แอปเหล่านี้บางส่วนเป็นโอเพนซอร์สได้ บางส่วนเป็นไคลเอนต์แบบรวมศูนย์ได้ บางส่วน Bitsocial Forge สร้างเองได้ และอีกหลายส่วนควรถูกสร้างโดยนักพัฒนาอิสระ

## แนวคิดที่อยู่ระหว่างการวิจัย

แนวคิดบางส่วนเหล่านี้มีรีโพซิทอรีในระยะแนวคิดอยู่แล้ว ยังไม่มีสิ่งใดในนั้นถูกสร้างขึ้น
แต่ละรีโพซิทอรีรวบรวมการออกแบบและคำถามที่ยังเปิดอยู่ เพื่อให้นักพัฒนาและผู้ให้ทุนสามารถนำไปสานต่อได้

- [WeTube](https://github.com/bitsocialnet/wetube): ทางเลือกแทน YouTube
  ที่ทุกช่องเป็นคอมมูนิตี้ที่ครีเอเตอร์เป็นเจ้าของ
- [Gitcommons](https://github.com/bitsocialnet/gitcommons):
  งานวิจัยและสถาปัตยกรรมสำหรับทางเลือกแทน GitHub ที่สร้างบน Bitsocial
- [Infinipedia](https://github.com/bitsocialnet/infinipedia): สารานุกรมที่ไม่มีใครเป็นเจ้าของ
  ซึ่งกลุ่มบรรณาธิการเผยแพร่เวอร์ชันที่แข่งขันกัน และผู้อ่านเป็นผู้เลือก
- [Hopium](https://github.com/bitsocialnet/hopium): ทางเลือกแทน Fomo สำหรับการเทรดเชิงสังคม
  ที่ทุกคอลจะถูกตรวจสอบกับการเทรดบนเชนของผู้โพสต์
  และทุกโทเคนมีห้องที่มีเพียงผู้ถือเท่านั้นที่โพสต์ได้

## ให้ทุนนักพัฒนาจำนวนมาก

เป้าหมายคือทำให้ไคลเอนต์โซเชียลหน้าใหม่ขอทุนได้ตั้งแต่ก่อนที่จะมีฐานผู้ใช้ระดับแพลตฟอร์มอยู่ในมือ

ซึ่งอาจอยู่ในรูปของการลงทุนโดยตรง ทุนสนับสนุน การระดมทุนจากชุมชน รายได้จากบริการของ Bitsocial ที่ประสบความสำเร็จ หรือโครงการให้ทุนแบบกระจายอำนาจที่ให้ชุมชน Bitsocial ในวงกว้างช่วยตัดสินว่านักพัฒนารายใดควรได้รับการสนับสนุน

สิ่งสำคัญคือความหลากหลาย เครือข่ายควรให้ทุนกับความพยายามหลายๆ ครั้ง ไม่ใช่รอให้แอปทางการเพียงแอปเดียวครอบคลุมทุกหมวดหมู่

## ความสำเร็จหน้าตาเป็นอย่างไร

Bitsocial จะสำเร็จเมื่อโซเชียลมีเดียถูกแยกออกเป็นเลเยอร์ที่แทนที่กันได้:

- โปรโตคอล
- ชุมชน
- อัตลักษณ์
- การโฮสต์
- การค้นพบเนื้อหา
- การกำกับดูแลเนื้อหา
- การสร้างรายได้
- แอป

เมื่อเลเยอร์เหล่านั้นแทนที่กันได้ ก็ไม่จำเป็นต้องมีบริษัทใดบริษัทหนึ่งเป็นเจ้าของโซเชียลกราฟทั้งหมดเพื่อให้ผลิตภัณฑ์ทำงานได้

## เดิมพันหลัก

ระบบนิเวศ Bitsocial ที่เติบโตเต็มที่ควรประกอบด้วย RPC สาธารณะ โหนดที่โฮสต์เอง ตลาดอัลกอริทึมจัดฟีด ผู้ให้บริการโฮสต์สื่อ บริการค้นพบเนื้อหา ไคลเอนต์โอเพนซอร์ส ไคลเอนต์เชิงพาณิชย์ และการทดลองที่ได้รับทุนจากชุมชน

โซเชียลมีเดียได้พบจุดสมดุลของมันเสียที คือเครือข่ายสังคมแบบเพียร์ทูเพียร์ที่กระจายอำนาจเต็มรูปแบบและไม่มีใครเป็นเจ้าของ นั่นคือ Bitsocial
