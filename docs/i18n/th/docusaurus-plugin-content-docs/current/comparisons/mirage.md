# Bitsocial และ Mirage

[Mirage](https://mirage.foundation/) คือเครือข่ายพูดคุยแบบ Reddit ที่มีชุมชน โพสต์แบบเธรด และการโหวต
แทนที่จะใช้ฐานข้อมูลของบริษัท Mirage รันบนบล็อกเชนของตัวเอง ซึ่งเป็นเชน Cosmos SDK ที่ใช้ฉันทามติ
CometBFT ผลิตภัณฑ์ของ Bitsocial ที่ใกล้เคียงที่สุดคือ [Seedit](/apps/seedit/) แอปแบบ Reddit
บนเครือข่าย Bitsocial การเปรียบเทียบนี้จึงเน้นไปที่วิธีที่แต่ละฝ่ายโฮสต์ ถือครอง และกลั่นกรองชุมชน

## Mirage ทำงานอย่างไร

- **โหนด** โหนด Mirage คือคอนเทนเนอร์ Docker ตัวเดียวที่รวมผู้ตรวจสอบ (validator) ฐานข้อมูล
  PostgreSQL อินเด็กเซอร์ HTTP API และเว็บฟรอนต์เอนด์ไว้ด้วยกัน ทุกโหนดเป็นผู้ตรวจสอบด้วย ตาม
  [คู่มือการติดตั้งใช้งาน](https://github.com/MirageFoundation/mirage-node/blob/dev/docs/guides/deploy.md)
  การรันโหนดต้องใช้เซิร์ฟเวอร์ Ubuntu บน amd64 และโทเค็น MIRAGE 10,000,000
  โทเค็นในบัญชีของผู้ดำเนินการ
- **การโพสต์** เบราว์เซอร์ลงลายเซ็นทุกการกระทำด้วยกุญแจ secp256k1 ของผู้ใช้ และผู้ใช้ฟรียังต้องคำนวณ
  proof of work เล็ก ๆ ด้วย โหนดห่อการกระทำนั้นเป็นธุรกรรมบนเชนและจ่ายค่าธรรมเนียม
- **การอ่าน** อินเด็กเซอร์ของแต่ละโหนดคัดลอกข้อมูลเชนลงในฐานข้อมูลของตัวเอง และให้บริการฟีดผ่าน HTTP
  API โหนดเก็บบล็อกไว้ราวหนึ่งสัปดาห์ ประวัติโพสต์ระยะยาวจึงอยู่ในฐานข้อมูลของแต่ละโหนด
  และโหนดใหม่จะเริ่มต้นโดยไม่มีประวัติก่อนจุดซิงก์ของตน
- **บัญชี** บัญชีคือกุญแจที่ได้มาจากวลี seed 12 คำ และ seed เดียวกันใช้ได้กับทุกโหนด
  ชื่อผู้ใช้ถูกบันทึกบนเชนและไม่ซ้ำกันทั่วทั้งเครือข่าย
- **ชุมชน** ทุกชื่อที่ถูกต้องเป็นชุมชนอยู่แล้ว และไม่มีใครเป็นเจ้าของ ทีมผู้คัดสรรแบบเสียเงิน
  ซึ่งแต่ละทีมมีผู้ใช้ได้ไม่เกินสิบคน ดูแลมุมมองที่ผ่านการกลั่นกรองของชุมชน
  ผู้อ่านเลือกมุมมองของทีมใดทีมหนึ่ง มุมมองค่าเริ่มต้นของโหนด หรือมุมมองที่ไม่เซ็นเซอร์ ดู
  [Mirage FAQ](https://mirage.talk/faq)
- **โทเค็น** โทเค็น MIRAGE ใช้จ่ายค่าสมัครสมาชิก เป็นรางวัลให้ผู้เขียนและโหนด
  และให้น้ำหนักในการกำกับดูแลแก่ผู้ตรวจสอบ สมาชิกที่จ่ายค่าสมัครไม่ต้องทำ proof of work
  และได้รับขีดจำกัดที่สูงกว่า

## จุดที่ต่างกัน

### ใครเป็นเจ้าของชุมชน

ใน Seedit ผู้สร้างชุมชนถือคู่กุญแจของชุมชน รันหรือมอบหมายให้ผู้อื่นรันโหนดของชุมชน
และกลั่นกรองชุมชนนั้น ใน Mirage ไม่มีใครเป็นเจ้าของชุมชน
ทีมผู้คัดสรรที่แข่งขันกันนำเสนอมุมมองที่ผ่านการกลั่นกรองของชื่อเดียวกัน
และมุมมองค่าเริ่มต้นคือทีมที่สมาชิกแบบเสียเงินเลือกมากที่สุด

### การควบคุมสแปม

Mirage ใช้กฎเดียวกับทั้งเครือข่าย ผู้ใช้ฟรีจ่ายด้วย proof of work ซึ่งความยากปรับตามปริมาณที่เข้ามา
ส่วนสมาชิกที่จ่ายค่าสมัครได้รับการยกเว้น ใน Bitsocial แต่ละชุมชนเลือกชาเลนจ์ของตัวเอง ตั้งแต่แคปต์ชา
รายการที่อนุญาต ไปจนถึงการชำระเงิน ดู [ความท้าทายในการต่อต้านสแปมแบบกำหนดเอง](/custom-challenges/)

### โครงสร้างพื้นฐาน

Mirage ต้องมีบล็อกเชน ผู้ตรวจสอบต้องได้ฉันทามติในทุกการกระทำ
และแต่ละโหนดรันสแตกเซิร์ฟเวอร์เต็มรูปแบบและต้องถือโทเค็นจำนวนมากเป็นสเตก Bitsocial ไม่มีเชน
โหนดชุมชนรันบนฮาร์ดแวร์ระดับผู้บริโภคได้จากแอปเดสก์ท็อปหรือ `bitsocial-cli`
และผู้อ่านช่วยแบ่งปันเนื้อหาได้

### การควบคุมทั้งเครือข่าย

Mirage มีการกำกับดูแลบนเชนที่ถ่วงน้ำหนักตามสเตกของผู้ตรวจสอบ ระบบนี้เปลี่ยนความยาก ราคา
และอัตราการออกโทเค็นได้ สร้างหรือเผาโทเค็นได้
และแต่งตั้งผู้ดูแลระบบซึ่งอินเด็กเซอร์อ้างอิงจะนำการลบของพวกเขาไปใช้กับโพสต์ใดก็ได้
โค้ดของเชนยังให้ฝ่ายกำกับดูแล
[ลบบัญชี](https://github.com/MirageFoundation/mirage-node/blob/142a2e4e2542b6a3c9cc6d71591c282e5e5a9503/blockchain/x/core/module/module.go#L2572-L2573)
และ
[ส่งโทเค็นจากที่อยู่ใดก็ได้](https://github.com/MirageFoundation/mirage-node/blob/142a2e4e2542b6a3c9cc6d71591c282e5e5a9503/blockchain/x/core/module/module.go#L2656)
ได้ด้วย ในเดือนตุลาคม 2026 มีผู้ตรวจสอบสี่รายที่ผลิตบล็อกของเชน
และทั้งสี่รายถูกจัดการโดยคู่มือปฏิบัติงานของโครงการเอง

Bitsocial ไม่มีผู้ดูแลระบบระดับโปรโตคอล เจ้าของชุมชนกลั่นกรองชุมชนของตน และแอปเลือกเองว่าจะแสดงอะไร
ดู [การกลั่นกรองในท้องถิ่น ไม่ใช่การแบนทั่วโลก](/local-moderation/)

### เบราว์เซอร์

เว็บไคลเอนต์ของ Mirage เป็นไคลเอนต์ HTTP ของโหนด เบราว์เซอร์ลงลายเซ็นการกระทำ
แต่ไม่ได้เข้าร่วมเครือข่ายเพียร์ทูเพียร์ แอป Bitsocial รันโหนดเพียร์ทูเพียร์ภายในแท็บเบราว์เซอร์ได้
ดู [เพียร์ทูเพียร์ในเบราว์เซอร์](/browser-p2p/)
