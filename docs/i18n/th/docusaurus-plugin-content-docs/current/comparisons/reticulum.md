# Bitsocial และ Reticulum

[Reticulum](https://reticulum.network/) เป็นสแตกเครือข่ายที่อิงการเข้ารหัส
สำหรับสร้างเครือข่ายบนสื่อกลางรับส่งข้อมูลใดก็ได้ที่มีอยู่ ได้แก่ วิทยุ LoRa, วิทยุแพ็กเก็ต, ลิงก์อนุกรม,
Wi-Fi, Ethernet, TCP, UDP หรือ I2P มันมักถูกพูดถึงคู่กับ Bitsocial
เพราะทั้งสองอย่างตัดบริษัทที่อยู่ตรงกลางออกไป แต่ทำในชั้นที่ต่างกัน
ทั้งสองจึงเป็นสิ่งที่เสริมกันมากกว่าจะเป็นคู่แข่งกัน

## ชั้นที่ต่างกัน

Reticulum เข้ามาแทนที่ชั้นเครือข่าย มันมอบเอนด์พอยต์ที่เข้ารหัสและกำหนดเส้นทางได้ให้แก่แอปพลิเคชัน
โดยไม่ต้องใช้ที่อยู่ IP, DNS, ผู้ออกใบรับรอง หรือบัญชีผู้ใช้
และถูกออกแบบมาให้ทำงานต่อไปได้บนลิงก์ที่ช้าได้ถึง 5 บิตต่อวินาทีโดยมี MTU ขนาด 500 ไบต์
มันไม่ได้กำหนดโพสต์ ชุมชน หรือการกลั่นกรอง แอปพลิเคชันที่สร้างอยู่ด้านบนเป็นผู้เพิ่มสิ่งเหล่านั้นเข้าไป

Bitsocial เป็นโปรโตคอลโซเชียล มันรันบนสแตก IPFS/libp2p ผ่านการเชื่อมต่ออินเทอร์เน็ตทั่วไป
รวมถึงจากแท็บเบราว์เซอร์ และกำหนดชุมชน เนื้อหาที่เผยแพร่ และชาเลนจ์ป้องกันสแปมของแต่ละชุมชน
ดู [โปรโตคอลเพียร์ทูเพียร์](/peer-to-peer-protocol/) และ
[เพียร์ทูเพียร์ในเบราว์เซอร์](/browser-p2p/)

ในสแตกของ Bitsocial นั้น Reticulum จะอยู่ในตำแหน่งราว ๆ เดียวกับ libp2p
ไม่ใช่ตำแหน่งเดียวกับโปรโตคอล Bitsocial

## Reticulum ทำงานอย่างไร

- **ตัวตน** ตัวตนใน Reticulum คือชุดกุญแจขนาด 512 บิต ประกอบด้วยกุญแจ X25519 สำหรับการเข้ารหัส
  และกุญแจ Ed25519 สำหรับลายเซ็น
- **ปลายทาง** แอปพลิเคชันสร้างปลายทางขึ้นมา โดยแต่ละปลายทางระบุที่อยู่ด้วยแฮช SHA-256
  ที่ตัดให้เหลือ 16 ไบต์ แพ็กเก็ตไม่มีที่อยู่ต้นทางติดไปด้วย
- **การประกาศ** ปลายทางจะเข้าถึงได้ด้วยการส่งการประกาศออกไป โหนดทรานสปอร์ตจะส่งต่อการประกาศนั้น
  และจดจำฮอปถัดไปสำหรับเส้นทางย้อนกลับ จึงไม่มีโหนดใดต้องมีแผนที่ของทั้งเครือข่าย
- **การเข้ารหัส** ทราฟฟิกถูกเข้ารหัสโดยค่าเริ่มต้น โดยใช้กุญแจชั่วคราวและมี forward secrecy
- **LXMF** ชั้นรับส่งข้อความ [LXMF](https://github.com/markqvist/LXMF) เพิ่มข้อความที่มีลายเซ็น
  การส่งถึงผู้รับโดยตรง และการเก็บแล้วส่งต่อผ่านโหนดกระจายข้อความสำหรับผู้รับที่ออฟไลน์อยู่

แอปพลิเคชันที่สร้างด้วยวิธีนี้ได้แก่ [Sideband](https://github.com/markqvist/Sideband) สำหรับรับส่งข้อความ
และ [Nomad Network](https://github.com/markqvist/NomadNet) สำหรับรับส่งข้อความและโฮสต์หน้าเพจ
คู่มือของ Reticulum มี [รายชื่อโปรแกรม](https://reticulum.network/manual/software.html) รวบรวมไว้

## Bitsocial จะรันบน Reticulum ได้หรือไม่

ตอนนี้ยังไม่ได้ Bitsocial ยังไม่มีทรานสปอร์ตสำหรับ Reticulum
และโมเดลข้อมูลของมันตั้งอยู่บนสมมติฐานว่ามีแบนด์วิดท์ระดับอินเทอร์เน็ต
ไคลเอนต์ดึงข้อมูลเมตาของชุมชนและเนื้อหาโพสต์จากเพียร์ และแลกเปลี่ยนข้อความ pubsub
ซึ่งไม่เหมาะนักกับลิงก์ที่ออกแบบมารอบแพ็กเก็ตขนาด 500 ไบต์
และมีอัตราการส่งข้อมูลที่วัดกันเป็นบิตหรือกิโลบิตต่อวินาที

เส้นทางที่เป็นไปได้จริงนั้นแคบกว่า คือไคลเอนต์ที่ทำงานบนเครือข่ายเมชในพื้นที่ระหว่างที่ไม่ได้เชื่อมต่อ
แล้วซิงก์กับเครือข่าย Bitsocial ที่กว้างกว่าเมื่อเข้าถึงเพียร์หรือเกตเวย์ที่มีอินเทอร์เน็ตได้
สิ่งนี้จะเป็นไคลเอนต์และบริดจ์ตัวใหม่ มากกว่าจะเป็นการเปลี่ยนแปลงโปรโตคอล
และยังไม่อยู่ในแผนงานปัจจุบัน

## สำหรับนักพัฒนา

Reticulum เผยแพร่ภายใต้
[สัญญาอนุญาต Reticulum](https://reticulum.network/manual/license.html) ซึ่งมีเงื่อนไขแบบ MIT
บวกกับข้อจำกัดอีกสองข้อ คือห้ามใช้ซอฟต์แวร์นี้ในระบบที่ออกแบบมาเพื่อทำร้ายผู้คน
หรือในการสร้างชุดข้อมูลสำหรับฝึก AI หรือแมชชีนเลิร์นนิง
ควรอ่านสัญญาอนุญาตนี้ก่อนรวมโค้ด Reticulum เข้าไปในแอป Bitsocial

อิมพลีเมนเทชันอ้างอิง [เขียนด้วย Python](https://github.com/markqvist/Reticulum) ผู้ดูแล
Reticulum เตือนว่าพอร์ตที่ไม่เป็นทางการของ Reticulum และ LXMF หลายตัวสร้างขึ้นโดยเครื่อง
และมีการอ้างสิทธิ์ด้านสัญญาอนุญาตที่ผู้ดูแลถือว่าเป็นโมฆะ
จึงควรเลือกใช้อิมพลีเมนเทชันอ้างอิงหรือโปรแกรมที่อยู่ในรายชื่อของคู่มือ
