# Bitsocial และโซเชียลเน็ตเวิร์กบนบล็อกเชน

Lens, DeSo และ Steem ต่างก็นำกิจกรรมทางโซเชียลไปไว้บนบล็อกเชน บัญชี การติดตาม โพสต์
หรือกฎที่เกี่ยวข้อง กลายเป็นธุรกรรมที่ผู้ตรวจสอบ (validator) เรียงลำดับและจัดเก็บ Bitsocial
ไม่ใช้บล็อกเชน เพราะโซเชียลมีเดียไม่จำเป็นต้องมีลำดับระดับโลกสำหรับทุกโพสต์ Bitsocial
จึงไม่ต้องมีฉันทามติ ค่าแก๊ส หรือการสเตก ดูเหตุผลเรื่องนี้ได้ที่
[โปรโตคอลเพียร์ทูเพียร์](/peer-to-peer-protocol/)

## สิ่งที่มีเหมือนกัน

- **มีคนต้องจ่ายเงินทุกครั้งที่เขียนข้อมูล** Lens เก็บค่าแก๊ส ซึ่งแอปสามารถออกให้แทนได้ DeSo
  เก็บค่าธรรมเนียมทุกการกระทำ ส่วน Steem จำกัดการกระทำตามจำนวนโทเค็นที่สเตกไว้
- **เชนกำหนดนโยบายสแปมเดียวสำหรับทุกคน** ค่าธรรมเนียม การสเตก และต้นทุนบัญชีมีผลทั่วทั้งเครือข่าย
  แทนที่แต่ละชุมชนจะเลือกเอง
- **บันทึกบนเชนเป็นของถาวร** แอปซ่อนเนื้อหาได้ แต่ลบเนื้อหาออกจากเชนไม่ได้
- **เบราว์เซอร์เป็นไคลเอนต์ API** เว็บแอปลงลายเซ็นธุรกรรม และอ่านข้อมูลผ่านโหนด อินเด็กเซอร์ หรือ
  API ที่คนอื่นเป็นผู้ดำเนินการ

## Lens

[Lens](https://lens.xyz/) รันบน Lens Chain ซึ่งเป็นเลเยอร์ 2 ของ Ethereum ที่สร้างด้วย ZK Stack ของ
ZKsync และใช้ Avail สำหรับความพร้อมใช้งานของข้อมูล Mask Network
[ดูแล Lens มาตั้งแต่เดือนมกราคม 2026](https://lens.xyz/news/mask-network-to-steward-the-next-chapter-of-lens)

- **บนเชน:** บัญชีคือสมาร์ตคอนแทรกต์ ชื่อผู้ใช้คือ NFT ภายในเนมสเปซ และกราฟ กลุ่ม ฟีด
  รวมถึงกฎของสิ่งเหล่านี้ก็เป็นคอนแทรกต์เช่นกัน
- **นอกเชน:** ข้อความและสื่อของโพสต์อยู่ในไฟล์ JSON ที่ URI หนึ่ง ซึ่งมักอยู่บน Grove
  บริการจัดเก็บข้อมูลของ Lens ที่อยู่หน้า IPFS รีแอ็กชันและบุ๊กมาร์กถูกเก็บโดย Lens API
  และแอปอ่านข้อมูลผ่าน API นั้น
- **สแปมและด่าน:** ธุรกรรมต้องใช้ค่าแก๊สเป็น GHO ซึ่งแอปออกให้แทนได้โดยมีการจำกัดอัตรา
  กฎของฟีดและกลุ่มอาจกำหนดให้ต้องถือโทเค็นหรือชำระเงิน
- **การดำเนินงานของเชน:** [L2BEAT](https://l2beat.com/scaling/projects/lens) จัดให้ Lens Chain เป็น
  validium ระดับ Stage 0 ที่มีผู้ดำเนินการแบบรวมศูนย์ซึ่งปฏิเสธไม่รวมธุรกรรมได้

## DeSo

[DeSo](https://docs.deso.org/) คือบล็อกเชนเลเยอร์ 1 ที่สร้างมาสำหรับแอปโซเชียล ซึ่งเปลี่ยนจาก proof
of work มาเป็น proof of stake ในเดือนกรกฎาคม 2024

- **บนเชน:** โปรไฟล์ โพสต์ ไลก์ การติดตาม และข้อความส่วนตัว ล้วนเป็นธุรกรรมที่โหนดเต็มทุกตัวจัดเก็บ
  รูปภาพและวิดีโอโฮสต์ไว้นอกเชน โดยโหนดอ้างอิงใช้ Google Cloud Storage และ Cloudflare Stream
- **สแปม:** ทุกการกระทำต้องจ่ายค่าธรรมเนียมเป็น DESO ผู้ใช้ใหม่มักได้รับ DESO
  เริ่มต้นจากโหนดหลังยืนยันเบอร์โทรศัพท์
- **การกลั่นกรอง:** แต่ละโหนดตัดสินใจเองว่าจะแสดงอะไรด้วยการขึ้นบัญชีดำหรือบัญชีเทา แต่
  [เนื้อหายังคงอยู่บนเชน](https://docs.deso.org/deso-blockchain/content-moderation)
- **ชุมชน:** เอกสารไม่ได้อธิบายองค์ประกอบพื้นฐานสำหรับชุมชนหรือฟอรัมไว้ “ชุมชน”
  คือฟีดที่แอปคัดสรรขึ้น
- **การรันโหนด:** ตาม [คู่มือผู้ตรวจสอบ](https://docs.deso.org/deso-validators/run-a-validator)
  ผู้ตรวจสอบต้องมี RAM อย่างน้อย 32 GB และดิสก์ 200 GB

## Steem

[Steem](https://steem.com/) คือบล็อกเชนโซเชียลที่จ่ายโทเค็นให้ผู้เขียนและผู้คัดสรร โดยมี
[Steemit](https://steemit.com/) เป็นแอปบล็อกหลัก Hive แยกตัวออกจาก Steem ในปี 2020 ตาม
[whitepaper ของ Hive](https://hive.io/whitepaper.pdf) การฟอร์กเกิดขึ้นหลังการขาย Steemit Inc. ให้
Justin Sun

- **บนเชน:** โพสต์ข้อความ คอมเมนต์ โหวต และประวัติการแก้ไขของสิ่งเหล่านี้ เรียงลำดับโดย witness
  ที่ได้รับเลือก 21 ราย ซึ่งผลิตบล็อกทุกสามวินาที รูปภาพโฮสต์ไว้นอกเชน
- **สแปม:** การกระทำต่าง ๆ ใช้ Resource Credits ซึ่งเพิ่มขึ้นตาม STEEM ที่สเตกไว้
  การสร้างบัญชีมีค่าใช้จ่ายเป็น STEEM โดย Steemit จ่ายแทนให้ผู้ใช้ที่ยืนยันอีเมลและเบอร์โทรศัพท์
- **ชุมชน:** ชุมชนคือ
  [การดำเนินการแบบกำหนดเองที่อินเด็กเซอร์เป็นผู้ตีความ](https://github.com/steemit/hivemind/blob/master/docs/communities.md)
  นอกฉันทามติ ผู้ดูแลปิดเสียงโพสต์ได้ ซึ่งจะซ่อนโพสต์ในแอป แต่โพสต์ยังคงอยู่บนเชน
- **รางวัล:** เงินเฟ้อเป็นแหล่งทุนของรางวัล และโหวตที่ถ่วงน้ำหนักตามสเตกเป็นตัวตัดสินการแบ่งรางวัล
  ผู้ถือรายใหญ่จึงเป็นผู้กำหนดว่าอะไรจะได้รับความสนใจ
