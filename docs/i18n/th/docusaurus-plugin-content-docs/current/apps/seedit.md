# Seedit

Seedit เป็นทางเลือกแบบไร้เซิร์ฟเวอร์ ไร้ผู้ดูแลระบบ และกระจายอำนาจเต็มรูปแบบ แทน Reddit แบบเก่า ที่สร้างขึ้นบนโปรโตคอล Bitsocial มันช่วยให้ผู้ใช้เป็นเจ้าของชุมชนของตนโดยสมบูรณ์ — ใครๆ ก็สามารถสร้างได้ และหลายชุมชนสามารถแข่งขันกันเพื่อชิงเส้นทางสั้นเดียวกันได้ เช่น `/s/funny`

## ดาวน์โหลด

| แพลตฟอร์ม  | ลิงค์                                                  |
| ---------- | ------------------------------------------------------ |
| เว็บ       | [seedit.app](https://seedit.app)                       |
| เว็บ (ENS) | `seedit.eth` ผ่านเบราว์เซอร์ Brave หรือ IPFS Companion |
| เดสก์ท็อป  | ใช้งานได้กับ Mac, Windows และ Linux                    |
| มือถือ     | ใช้งานได้กับ Android                                   |

## ชุมชนทำงานอย่างไร

Seedit จัดระเบียบเนื้อหาออกเป็นชุมชนที่คล้ายกับ subreddits แต่ละชุมชนเป็นของผู้สร้างและดำเนินงานโดยไม่มีการบริหารแบบรวมศูนย์ หลายชุมชนสามารถแข่งขันกันเพื่อชิงเส้นทาง[ไดเรกทอรี](/directories/)เดียวกันได้ เช่น `/s/funny` ซึ่งจะเปิดผู้ชนะในปัจจุบัน การสมัครติดตามและลิงก์โพสต์จะชี้ไปยังชุมชนที่เจาะจงเสมอ

### การสร้างชุมชน

มีสองวิธีในการสร้างชุมชนใหม่:

1. **ไคลเอ็นต์เดสก์ท็อป** — ใช้ GUI ในตัวในแอปพลิเคชันเดสก์ท็อปเพื่อตั้งค่าและกำหนดค่าชุมชนของคุณ
2. **bitsocial-cli** — เรียกใช้เครื่องมือ CLI เพื่อสร้างและจัดการชุมชนจากบรรทัดคำสั่ง

### รายการชุมชนเริ่มต้น

บัญชีใหม่จะสมัครติดตามรายการเริ่มต้นที่ระบุชุมชนแบบเจาะจง ซึ่งกำหนดไว้ใน `seedit-default-subscriptions.json` ในรีโพซิทอรี [bitsocialnet/lists](https://github.com/bitsocialnet/lists) ส่วนผู้สมัครของไดเรกทอรีจะอยู่ในไฟล์ `seedit-directories/seedit-<code>-directory.json` ในรีโพซิทอรีเดียวกัน หากต้องการเพิ่มชุมชนของคุณลงในรายการใดรายการหนึ่ง ให้ส่ง pull request พร้อมรายละเอียดของชุมชนของคุณ
