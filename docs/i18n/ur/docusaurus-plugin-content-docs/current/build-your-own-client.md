# اپنا Bitsocial کلائنٹ بنائیں

Bitsocial کی کامیابی اس میں نہیں کہ ہر ضرورت کے لیے ایک ہی سرکاری ایپ ہو۔ کامیابی تب ہے جب بہت سے کلائنٹ ایک
ہی پروٹوکول پر چلیں اور انٹرفیس، کلچر، دریافت، ڈیفالٹس اور کاروباری ماڈل پر ایک دوسرے سے مقابلہ کریں۔

5chan اور Seedit ابتدائی مثالیں ہیں، کوئی حد نہیں۔ ایک بلڈر کو کسی پلیٹ فارم مالک سے اجازت لیے بغیر نیا
امیج بورڈ، فورم، پروفائل کلائنٹ، موبائل فرسٹ سماجی ایپ، کسی مخصوص کمیونٹی کا ٹول، یا ایسا مرکزی کلائنٹ جاری
کرنے کے قابل ہونا چاہیے جو اندر ہی اندر Bitsocial استعمال کرتا ہو۔

## بلڈرز کیا بدل سکتے ہیں

ایک Bitsocial کلائنٹ پورے نیٹ ورک کو فورک کیے بغیر پروڈکٹ کے فیصلوں پر مقابلہ کر سکتا ہے:

- انٹرفیس اور بصری زبان
- آن بورڈنگ کا طریقہ
- کمیونٹی کے ڈیفالٹس
- ماڈریشن کے انٹرفیس
- دریافت کا ماڈل
- میڈیا کا تجربہ
- موبائل، ڈیسک ٹاپ یا کم بینڈوڈتھ کی پابندیاں
- کمائی اور کاروباری ماڈل

مشترکہ تہہ پروٹوکول ہے۔ پروڈکٹ کی تہہ مقابلے کے لیے کھلی ہے۔

## سیکھنے کا تیز ترین راستہ

انہی ایپس سے شروع کریں جو پہلے سے موجود ہیں:

- گمنام امیج بورڈ کمیونٹیز کے لیے [5chan](https://5chan.app) آزمائیں۔
- Reddit طرز کی گفتگو کے لیے [Seedit](https://seedit.app) آزمائیں۔
- کلائنٹ سائیڈ انضمام کے لیے [Bitsocial React hooks](https://hooks.bitsocial.net/docs/quickstart/) کی دستاویزات پڑھیں۔
- نوڈ اور کمیونٹی آپریشنز کے لیے [Bitsocial CLI](/developer-tools/cli/) کی دستاویزات پڑھیں۔

اگر آپ تیزی سے آگے بڑھنا چاہتے ہیں تو پہلے کسی موجودہ ایپ میں حصہ ڈالیں۔ اگر آپ کو مطلوبہ انٹرفیس، کلچر یا
کمیونٹی ماڈل وہاں فٹ نہ آئے تو الگ کلائنٹ بنائیں۔

## پہلا ورژن محدود رکھیں

بہترین پہلا ورژن کوئی ہمہ گیر سماجی ایپ نہیں ہوتا۔ یہ ایسا کلائنٹ ہوتا ہے جس کے سامعین واضح ہوں اور جس کے
وجود کی ایک مضبوط وجہ ہو۔

اچھے نقطۂ آغاز میں یہ شامل ہیں:

- کسی ایک مخصوص کلچر کے لیے صاف ستھرا امیج بورڈ کلائنٹ
- موبائل فرسٹ فورم کلائنٹ
- سخت ڈیفالٹس والی واحد کمیونٹی کی ایپ
- تخلیق کاروں کی کمیونٹی کا کلائنٹ
- صرف پڑھنے کے لیے دریافت کا کلائنٹ
- ماڈریشن یا آپریٹر کنسول
- کسی زبان، خطے یا ڈیوائس کی قسم کے لیے بہتر بنایا گیا کلائنٹ

چھوٹے کلائنٹ اس لیے کارآمد ہیں کہ Bitsocial انہیں اپنے صارفین کو کسی نجی ڈیٹابیس میں قید کرنے کے بجائے اسی
نیٹ ورک میں بڑھنے دیتا ہے۔

## عمل درآمد کے راستے

عملی طور پر تین راستے ہیں:

1. جب آپ کا خیال 5chan یا Seedit کے قریب ہو تو کسی موجودہ کلائنٹ کو فورک کریں۔
2. [Bitsocial React hooks](https://hooks.bitsocial.net/) کی مدد سے نیا React کلائنٹ بنائیں۔
3. نوڈ APIs اور عوامی RPC انفراسٹرکچر کے اوپر اپنا انضمام خود بنائیں۔

عوامی RPC تیسرے راستے کو کہیں زیادہ عملی بنا دے گا۔ صارف کسی ہوسٹ شدہ، غیر تحویلی RPC فراہم کنندہ سے شروع
کر سکتا ہے اور بعد میں خود میزبانی یا کسی مدمقابل فراہم کنندہ کی طرف منتقل ہو سکتا ہے۔

## ڈیزائن کا اصول

وہ کلائنٹ بنائیں جو آپ کی کمیونٹی کے لیے موجود ہونا چاہیے، پھر ہم آہنگ کلائنٹس کو کھلے میدان میں مقابلہ
کرنے دیں۔
