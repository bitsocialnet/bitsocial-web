# ایجنٹ ہکس

کمٹ شدہ لائف سائیکل ہکس صرف اتنا کرتے ہیں کہ کامیابی سے ترمیم شدہ JavaScript/TypeScript فائلوں کو انسٹال شدہ oxfmt کے ذریعے فارمیٹ کر دیں۔ مشترکہ منطق `scripts/agent-hooks/format.mjs` میں ہے؛ ہر نیٹو ریپر کام اسی کے سپرد کرتا ہے۔

| ایپ | نیٹو کنفیگریشن | ایونٹ |
|---|---|---|
| Codex | `.codex/hooks.json` | `PostToolUse`, `apply_patch` |
| Claude Code | `.claude/settings.json` | `PostToolUse`, `Edit|Write|MultiEdit` |
| Cursor | `.cursor/hooks.json` | `afterFileEdit` |

Claude کوئی الگ `.claude/hooks.json` نہیں پڑھتا۔ پروجیکٹ پر اعتماد اور ہکس کے فعال ہونے یا نہ ہونے کا اختیار بدستور ہر ایپ کے پاس ہے؛ اعتماد کو بائی پاس کرنے کے بجائے اس کی موجودہ ترتیبات کا معائنہ کریں۔ `.codex/config.toml` ریپوزٹری کی کنفیگریشن ہے، ہک کمانڈز کی رجسٹری نہیں۔

فارمیٹر ایونٹ/پے لوڈ، ترمیم کی کامیابی، فائل ایکسٹینشن، اور سِم لنکس سمیت فائل کے ریپوزٹری کے اندر ہونے کی توثیق کرتا ہے۔ انحصارات غائب ہوں یا ان پٹ غیر متعلق ہو تو کوئی کام نہیں ہوتا۔ کمانڈز آرگیومنٹس کی ایک ایرے استعمال کرتی ہیں اور Corepack کی نیٹ ورک رسائی بند رہتی ہے؛ ہکس نہ انحصارات انسٹال کرتے ہیں، نہ بلڈز/ریویوز چلاتے ہیں، اور نہ Git میں کوئی تبدیلی کرتے ہیں۔

جانچیں [verification.md](https://github.com/bitsocialnet/bitsocial-web/blob/master/docs/agent-playbooks/verification.md) کے مطابق صراحتاً چلائیں۔ ورک فلو بدلنے کے بعد `yarn ai-workflow:sync`، `yarn ai-workflow:check` اور `yarn ai-workflow:test` چلائیں۔ فکسچرز عارضی فائلیں اور فرضی فارمیٹر کالز استعمال کرتے ہیں؛ یہ ثابت نہیں کرتے کہ ہر ایپ نے اپنی کنفیگریشن لوڈ کر لی ہے۔ اپ گریڈ کے بعد ایپ کو دوبارہ لوڈ کریں اور اس کے کیٹلاگ کا معائنہ کریں۔

Impeccable ڈیزائن اسکل اور اس کے قابلِ اجرا ہیلپرز `.agents/skills/impeccable` کے تحت ضرورت پڑنے پر دستیاب رہتے ہیں۔ اس کا سابقہ Codex ہک ایک غیر موجود ڈائریکٹری کی طرف اشارہ کرتا تھا؛ اب ڈیزائن ورک فلو اُس وقت چلتا ہے جب اس کی اسکل منتخب کی جائے، اور کوئی ہمیشہ فعال رہنے والا ڈیزائن ہک نہیں ہے۔ اسکل کو ڈیزائن کے کسی ضمنی قدم کے طور پر پروجیکٹ ہکس کی کنفیگریشن نہیں بدلنی چاہیے۔
