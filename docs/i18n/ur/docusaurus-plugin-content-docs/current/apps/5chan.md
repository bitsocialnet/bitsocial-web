# 5chan

5chan ایک سرور لیس، ایڈمن سے پاک اور مکمل طور پر غیر مرکزی امیج بورڈ ہے جو Bitsocial پروٹوکول پر چلتا ہے۔ یہ امیج بورڈز کے مانوس ڈائریکٹری ڈھانچے کی پیروی کرتا ہے، مگر ساتھ ہی غیر مرکزی ملکیت متعارف کراتا ہے — کوئی بھی بورڈ بنا سکتا ہے، اور متعدد بورڈ ووٹنگ کے ذریعے ایک ہی ڈائریکٹری سلاٹ کے لیے مقابلہ کر سکتے ہیں۔

## ڈاؤن لوڈز

| پلیٹ فارم | لنک                                  |
| --------- | ------------------------------------ |
| ویب       | [5chan.app](https://5chan.app)       |
| ڈیسک ٹاپ  | Mac، Windows اور Linux کے لیے دستیاب |
| موبائل    | Android کے لیے دستیاب                |

## بورڈز کیسے کام کرتے ہیں

5chan مواد کو کلاسک ڈائریکٹری ترتیب (مثلاً `/b/`، `/g/`) کے ذریعے بورڈز میں منظم کرتا ہے۔ روایتی امیج بورڈز کے برعکس، جہاں ایک مرکزی ایڈمن ہر بورڈ کو کنٹرول کرتا ہے، 5chan ہر صارف کو اپنا بورڈ بنانے اور اس کا مکمل مالک ہونے کی اجازت دیتا ہے۔ جب متعدد بورڈ ایک ہی ڈائریکٹری سلاٹ کو نشانہ بناتے ہیں، تو وہ اس پوزیشن کے لیے مقابلہ کرتے ہیں؛ دیکھیں [ڈائریکٹریز](/directories/)۔

### بورڈ بنانا

نیا بورڈ بنانے کے لیے آپ کو `bitsocial-cli` کو ایک peer-to-peer نوڈ کے طور پر چلانا ہوگا۔ اس سے یقینی بنتا ہے کہ آپ کا بورڈ کسی مرکزی سرور پر انحصار کیے بغیر غیر مرکزی طریقے سے میزبان ہو۔

### ڈائریکٹری تفویض

ہر ڈائریکٹری کے امیدوار بورڈز [bitsocialnet/lists](https://github.com/bitsocialnet/lists) ریپوزٹری میں ایک `5chan-directories/5chan-<code>-directory.json` فائل میں درج ہوتے ہیں، اور کوئی بورڈ اس فائل پر pull request کے ذریعے ڈائریکٹری میں شامل ہوتا ہے۔ 5chan ہر ڈائریکٹری کے لیے [`@bitsocial/pubsub-voting`](https://github.com/bitsocialnet/pubsub-voting) کے ذریعے ایک ووٹنگ مقابلہ بھی چلاتا ہے: ہر 5chan Pass ہولڈر کو ایک ووٹ ملتا ہے، اور کسی غیر درج شدہ بورڈ کو ووٹ دینا اسے نامزد کر دیتا ہے۔ یہ مقابلے فی الحال Base Sepolia ٹیسٹ نیٹ پر چل رہے ہیں، جہاں نتائج دکھائے جاتے ہیں لیکن فہرست کی ترتیب نہیں بدلتے۔

## اندرونی ساخت

پردے کے پیچھے 5chan اپنے نیٹ ورک رابطوں کے لیے مشترکہ Bitsocial پروٹوکول کلائنٹ لیئر استعمال کرتا ہے۔
5chan.app پر موجود ویب ایپ بطور ڈیفالٹ براؤزر میں Helia نوڈ چلاتی ہے، اس لیے ایک عام ٹیب بھی نیٹ ورک میں
بطور peer شامل ہو جاتا ہے: یہ دوسرے peers سے بورڈ لوڈ کرتا ہے اور pubsub پر شائع کرتا ہے، اور مواد کے راستے
میں کوئی مرکزی IPFS گیٹ وے نہیں ہوتا۔ اس کے تقاضے کیا ہیں اور براؤزر نوڈ اب بھی کیا نہیں کر سکتا، اس کے لیے
[براؤزر Peer-to-Peer](/browser-p2p/) دیکھیں۔
