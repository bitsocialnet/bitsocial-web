# Bitsocial اور بلاک چین سوشل نیٹ ورکس

Lens، DeSo اور Steem میں سے ہر ایک سوشل سرگرمی کو بلاک چین پر رکھتا ہے۔ اکاؤنٹس، فالوز، پوسٹس یا ان
سے متعلق قواعد ایسی ٹرانزیکشنز بن جاتے ہیں جنہیں ویلیڈیٹرز ترتیب دیتے اور محفوظ کرتے ہیں۔ Bitsocial
کوئی بلاک چین استعمال نہیں کرتا: سوشل میڈیا کو ہر پوسٹ کے لیے عالمی ترتیب کی ضرورت نہیں، اس لیے
Bitsocial اتفاقِ رائے، گیس اور اسٹیکنگ سے بچ جاتا ہے۔ اس استدلال کے لیے دیکھیں
[پیئر ٹو پیئر پروٹوکول](/peer-to-peer-protocol/)۔

## ان میں کیا مشترک ہے

- **ڈیٹا لکھنے کے ہر عمل کی قیمت کوئی ادا کرتا ہے۔** Lens گیس وصول کرتا ہے، جسے ایپس اسپانسر کر سکتی
  ہیں؛ DeSo ہر عمل پر فیس لیتا ہے؛ Steem اسٹیک کیے گئے ٹوکنز کے حساب سے اعمال کا کوٹہ دیتا ہے۔
- **چین سب کے لیے ایک ہی اسپیم پالیسی طے کرتی ہے۔** فیسیں، اسٹیک اور اکاؤنٹ کی لاگت ہر کمیونٹی کے
  اپنے انتخاب کے بجائے پورے نیٹ ورک پر لاگو ہوتی ہیں۔
- **آن چین ریکارڈ مستقل ہوتے ہیں۔** ایپس مواد چھپا سکتی ہیں، مگر اسے چین سے ہٹا نہیں سکتیں۔
- **براؤزرز API کلائنٹس ہیں۔** ویب ایپس ٹرانزیکشنز پر دستخط کرتی ہیں اور کسی اور کے چلائے ہوئے نوڈ،
  انڈیکسر یا API کے ذریعے پڑھتی ہیں۔

## Lens

[Lens](https://lens.xyz/) Lens Chain پر چلتا ہے، جو ZKsync کے ZK Stack سے بنا Ethereum کا لیئر 2 ہے
اور ڈیٹا کی دستیابی کے لیے Avail استعمال کرتا ہے۔ Mask Network
[جنوری 2026 سے Lens کی نگرانی سنبھالے ہوئے ہے](https://lens.xyz/news/mask-network-to-steward-the-next-chapter-of-lens)۔

- **چین پر:** اکاؤنٹس اسمارٹ کانٹریکٹس ہیں، یوزر نیمز نیم اسپیسز کے اندر NFTs ہیں، اور گرافس، گروپس،
  فیڈز اور ان کے قواعد بھی کانٹریکٹس ہیں۔
- **چین سے باہر:** پوسٹ کا متن اور میڈیا کسی URI پر ایک JSON فائل میں ہوتے ہیں، عام طور پر Grove پر،
  جو IPFS کے آگے کام کرنے والی Lens کی اسٹوریج سروس ہے۔ ری ایکشنز اور بک مارکس Lens API کے پاس رہتے
  ہیں، اور ایپس اسی API کے ذریعے پڑھتی ہیں۔
- **اسپیم اور رکاوٹیں:** ٹرانزیکشنز کے لیے GHO میں گیس درکار ہوتی ہے، جسے ایپس شرح کی حدوں کے ساتھ
  اسپانسر کر سکتی ہیں۔ فیڈ اور گروپ کے قواعد ٹوکن ہولڈنگز یا ادائیگیاں لازمی قرار دے سکتے ہیں۔
- **چین کا انتظام:** [L2BEAT](https://l2beat.com/scaling/projects/lens) Lens Chain کو Stage 0
  validium قرار دیتا ہے، جس کا ایک مرکزی آپریٹر ہے جو ٹرانزیکشنز شامل کرنے سے انکار کر سکتا ہے۔

## DeSo

[DeSo](https://docs.deso.org/) سوشل ایپس کے لیے بنایا گیا لیئر 1 بلاک چین ہے۔ جولائی 2024 میں یہ پروف
آف ورک سے پروف آف اسٹیک پر منتقل ہوا۔

- **چین پر:** پروفائلز، پوسٹس، لائکس، فالوز اور براہِ راست پیغامات سب ٹرانزیکشنز ہیں جنہیں ہر فل نوڈ
  محفوظ کرتا ہے۔ تصاویر اور ویڈیو چین سے باہر ہوسٹ ہوتی ہیں؛ حوالہ جاتی نوڈ Google Cloud Storage اور
  Cloudflare Stream استعمال کرتا ہے۔
- **اسپیم:** ہر عمل پر DESO میں فیس ادا ہوتی ہے۔ نئے صارفین کو عموماً فون کی تصدیق کے بعد کسی نوڈ سے
  ابتدائی DESO ملتا ہے۔
- **ماڈریشن:** ہر نوڈ بلیک لسٹ یا گرے لسٹ کر کے طے کرتا ہے کہ کیا دکھانا ہے، مگر
  [مواد چین پر رہتا ہے](https://docs.deso.org/deso-blockchain/content-moderation)۔
- **کمیونٹیز:** دستاویزات میں کمیونٹی یا فورم کا کوئی بنیادی جزو بیان نہیں کیا گیا؛ “کمیونٹی” ایک فیڈ
  ہے جسے کوئی ایپ ترتیب دیتی ہے۔
- **نوڈ چلانا:** [ویلیڈیٹر گائیڈ](https://docs.deso.org/deso-validators/run-a-validator) کے مطابق
  ویلیڈیٹرز کو کم از کم 32 GB RAM اور 200 GB ڈسک درکار ہوتی ہے۔

## Steem

[Steem](https://steem.com/) ایک سوشل بلاک چین ہے جو مصنفین اور کیوریٹرز کو ٹوکنز میں معاوضہ دیتی ہے،
اور [Steemit](https://steemit.com/) اس کی مرکزی بلاگنگ ایپ ہے۔ Hive نے 2020 میں Steem سے علیحدگی
اختیار کی؛ [Hive کے وائٹ پیپر](https://hive.io/whitepaper.pdf) کے مطابق یہ فورک Steemit Inc. کی
Justin Sun کو فروخت کے بعد ہوا۔

- **چین پر:** متنی پوسٹس، تبصرے، ووٹس اور ان کی ترمیمی تاریخ، جنہیں 21 منتخب وٹنیسز ترتیب دیتے ہیں
  اور ہر تین سیکنڈ میں ایک بلاک بناتے ہیں۔ تصاویر چین سے باہر ہوسٹ ہوتی ہیں۔
- **اسپیم:** اعمال Resource Credits خرچ کرتے ہیں، جو اسٹیک کیے گئے STEEM کے ساتھ بڑھتے ہیں۔ اکاؤنٹ
  بنانے پر STEEM خرچ ہوتا ہے؛ Steemit یہ قیمت ان صارفین کے لیے ادا کرتا ہے جو ای میل پتے اور فون نمبر
  کی تصدیق کریں۔
- **کمیونٹیز:** یہ
  [ایک انڈیکسر کی تشریح کردہ کسٹم آپریشنز ہیں](https://github.com/steemit/hivemind/blob/master/docs/communities.md)
  جو اتفاقِ رائے سے باہر ہیں۔ ماڈریٹرز پوسٹس میوٹ کر سکتے ہیں، جس سے وہ ایپس میں چھپ جاتی ہیں مگر چین
  پر رہتی ہیں۔
- **انعامات:** افراطِ زر انعامات کی مالی معاونت کرتا ہے، اور اسٹیک کے وزن والے ووٹ طے کرتے ہیں کہ
  انہیں کیسے تقسیم کیا جائے، اس لیے بڑے ہولڈرز یہ طے کرتے ہیں کہ کس چیز کو توجہ ملے۔
