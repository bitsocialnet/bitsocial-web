# Bitsocial اور Mirage

[Mirage](https://mirage.foundation/) کمیونٹیز، تھریڈڈ پوسٹس اور ووٹس والا Reddit طرز کا مباحثہ نیٹ ورک
ہے۔ یہ کسی کمپنی کے ڈیٹا بیس کے بجائے اپنے بلاک چین پر چلتا ہے، جو CometBFT اتفاقِ رائے والی ایک
Cosmos SDK چین ہے۔ Bitsocial کی قریب ترین پروڈکٹ [Seedit](/apps/seedit/) ہے، جو Bitsocial نیٹ ورک پر
Reddit طرز کی ایپ ہے، اس لیے یہ موازنہ زیادہ تر اس بارے میں ہے کہ دونوں کمیونٹیز کی میزبانی، ملکیت اور
ماڈریشن کیسے کرتے ہیں۔

## Mirage کیسے کام کرتا ہے

- **نوڈز۔** Mirage نوڈ ایک Docker کنٹینر ہے جس میں ایک ویلیڈیٹر، ایک PostgreSQL ڈیٹا بیس، ایک
  انڈیکسر، ایک HTTP API اور ویب فرنٹ اینڈ ہوتے ہیں۔ ہر نوڈ ویلیڈیٹر بھی ہوتا ہے۔
  [ڈیپلائے گائیڈ](https://github.com/MirageFoundation/mirage-node/blob/dev/docs/guides/deploy.md) کے
  مطابق نوڈ چلانے کے لیے amd64 پر Ubuntu سرور اور آپریٹر کے اکاؤنٹ میں 10,000,000 MIRAGE ٹوکنز
  درکار ہیں۔
- **پوسٹ کرنا۔** براؤزر ہر عمل پر صارف کی secp256k1 کلید سے دستخط کرتا ہے، اور مفت صارفین ایک چھوٹا
  پروف آف ورک بھی حل کرتے ہیں۔ نوڈ اس عمل کو چین ٹرانزیکشن میں لپیٹتا ہے اور فیس ادا کرتا ہے۔
- **پڑھنا۔** ہر نوڈ کا انڈیکسر چین کا ڈیٹا اپنے ڈیٹا بیس میں نقل کرتا ہے اور HTTP API کے ذریعے فیڈز
  پیش کرتا ہے۔ نوڈز تقریباً ایک ہفتے کے بلاکس رکھتے ہیں، اس لیے پوسٹس کی طویل مدتی تاریخ ہر نوڈ کے
  ڈیٹا بیس میں رہتی ہے، اور نیا نوڈ اپنے سنک پوائنٹ سے پہلے کی تاریخ کے بغیر شروع ہوتا ہے۔
- **اکاؤنٹس۔** اکاؤنٹ 12 الفاظ کے سیڈ فریز سے اخذ کردہ ایک کلید ہے، اور وہی سیڈ کسی بھی نوڈ پر کام
  کرتا ہے۔ یوزر نیمز چین پر درج ہوتے ہیں اور پورے نیٹ ورک میں منفرد ہوتے ہیں۔
- **کمیونٹیز۔** ہر درست نام پہلے سے ایک کمیونٹی ہے، اور اس کا کوئی مالک نہیں۔ ادا شدہ کیوریٹر ٹیمیں،
  جن میں سے ہر ایک میں زیادہ سے زیادہ دس صارفین ہوتے ہیں، کسی کمیونٹی کا ماڈریٹ کیا ہوا منظر برقرار
  رکھتی ہیں؛ قارئین کسی ٹیم کا منظر، نوڈ کا ڈیفالٹ یا غیر سنسر شدہ منظر چنتے ہیں۔ دیکھیں
  [Mirage FAQ](https://mirage.talk/faq)۔
- **ٹوکن۔** MIRAGE ٹوکن سبسکرپشنز کی ادائیگی کرتا ہے، مصنفین اور نوڈز کو انعام دیتا ہے، اور ویلیڈیٹرز
  کو گورننس میں وزن دیتا ہے۔ سبسکرائبرز پروف آف ورک سے مستثنیٰ ہوتے ہیں اور زیادہ حدیں پاتے ہیں۔

## فرق کہاں ہے

### کمیونٹی کا مالک کون ہے

Seedit میں کمیونٹی بنانے والا اس کا کلیدی جوڑا رکھتا ہے، اس کا نوڈ چلاتا ہے یا یہ کام کسی کو سونپ
دیتا ہے، اور اس کی ماڈریشن کرتا ہے۔ Mirage میں کسی کمیونٹی کا کوئی مالک نہیں: مقابلہ کرنے والی کیوریٹر
ٹیمیں ایک ہی نام کے ماڈریٹ کیے ہوئے منظر پیش کرتی ہیں، اور ڈیفالٹ منظر اس ٹیم کا ہوتا ہے جسے سب سے
زیادہ ادائیگی کرنے والے سبسکرائبرز نے چنا ہو۔

### اسپیم پر قابو

Mirage پورے نیٹ ورک پر ایک ہی قاعدہ لاگو کرتا ہے: مفت صارفین پروف آف ورک کی صورت میں قیمت ادا کرتے ہیں
جس کی مشکل آنے والے حجم کے مطابق بدلتی ہے، اور سبسکرائبرز اس سے مستثنیٰ ہیں۔ Bitsocial میں ہر کمیونٹی
اپنا چیلنج خود چنتی ہے، کیپچا سے اجازت فہرستوں اور ادائیگیوں تک۔ دیکھیں
[حسب ضرورت اینٹی اسپیم چیلنجز](/custom-challenges/)۔

### انفراسٹرکچر

Mirage کو بلاک چین درکار ہے۔ ویلیڈیٹرز ہر عمل پر اتفاقِ رائے کرتے ہیں، اور ہر نوڈ ایک مکمل سرور اسٹیک
چلاتا ہے اور اسے ٹوکنز کا بڑا اسٹیک رکھنا پڑتا ہے۔ Bitsocial میں کوئی چین نہیں: کمیونٹی نوڈ ڈیسک ٹاپ
ایپ یا `bitsocial-cli` سے عام صارف کے ہارڈویئر پر چلتا ہے، اور قارئین مواد پھیلانے میں مدد کر سکتے
ہیں۔

### نیٹ ورک بھر کا کنٹرول

Mirage میں ویلیڈیٹر اسٹیک کے وزن والی آن چین گورننس ہے۔ یہ مشکل، قیمتیں اور ٹوکن کا اجرا بدل سکتی ہے،
ٹوکنز منٹ یا برن کر سکتی ہے، اور ایسے ایڈمنز مقرر کر سکتی ہے جن کے حذف کرنے کے فیصلے حوالہ جاتی
انڈیکسر کسی بھی پوسٹ پر لاگو کرتا ہے۔ چین کا کوڈ گورننس کو
[اکاؤنٹس حذف کرنے](https://github.com/MirageFoundation/mirage-node/blob/142a2e4e2542b6a3c9cc6d71591c282e5e5a9503/blockchain/x/core/module/module.go#L2572-L2573)
اور
[کسی بھی پتے سے ٹوکن بھیجنے](https://github.com/MirageFoundation/mirage-node/blob/142a2e4e2542b6a3c9cc6d71591c282e5e5a9503/blockchain/x/core/module/module.go#L2656)
کی اجازت بھی دیتا ہے۔ اکتوبر 2026 میں چین کے بلاکس چار ویلیڈیٹرز بنا رہے تھے، اور چاروں منصوبے کی
اپنی رن بکس کے تحت چلائے جا رہے تھے۔

Bitsocial میں پروٹوکول کی سطح کا کوئی ایڈمنسٹریٹر نہیں۔ کمیونٹی مالکان اپنی کمیونٹیز کی ماڈریشن کرتے
ہیں اور ایپس طے کرتی ہیں کہ کیا دکھانا ہے۔ دیکھیں
[مقامی ماڈریشن، عالمی پابندیاں نہیں](/local-moderation/)۔

### براؤزر

Mirage کا ویب کلائنٹ کسی نوڈ کا HTTP کلائنٹ ہے: براؤزر اعمال پر دستخط کرتا ہے مگر کسی پیئر ٹو پیئر
نیٹ ورک میں شامل نہیں ہوتا۔ Bitsocial ایپس براؤزر ٹیب کے اندر پیئر ٹو پیئر نوڈ چلا سکتی ہیں۔ دیکھیں
[براؤزر پیئر ٹو پیئر](/browser-p2p/)۔
