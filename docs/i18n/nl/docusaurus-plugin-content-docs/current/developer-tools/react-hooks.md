# React Hooks

`@bitsocial/bitsocial-react-hooks` geeft React-apps een hooks-API voor het Bitsocial-protocol: feeds, reacties, community's, auteursprofielen, accounts en publiceren, zonder centrale server. [5chan](/apps/5chan/) en [Seedit](/apps/seedit/) zijn erop gebouwd.

De bibliotheek heeft een eigen documentatiesite, die bij elke release wordt bijgewerkt: **[hooks.bitsocial.net](https://hooks.bitsocial.net/)**.

## Installatie

```bash
npm install @bitsocial/bitsocial-react-hooks
```

Het pakket ondersteunt React 16.8 en hoger.

## Waar begin je

- [Snelstart](https://hooks.bitsocial.net/docs/quickstart/): render je eerste communityfeed.
- [Concepten](https://hooks.bitsocial.net/docs/concepts/): hoe feeds, lokale accounts, gedeelde state en publiceren met elkaar samenhangen.
- [API-referentie](https://hooks.bitsocial.net/docs/api/feeds-hooks/): elke hook met zijn opties en returnwaarden.
- [Playground](https://hooks.bitsocial.net/#playground): bewerk live voorbeelden die op gesimuleerde content draaien.
- [Bouwen met AI](https://hooks.bitsocial.net/docs/ai/): `llms.txt` en Markdown-versies van elke pagina voor codeeragents.
