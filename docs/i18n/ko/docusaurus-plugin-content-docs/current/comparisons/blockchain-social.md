# Bitsocial과 블록체인 소셜 네트워크

Lens, DeSo, Steem은 모두 소셜 활동을 블록체인에 올립니다. 계정, 팔로우, 게시물, 또는 이를 둘러싼
규칙이 검증자가 순서를 정하고 저장하는 트랜잭션이 됩니다. Bitsocial은 블록체인을 쓰지 않습니다. 소셜
미디어에는 모든 게시물의 전역 순서가 필요하지 않으므로, Bitsocial은 합의, 가스, 스테이킹을
건너뜁니다. 그 이유는 [P2P 프로토콜](/peer-to-peer-protocol/)을 참고하세요.

## 공통점

- **쓰기마다 누군가가 비용을 낸다.** Lens는 가스를 부과하고 앱이 이를 대신 내줄 수 있습니다. DeSo는
  모든 행동에 수수료를 매기고, Steem은 스테이킹한 토큰에 따라 행동을 배분합니다.
- **체인이 모두에게 하나의 스팸 정책을 정한다.** 수수료, 스테이크, 계정 비용은 커뮤니티마다 고르는
  것이 아니라 네트워크 전체에 적용됩니다.
- **온체인 기록은 영구적이다.** 앱은 콘텐츠를 숨길 수는 있지만 체인에서 지울 수는 없습니다.
- **브라우저는 API 클라이언트다.** 웹 앱은 트랜잭션에 서명하고, 다른 누군가가 운영하는 노드, 인덱서,
  API를 통해 데이터를 읽습니다.

## Lens

[Lens](https://lens.xyz/)는 Lens Chain 위에서 동작합니다. Lens Chain은 ZKsync의 ZK Stack으로 만든
이더리움 레이어 2이며, 데이터 가용성에는 Avail을 사용합니다. Mask Network가
[2026년 1월부터 Lens를 맡아 운영](https://lens.xyz/news/mask-network-to-steward-the-next-chapter-of-lens)하고
있습니다.

- **체인 위:** 계정은 스마트 컨트랙트이고, 사용자 이름은 네임스페이스 안의 NFT이며, 그래프, 그룹,
  피드와 그 규칙도 컨트랙트입니다.
- **체인 밖:** 게시물의 텍스트와 미디어는 어떤 URI에 있는 JSON 파일에 담기며, 보통 IPFS 앞단에 놓인
  Lens의 스토리지 서비스 Grove에 저장됩니다. 반응과 북마크는 Lens API가 보관하고, 앱은 그 API를 통해
  데이터를 읽습니다.
- **스팸과 관문:** 트랜잭션에는 GHO로 내는 가스가 필요하며, 앱이 속도 제한을 걸고 이를 대신 내줄 수
  있습니다. 피드와 그룹 규칙으로 토큰 보유나 결제를 요구할 수도 있습니다.
- **체인 운영:** [L2BEAT](https://l2beat.com/scaling/projects/lens)는 Lens Chain을 Stage 0
  validium으로 평가하며, 중앙화된 운영자가 트랜잭션 포함을 거부할 수 있다고 봅니다.

## DeSo

[DeSo](https://docs.deso.org/)는 소셜 앱을 위해 만든 레이어 1 블록체인입니다. 2024년 7월 작업
증명에서 지분 증명으로 전환했습니다.

- **체인 위:** 프로필, 게시물, 좋아요, 팔로우, 다이렉트 메시지가 모두 트랜잭션이며 모든 풀 노드가
  이를 저장합니다. 이미지와 동영상은 오프체인에 호스팅되며, 참조 노드는 Google Cloud Storage와
  Cloudflare Stream을 사용합니다.
- **스팸:** 모든 행동에 DESO로 수수료를 냅니다. 신규 사용자는 보통 전화번호 인증을 거친 뒤 노드에서
  초기 DESO를 받습니다.
- **모더레이션:** 각 노드는 블랙리스트나 그레이리스트로 무엇을 보여줄지 정하지만,
  [콘텐츠는 온체인에 남습니다](https://docs.deso.org/deso-blockchain/content-moderation).
- **커뮤니티:** 문서에는 커뮤니티나 포럼 프리미티브가 설명되어 있지 않으며, "커뮤니티"란 앱이
  큐레이션하는 피드를 말합니다.
- **노드 운영:** [검증자 가이드](https://docs.deso.org/deso-validators/run-a-validator)에 따르면
  검증자에는 최소 RAM 32GB와 디스크 200GB가 필요합니다.

## Steem

[Steem](https://steem.com/)은 작성자와 큐레이터에게 토큰으로 보상하는 소셜 블록체인이며, 대표 블로그
앱은 [Steemit](https://steemit.com/)입니다. Hive는 2020년 Steem에서 갈라져 나왔습니다.
[Hive 백서](https://hive.io/whitepaper.pdf)에 따르면 이 포크는 Steemit Inc.가 Justin Sun에게 매각된
뒤에 일어났습니다.

- **체인 위:** 텍스트 게시물, 댓글, 투표와 그 수정 기록이며, 선출된 21명의 위트니스가 3초마다 블록을
  생성해 순서를 정합니다. 이미지는 오프체인에 호스팅됩니다.
- **스팸:** 행동은 Resource Credits를 소모하며, Resource Credits는 스테이킹한 STEEM에 따라
  늘어납니다. 계정을 만드는 데는 STEEM이 들고, 이메일 주소와 전화번호를 인증한 사용자에 대해서는
  Steemit이 이를 대신 냅니다.
- **커뮤니티:** 커뮤니티는 합의 밖에서
  [인덱서가 해석하는 커스텀 오퍼레이션](https://github.com/steemit/hivemind/blob/master/docs/communities.md)입니다.
  모더레이터는 게시물을 뮤트할 수 있는데, 그러면 앱에서는 숨겨지지만 온체인에는 남습니다.
- **보상:** 인플레이션이 보상 재원이 되고, 스테이크로 가중된 투표가 분배 방식을 정하므로, 대량
  보유자가 무엇이 주목받을지를 좌우합니다.
