# Bitsocial과 Mirage

[Mirage](https://mirage.foundation/)는 커뮤니티, 스레드형 게시물, 투표를 갖춘 Reddit 스타일의 토론
네트워크입니다. 회사 데이터베이스 대신 자체 블록체인, 즉 CometBFT 합의를 쓰는 Cosmos SDK 체인 위에서
동작합니다. Bitsocial에서 가장 가까운 제품은 Bitsocial 네트워크 위의 Reddit 스타일 앱인
[Seedit](/apps/seedit/)이므로, 이 비교는 주로 각자가 커뮤니티를 어떻게 호스팅하고, 소유하고,
모더레이션하는지에 관한 것입니다.

## Mirage의 동작 방식

- **노드.** Mirage 노드는 검증자, PostgreSQL 데이터베이스, 인덱서, HTTP API, 웹 프런트엔드를 담은
  하나의 Docker 컨테이너입니다. 모든 노드는 검증자이기도 합니다.
  [배포 가이드](https://github.com/MirageFoundation/mirage-node/blob/dev/docs/guides/deploy.md)에
  따르면 노드를 운영하려면 amd64 기반 Ubuntu 서버와 운영자 계정에 있는 10,000,000 MIRAGE 토큰이
  필요합니다.
- **게시.** 브라우저는 사용자의 secp256k1 키로 각 행동에 서명하고, 무료 사용자는 작은 작업 증명도
  계산합니다. 노드는 그 행동을 체인 트랜잭션으로 감싸고 수수료를 냅니다.
- **읽기.** 각 노드의 인덱서는 체인 데이터를 자체 데이터베이스로 복사하고 HTTP API로 피드를
  제공합니다. 노드는 약 일주일 분량의 블록만 보관하므로, 장기적인 게시물 기록은 각 노드의
  데이터베이스에 있으며, 새 노드는 동기화 시점 이전의 기록 없이 시작합니다.
- **계정.** 계정은 12단어 시드 문구에서 파생된 키이며, 같은 시드를 어느 노드에서나 쓸 수 있습니다.
  사용자 이름은 체인에 기록되며 네트워크 전체에서 고유합니다.
- **커뮤니티.** 유효한 이름은 모두 이미 하나의 커뮤니티이며, 누구도 그것을 소유하지 않습니다. 최대
  10명으로 이루어진 유료 큐레이터 팀이 각자 커뮤니티의 모더레이션된 뷰를 관리하고, 독자는 어느 팀의
  뷰, 노드의 기본 뷰, 검열되지 않은 뷰 중에서 고릅니다. [Mirage FAQ](https://mirage.talk/faq)를
  참고하세요.
- **토큰.** MIRAGE 토큰은 구독료를 내고, 작성자와 노드에 보상하며, 검증자에게 거버넌스 가중치를
  줍니다. 구독자는 작업 증명을 건너뛰고 더 높은 한도를 받습니다.

## 차이점

### 누가 커뮤니티를 소유하는가

Seedit에서는 커뮤니티를 만든 사람이 그 키페어를 보유하고, 노드를 직접 운영하거나 위임하며,
모더레이션합니다. Mirage에서는 누구도 커뮤니티를 소유하지 않습니다. 경쟁하는 큐레이터 팀들이 같은
이름에 대해 모더레이션된 뷰를 제공하고, 기본 뷰는 가장 많은 유료 구독자가 고른 팀의 뷰가 됩니다.

### 스팸 방지

Mirage는 네트워크 전체에 하나의 규칙을 적용합니다. 무료 사용자는 들어오는 양에 따라 난이도가
조정되는 작업 증명으로 대가를 치르고, 구독자는 이를 건너뜁니다. Bitsocial에서는 캡차부터 허용 목록,
결제까지 각 커뮤니티가 자체 챌린지를 고릅니다. [맞춤형 스팸 방지 챌린지](/custom-challenges/)를
참고하세요.

### 인프라

Mirage에는 블록체인이 필요합니다. 검증자는 모든 행동에 대해 합의에 도달하고, 각 노드는 완전한 서버
스택을 실행하며 많은 양의 토큰을 스테이크로 보유해야 합니다. Bitsocial에는 체인이 없습니다. 커뮤니티
노드는 데스크톱 앱이나 `bitsocial-cli`로 일반 소비자용 하드웨어에서 실행되며, 독자도 콘텐츠 공유를
도울 수 있습니다.

### 네트워크 전체에 대한 통제

Mirage에는 검증자 스테이크로 가중되는 온체인 거버넌스가 있습니다. 거버넌스는 난이도, 가격, 토큰
발행량을 바꾸고, 토큰을 발행하거나 소각하며, 관리자를 임명할 수 있는데, 참조 인덱서는 그 관리자의
삭제를 어떤 게시물에든 적용합니다. 체인 코드는 거버넌스가
[계정을 삭제](https://github.com/MirageFoundation/mirage-node/blob/142a2e4e2542b6a3c9cc6d71591c282e5e5a9503/blockchain/x/core/module/module.go#L2572-L2573)하고
[어떤 주소에서든 토큰을 보내는 것](https://github.com/MirageFoundation/mirage-node/blob/142a2e4e2542b6a3c9cc6d71591c282e5e5a9503/blockchain/x/core/module/module.go#L2656)도
허용합니다. 2026년 10월에는 검증자 네 곳이 체인의 블록을 생산했고, 프로젝트 자체 런북이 네 곳 모두를
관리했습니다.

Bitsocial에는 프로토콜 수준의 관리자가 없습니다. 커뮤니티 소유자가 자기 커뮤니티를 모더레이션하고,
무엇을 보여줄지는 앱이 선택합니다. [전역 차단이 아닌 로컬 모더레이션](/local-moderation/)을
참고하세요.

### 브라우저

Mirage의 웹 클라이언트는 노드의 HTTP 클라이언트입니다. 브라우저는 행동에 서명하지만 P2P 네트워크에
참여하지는 않습니다. Bitsocial 앱은 브라우저 탭 안에서 P2P 노드를 실행할 수 있습니다.
[브라우저 피어 투 피어](/browser-p2p/)를 참고하세요.

| 경제             | 구독, 보상, 검증자 스테이크에 쓰이는 MIRAGE 토큰                                                            | 프로토콜에는 없음, 챌린지로 결제나 토큰을 요구할 수 있음                              |
