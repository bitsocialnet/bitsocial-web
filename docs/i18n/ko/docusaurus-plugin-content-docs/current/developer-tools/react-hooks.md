# React Hooks

`@bitsocial/bitsocial-react-hooks`는 React 앱에 Bitsocial 프로토콜용 훅 API를 제공합니다. 피드, 댓글, 커뮤니티, 작성자 프로필, 계정, 게시 기능을 중앙 서버 없이 다룰 수 있습니다. [5chan](/apps/5chan/)과 [Seedit](/apps/seedit/)이 이 라이브러리를 기반으로 만들어졌습니다.

이 라이브러리에는 릴리스마다 업데이트되는 전용 문서 사이트가 있습니다: **[hooks.bitsocial.net](https://hooks.bitsocial.net/)**.

## 설치

```bash
npm install @bitsocial/bitsocial-react-hooks
```

이 패키지는 React 16.8 이상을 지원합니다.

## 어디서 시작할까요

- [빠른 시작](https://hooks.bitsocial.net/docs/quickstart/): 첫 번째 커뮤니티 피드를 렌더링해 봅니다.
- [개념](https://hooks.bitsocial.net/docs/concepts/): 피드, 로컬 계정, 공유 상태, 게시가 어떻게 맞물려 동작하는지 설명합니다.
- [API 레퍼런스](https://hooks.bitsocial.net/docs/api/feeds-hooks/): 모든 훅의 옵션과 반환값을 정리합니다.
- [플레이그라운드](https://hooks.bitsocial.net/#playground): 시뮬레이션 콘텐츠로 실행되는 라이브 예제를 직접 수정해 볼 수 있습니다.
- [AI로 개발하기](https://hooks.bitsocial.net/docs/ai/): 코딩 에이전트를 위한 `llms.txt`와 모든 페이지의 Markdown 버전을 제공합니다.
