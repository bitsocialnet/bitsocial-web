# React Hooks

`@bitsocial/bitsocial-react-hooks` cung cấp cho ứng dụng React một API hooks dành cho giao thức Bitsocial: bảng tin, bình luận, cộng đồng, hồ sơ tác giả, tài khoản và đăng nội dung, mà không cần máy chủ trung tâm. [5chan](/apps/5chan/) và [Seedit](/apps/seedit/) được xây dựng trên thư viện này.

Thư viện có trang tài liệu riêng, được cập nhật theo mỗi bản phát hành: **[hooks.bitsocial.net](https://hooks.bitsocial.net/)**.

## Cài đặt

```bash
npm install @bitsocial/bitsocial-react-hooks
```

Gói này hỗ trợ React 16.8 trở lên.

## Bắt đầu từ đâu

- [Bắt đầu nhanh](https://hooks.bitsocial.net/docs/quickstart/): hiển thị bảng tin cộng đồng đầu tiên của bạn.
- [Khái niệm](https://hooks.bitsocial.net/docs/concepts/): cách bảng tin, tài khoản cục bộ, trạng thái dùng chung và việc đăng nội dung phối hợp với nhau.
- [Tài liệu tham khảo API](https://hooks.bitsocial.net/docs/api/feeds-hooks/): mọi hook cùng các tùy chọn và giá trị trả về của chúng.
- [Môi trường thử nghiệm](https://hooks.bitsocial.net/#playground): chỉnh sửa các ví dụ trực tiếp chạy trên nội dung mô phỏng.
- [Xây dựng với AI](https://hooks.bitsocial.net/docs/ai/): `llms.txt` và phiên bản Markdown của mọi trang dành cho các agent lập trình.
