# Хуки агентов

Закоммиченные хуки жизненного цикла делают только одно: форматируют успешно отредактированные файлы JavaScript/TypeScript установленным oxfmt. Общая логика находится в `scripts/agent-hooks/format.mjs`; каждая нативная обёртка делегирует работу ей.

| Приложение | Нативная конфигурация | Событие |
|---|---|---|
| Codex | `.codex/hooks.json` | `PostToolUse`, `apply_patch` |
| Claude Code | `.claude/settings.json` | `PostToolUse`, `Edit|Write|MultiEdit` |
| Cursor | `.cursor/hooks.json` | `afterFileEdit` |

Claude не читает отдельный файл `.claude/hooks.json`. Каждое приложение по-прежнему само решает, доверять ли проекту и включены ли хуки; изучите его текущие настройки, а не обходите проверку доверия. `.codex/config.toml` — это конфигурация репозитория, а не реестр команд хуков.

Форматтер проверяет событие и полезную нагрузку, успешность правки, расширение файла и то, что файл находится внутри репозитория, с учётом символических ссылок. Если зависимостей нет или входные данные не относятся к делу, он ничего не делает. Команды передаются массивом аргументов, а сетевой доступ Corepack отключён; хуки не устанавливают зависимости, не запускают сборки и ревью и не изменяют Git.

Запускайте проверки явно, согласно [verification.md](https://github.com/bitsocialnet/bitsocial-web/blob/master/docs/agent-playbooks/verification.md). После изменения рабочего процесса запустите `yarn ai-workflow:sync`, `yarn ai-workflow:check` и `yarn ai-workflow:test`. Фикстуры используют одноразовые файлы и имитацию вызовов форматтера; они не доказывают, что каждое приложение загрузило свою конфигурацию. После обновлений перезагрузите приложение и проверьте его каталог.

Навык дизайна Impeccable и его исполняемые хелперы по-прежнему доступны по запросу в `.agents/skills/impeccable`. Его прежний хук для Codex указывал на несуществующий каталог; теперь дизайнерский рабочий процесс запускается, когда выбран его навык, и постоянно включённого дизайн-хука больше нет. Навык не должен перенастраивать хуки проекта как побочный шаг дизайнерской работы.
