# Переводы

Сайт about использует JSON-файлы i18next в `about/public/translations/{lang}/default.json`. Переводы страниц Docusaurus хранятся отдельно, в `docs/i18n/`.

## Ключи сайта about

Используйте `.agents/skills/translate/SKILL.md`. Определяйте текущие локали по содержимому диска и сохраняйте плейсхолдеры, разметку, технические термины и названия брендов. При больших запросах дочерние агенты могут генерировать независимые карты, но все записи в локали последовательно применяет один родительский агент: у скрипта обновления нет блокировки записи.

Используйте уникальный путь к карте, принадлежащий только этой задаче. Сделайте предпросмотр командой `node scripts/update-translations.js --key <key> --map <map.json> --include-en --dry`, затем примените изменения с теми же аргументами и `--write`. После записи проверьте покрытие и значения и удалите только те временные карты, которые принадлежат этой задаче.

Для запрошенных удалений используйте `--delete`. Изучите результаты `--audit --dry`, прежде чем выполнять авторизованный `--audit --write`; динамические ключи перевода требуют ручной проверки исходников. Копируйте английский текст во все локали только для технического термина, бренда или плейсхолдера.

## Страницы Docusaurus

`scripts/translate-docs.py` — это скрипт массовой записи для всех страниц и локалей без пофайлового фильтра; не используйте его для узкой правки перевода. `scripts/check-docs-translations.py` — проверяющий скрипт, который ничего не записывает и поддерживает `--locales` и `--paths`.

Блоки кода, ссылки, инлайн-код, адреса контрактов, заголовки, таблицы и блоки-предупреждения должны соответствовать английскому исходнику. Устраняйте ошибки проверки; предупреждения `frontmatter-untranslated` из-за названий брендов могут быть ожидаемыми. Следуйте `docs/AGENTS.md` и собирайте через корень репозитория, когда меняете тему документации или поведение i18n, чтобы статический вывод и Pagefind оставались согласованными.

## Необязательное семантическое ревью

Для выбранных ключей i18next используйте `scripts/jev/translation-README.md`. Для страниц документации сначала запустите `node scripts/jev/docs-translations.mjs --locales it,de --paths browser-p2p.md`. Команда требует явно выбрать локали и страницы, запускает структурную проверку и помечает семантическое ревью как непроверенное, пока не включён живой инференс. Добавляйте `--live`, только если у задачи есть авторизация на использование провайдера и бюджет; общая приватная конфигурация машины предоставляет учётные данные и закреплённую модель. Переменные окружения и `--model` могут переопределить эти настройки. Команда никогда не редактирует переводы.

Адаптер страниц сохраняет контекст всей страницы и ограничивает размер каждой страницы 24 КБ, а каждый прогон — 30 парами. Для более крупных страниц подготовьте явно выровненные пары абзацев исходника и перевода для `translations.mjs --pairs`; не сопоставляйте абзацы автоматически по порядковому номеру. Семантические результаты носят рекомендательный характер: изучайте найденные проблемы и степень неопределённости и сохраняйте детерминированные проверки кода, ссылок и адресов.
