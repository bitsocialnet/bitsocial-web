# 5chan

5chan — бессерверный, не требующий администраторов и полностью децентрализованный имиджборд, который работает на протоколе Bitsocial. Он повторяет привычную структуру каталога имиджборда, но добавляет к ней децентрализованное владение: любой может создать доску, а несколько досок могут бороться за один и тот же слот каталога через механизм голосования.

## Как устроены доски

5chan раскладывает контент по доскам, используя классическую структуру каталога (например, `/b/`, `/g/`). В отличие от традиционных имиджбордов, где всеми досками управляет центральный администратор, 5chan позволяет любому пользователю создать собственную доску и полностью ею владеть. Когда на один слот каталога претендуют несколько досок, они соревнуются за эту позицию; см. [Каталоги](/directories/).

### Создание доски

Чтобы создать новую доску, нужно запустить `bitsocial-cli` как одноранговый узел. Так ваша доска размещается децентрализованно и не зависит ни от какого центрального сервера.

### Назначение слотов каталога

Доски-кандидаты для каждого каталога перечислены в файле `5chan-directories/5chan-<code>-directory.json` в репозитории [bitsocialnet/lists](https://github.com/bitsocialnet/lists), а доска присоединяется к каталогу через пул-реквест к этому файлу. Кроме того, 5chan проводит голосование для каждого каталога с помощью [`@bitsocial/pubsub-voting`](https://github.com/bitsocialnet/pubsub-voting): у каждого владельца 5chan Pass один голос, а голос за доску, которой нет в списке, выдвигает её в кандидаты. Сейчас голосования проходят в тестовой сети Base Sepolia, где итоги отображаются, но не меняют порядок списка.

## Внутреннее устройство

Под капотом 5chan использует общий клиентский уровень протокола Bitsocial для работы с сетью.
Веб-приложение на 5chan.app по умолчанию запускает узел Helia прямо в браузере, поэтому обычная
вкладка присоединяется к сети как равноправный участник: она загружает доски у других участников и
публикует через pubsub, без централизованного шлюза IPFS на пути к контенту. О том, что за этим
стоит и чего браузерный узел всё же не умеет, читайте в разделе
[Одноранговая сеть в браузере](/browser-p2p/).
