# Seedit

Seedit — это бессерверная, не требующая администратора и полностью децентрализованная альтернатива Reddit старого стиля, построенная на протоколе Bitsocial. Это дает пользователям полную власть над своими сообществами — любой может создать одно, и несколько сообществ могут конкурировать за один и тот же короткий маршрут, например `/s/funny`.

## Как работают сообщества

Seedit организует контент в сообщества, похожие на субреддиты. Каждое сообщество принадлежит своему создателю и функционирует без централизованного управления. Несколько сообществ могут конкурировать за один и тот же маршрут [каталога](/directories/), например `/s/funny`, который открывает текущего победителя. Подписки и ссылки на посты всегда указывают на точное сообщество.

### Создание сообщества

Создать новое сообщество можно двумя способами:

1. **Клиент для настольных компьютеров**. Используйте встроенный графический интерфейс настольного приложения для настройки вашего сообщества.
2. **bitsocial-cli** — запустите инструмент CLI для создания сообществ и управления ими из командной строки.

### Список сообществ по умолчанию

Новые аккаунты подписываются на список конкретных сообществ по умолчанию, определенный в `seedit-default-subscriptions.json` в репозитории [bitsocialnet/lists](https://github.com/bitsocialnet/lists). Кандидаты в каталоги перечислены в файлах `seedit-directories/seedit-<code>-directory.json` в том же репозитории. Чтобы добавить ваше сообщество в любой из этих списков, отправьте запрос на включение с деталями вашего сообщества.
