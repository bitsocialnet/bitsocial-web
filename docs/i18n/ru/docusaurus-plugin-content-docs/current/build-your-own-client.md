# Создайте собственный клиент Bitsocial

Bitsocial побеждает не за счёт одного официального приложения на каждый сценарий. Он побеждает
тогда, когда множество клиентов работают поверх одного протокола и при этом конкурируют интерфейсом,
культурой, обнаружением контента, настройками по умолчанию и бизнес-моделью.

5chan и Seedit — ранние подтверждения работоспособности, а не потолок. Разработчик должен иметь
возможность выпустить новый имиджборд, форум, клиент с профилями, социальное приложение с упором на
мобильные устройства, инструмент для нишевого сообщества или даже централизованный клиент, который
использует Bitsocial внутри, — и не спрашивать при этом разрешения у владельца платформы.

## Что разработчик может изменить

Клиент Bitsocial может конкурировать продуктовыми решениями, не ответвляя от себя всю сеть:

- интерфейс и визуальный язык
- процесс онбординга
- настройки сообществ по умолчанию
- инструменты модерации
- модель обнаружения контента
- работа с медиа
- ограничения мобильных, настольных устройств или медленных соединений
- монетизация и бизнес-модель

Общий уровень — это протокол. Продуктовый уровень открыт для конкуренции.

## Самый быстрый способ разобраться

Начните с приложений, которые уже существуют:

- Попробуйте [5chan](https://5chan.app) — анонимные сообщества в формате имиджборда.
- Попробуйте [Seedit](https://seedit.app) — обсуждения в стиле Reddit.
- Прочитайте документацию по [React-хукам Bitsocial](https://hooks.bitsocial.net/docs/quickstart/) для интеграции на стороне клиента.
- Прочитайте документацию по [Bitsocial CLI](/developer-tools/cli/) для работы с узлами и сообществами.

Если хотите двигаться быстро, сначала помогите существующему приложению. Если нужный вам интерфейс,
культура или модель сообщества туда не вписываются, стройте отдельный клиент.

## Выберите узкую первую версию

Лучшая первая версия — не универсальное социальное приложение. Это клиент с одной понятной
аудиторией и одной весомой причиной существовать.

Хорошие отправные точки:

- более аккуратный клиент-имиджборд для одной конкретной культуры
- форум с упором на мобильные устройства
- приложение для одного сообщества со строгими настройками по умолчанию
- клиент для сообществ авторов
- клиент только для чтения и просмотра
- консоль модератора или оператора
- клиент, оптимизированный под язык, регион или класс устройств

Небольшие клиенты полезны потому, что Bitsocial даёт им расти внутри общей сети, а не запирать своих
пользователей в приватной базе данных.

## Пути реализации

Практичных путей три:

1. Форкнуть существующий клиент, если ваша идея близка к 5chan или Seedit.
2. Собрать новый клиент на React с [React-хуками Bitsocial](https://hooks.bitsocial.net/).
3. Построить собственную интеграцию поверх API узла и публичной RPC-инфраструктуры.

Публичный RPC должен сделать третий путь заметно практичнее. Пользователь может начать с
размещённого некастодиального RPC-провайдера, а позже перейти на собственный хостинг или к
конкурирующему провайдеру.

## Принцип проектирования

Постройте клиент, который должен существовать для вашего сообщества, а затем дайте совместимым
клиентам конкурировать публично.
