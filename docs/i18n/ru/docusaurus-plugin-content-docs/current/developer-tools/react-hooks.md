# React Hooks

`@bitsocial/bitsocial-react-hooks` даёт React-приложениям API хуков для протокола Bitsocial: ленты, комментарии, сообщества, профили авторов, аккаунты и публикация — и всё это без центрального сервера. На этой библиотеке построены [5chan](/apps/5chan/) и [Seedit](/apps/seedit/).

У библиотеки есть собственный сайт документации, который обновляется с каждым релизом: **[hooks.bitsocial.net](https://hooks.bitsocial.net/)**.

## Установка

```bash
npm install @bitsocial/bitsocial-react-hooks
```

Пакет поддерживает React 16.8 и новее.

## С чего начать

- [Быстрый старт](https://hooks.bitsocial.net/docs/quickstart/): отрисуйте свою первую ленту сообщества.
- [Концепции](https://hooks.bitsocial.net/docs/concepts/): как ленты, локальные аккаунты, общее состояние и публикация работают вместе.
- [Справочник API](https://hooks.bitsocial.net/docs/api/feeds-hooks/): все хуки с их параметрами и возвращаемыми значениями.
- [Песочница](https://hooks.bitsocial.net/#playground): редактируйте живые примеры, работающие на имитированном контенте.
- [Разработка с ИИ](https://hooks.bitsocial.net/docs/ai/): `llms.txt` и Markdown-версии каждой страницы для ИИ-агентов, пишущих код.
