# Децентрализовать все социальные сети

Конечное состояние — это не одно приложение. Это рынок клиентов, узлов, сервисов и сообществ,
способный заменить владение платформой конкуренцией вокруг протокола.

На этапе 5 Bitsocial выходит за пределы первых приоритетных категорий и начинает финансировать как
можно больше социальных форматов.

## Что ещё предстоит построить

Первые этапы сосредоточены на категориях с наибольшим рычагом: имиджборды, форумы, публичный RPC,
Bitsocial Chain, узлы профилей, альтернатива Twitter/X из этапа 2 и сервисная экономика вокруг них.

После этого сеть должна расширяться в длинный хвост:

- клиенты для блогов
- приложения для краудфандинга
- авторское видео и достойная [альтернатива YouTube](https://github.com/bitsocialnet/wetube)
- сообщества вокруг авторов
- эксперименты с короткими форматами
- локальные или языковые социальные приложения
- нишевые клиенты, слишком маленькие для первых четырёх этапов
- инструменты, которые упрощают ведение уже существующих сообществ

Часть этих приложений может быть с открытым исходным кодом. Часть может быть централизованными
клиентами. Часть может построить Bitsocial Forge, и многое должны построить независимые
разработчики.

## Идеи на стадии исследования

У некоторых из этих идей уже есть репозитории на стадии идеи. В них пока ничего не построено. Каждый
собирает дизайн и открытые вопросы, чтобы разработчики и инвесторы могли за них взяться.

- [WeTube](https://github.com/bitsocialnet/wetube): альтернатива YouTube, в которой каждый канал —
  это сообщество, принадлежащее его автору.
- [GitCommons](https://github.com/bitsocialnet/gitcommons): исследования и архитектура альтернативы
  GitHub на базе Bitsocial.
- [Infinipedia](https://github.com/bitsocialnet/infinipedia): энциклопедия, которая никому не
  принадлежит: редакционные группы публикуют конкурирующие версии, а читатели выбирают.
- [Modelswarm](https://github.com/bitsocialnet/modelswarm): альтернатива Hugging Face, где рой пиров
  распространяет ИИ-модели с открытыми весами, а каждый файл проверяется по подписанному релизу его
  издателя.

### Рассмотрено и отложено

- [Hopium](https://github.com/bitsocialnet/hopium): альтернатива Fomo для социального трейдинга.
  Отложена в ноябре 2026 года; причины описаны в репозитории.

## Финансирование множества разработчиков

Цель — сделать новые социальные клиенты пригодными для финансирования до того, как у них появится
охват уровня платформы.

Сюда могут входить прямые инвестиции, гранты, финансирование сообществом, доход от успешных сервисов
Bitsocial или децентрализованные грантовые программы, где более широкое сообщество Bitsocial само
помогает решать, кому из разработчиков стоит помочь.

Главное здесь — плюрализм. Сеть должна финансировать много попыток, а не ждать, пока одно
официальное приложение закроет все категории.

## Как выглядит успех

Bitsocial добивается успеха, когда социальные сети можно разложить на заменяемые уровни:

- протокол
- сообщества
- идентичность
- хостинг
- обнаружение контента
- модерация
- монетизация
- приложения

Как только эти уровни становятся заменяемыми, ни одной компании не нужно владеть всем социальным
графом, чтобы продукт работал.

## Главная ставка

Зрелая экосистема Bitsocial должна включать публичные RPC, самостоятельно размещённые узлы, рынки
алгоритмов ленты, медиахостинги, сервисы обнаружения контента, клиенты с открытым исходным кодом,
коммерческие клиенты и эксперименты, финансируемые сообществом.

Социальные сети наконец находят своё равновесие: полностью децентрализованная одноранговая
социальная сеть, которой никто не владеет, — Bitsocial.
