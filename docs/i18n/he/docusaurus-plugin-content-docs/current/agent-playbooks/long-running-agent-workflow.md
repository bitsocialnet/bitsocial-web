# עבודת סוכנים ארוכת טווח

השתמש במצב משימה עמיד כשהעבודה צריכה להתחדש או לעבור מסירה, או כשהרצה יחידה ארוכה מספיק כדי שדחיסת ההקשר עלולה לאבד את המעקב אחר העבודה שנותרה. משימות קטנות אינן צריכות לוח או קובץ התקדמות. בעבודה משותפת, שמור `feature-list.json` ו-`progress.md` תמציתיים בתיקייה `docs/agent-runs/<slug>/` ייעודית למשימה, ונצל תבניות קיימות כשזה מועיל.

תעד את התוצאה המבוקשת, את הענף/ה-worktree הנוכחי, את הבעלות על קבצים, את השינויים שהושלמו, את הבדיקות ותוצאותיהן, את התהליכים/הסשנים שבבעלותך ואת הצעד הבא שטרם נפתר. אל תשמור פרטי גישה או העתקות שרירותיות של קוד מקור. סמן תכונה כהושלמה רק כשקריטריוני הקבלה שלה אומתו.

בחידוש העבודה, בדוק את מצב Git, את ההתקדמות האחרונה ואת קוד המקור הרלוונטי לפני עריכה. עשה שימוש חוזר במשאבים תואמים שבבעלותך; הפעל שרת פיתוח רק כשהבדיקה הבאה זקוקה לו. בחר בדיקות לפי ההשפעה בעזרת [verification.md](https://github.com/bitsocialnet/bitsocial-web/blob/master/docs/agent-playbooks/verification.md), במקום לחזור על מעבר מלא שלא השתנה.

שמור על עבודה מואצלת קשורה מתוחמת בהיקפה וללא חפיפה. סוכן אחד אחראי על הבדיקות הכבדות ועל סשני הדפדפן. עדכן את המצב העמיד כשפרוסה שהושלמה, חסם או מסירה משנים את מה שהתורם הבא צריך לדעת; אל תתעד באופן מכני כל פקודה.
