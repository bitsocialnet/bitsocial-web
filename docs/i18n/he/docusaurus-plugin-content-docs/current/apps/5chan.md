# 5chan

5chan הוא לוח תמונות ללא שרתים, ללא מנהלים ומבוזר לחלוטין, שרץ על פרוטוקול Bitsocial. הוא שומר על מבנה הספריות המוכר של לוחות תמונות, ומוסיף לו בעלות מבוזרת — כל אחד יכול ליצור לוח, וכמה לוחות יכולים להתחרות על אותה משבצת ספרייה באמצעות מנגנון הצבעה.

## הורדות

| פלטפורמה    | קישור                          |
| ----------- | ------------------------------ |
| אינטרנט     | [5chan.app](https://5chan.app) |
| שולחן עבודה | זמין ל-Mac, ל-Windows ול-Linux |
| נייד        | זמין ל-Android                 |

## איך לוחות עובדים

5chan מארגן תוכן בלוחות באמצעות מבנה ספריות קלאסי (למשל `/b/`, `/g/`). בניגוד ללוחות תמונות מסורתיים, שבהם מנהל מרכזי שולט בכל לוח, 5chan מאפשר לכל משתמש ליצור לוח משלו ולהיות הבעלים המלא שלו. כאשר כמה לוחות מכוונים לאותה משבצת ספרייה, הם מתחרים על המקום הזה; ראו [ספריות](/directories/).

### יצירת לוח

כדי ליצור לוח חדש צריך להריץ את `bitsocial-cli` כצומת עמית לעמית. כך הלוח שלכם מתארח באופן מבוזר, בלי להסתמך על שרת מרכזי כלשהו.

### הקצאת משבצות ספרייה

הלוחות המועמדים של כל ספרייה מופיעים בקובץ `5chan-directories/5chan-<code>-directory.json` במאגר [bitsocialnet/lists](https://github.com/bitsocialnet/lists), ולוח מצטרף לספרייה באמצעות pull request לקובץ הזה. בנוסף, 5chan מקיים תחרות הצבעה לכל ספרייה באמצעות [`@bitsocial/pubsub-voting`](https://github.com/bitsocialnet/pubsub-voting): כל מחזיק 5chan Pass מקבל קול אחד, והצבעה בעד לוח שאינו ברשימה מעמידה אותו כמועמד. התחרויות רצות כרגע ברשת הבדיקה Base Sepolia, שבה תוצאות הספירה מוצגות אך אינן משנות את סדר הרשימה.

## מבנה פנימי

מתחת למכסה המנוע, 5chan משתמש בשכבת הלקוח המשותפת של פרוטוקול Bitsocial עבור פעולות הרשת שלו.
אפליקציית האינטרנט בכתובת 5chan.app מריצה כברירת מחדל צומת Helia בדפדפן, כך שלשונית רגילה מצטרפת
לרשת כעמית: היא טוענת לוחות מעמיתים אחרים ומפרסמת דרך pubsub, בלי שער IPFS מרכזי בנתיב התוכן. ראו
[עמית לעמית בדפדפן](/browser-p2p/) כדי להבין מה זה כרוך ומה צומת בדפדפן עדיין לא יכול לעשות.
