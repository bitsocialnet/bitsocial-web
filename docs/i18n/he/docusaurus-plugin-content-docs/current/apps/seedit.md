# Seedit

Seedit היא אלטרנטיבה חסרת שרתים, ניהול ומבוזרת לחלוטין ל-Reddit בסגנון ישן, הבנויה על פרוטוקול Bitsocial. זה נותן למשתמשים בעלות מלאה על הקהילות שלהם - כל אחד יכול ליצור אחת, וקהילות מרובות יכולות להתחרות על אותו נתיב קצר, כמו `/s/funny`.

## הורדות

| פלטפורמה      | קישור                                         |
| ------------- | --------------------------------------------- |
| אינטרנט       | [seedit.app](https://seedit.app)              |
| אינטרנט (ENS) | `seedit.eth` דרך דפדפן אמיץ או IPFS Companion |
| שולחן עבודה   | זמין עבור Mac, Windows ולינוקס                |
| נייד          | זמין עבור אנדרואיד                            |

## כיצד פועלות קהילות

Seedit מארגן תוכן בקהילות בדומה ל-subreddits. כל קהילה נמצאת בבעלות היוצר שלה ופועלת ללא ניהול ריכוזי. קהילות מרובות יכולות להתחרות על אותו נתיב [ספרייה](/directories/), כמו `/s/funny`, שפותח את הקהילה הזוכה הנוכחית. מנויים וקישורים לפוסטים מצביעים תמיד על הקהילה המדויקת.

### יצירת קהילה

ישנן שתי דרכים ליצור קהילה חדשה:

1. **לקוח שולחני** - השתמש ב-GUI המובנה ביישום שולחן העבודה כדי להגדיר ולהגדיר את הקהילה שלך.
2. **bitsocial-cli** - הפעל את כלי ה-CLI כדי ליצור ולנהל קהילות משורת הפקודה.

### רשימת ברירת מחדל לקהילה

חשבונות חדשים נרשמים כמנויים לרשימת ברירת מחדל של קהילות מסוימות לפי הכתובות המדויקות שלהן, המוגדרת ב-`seedit-default-subscriptions.json` במאגר [bitsocialnet/lists](https://github.com/bitsocialnet/lists). המועמדות לספריות מופיעות בקובצי `seedit-directories/seedit-<code>-directory.json` באותו מאגר. כדי להוסיף את הקהילה שלך לאחת הרשימות, שלח בקשת משיכה עם פרטי הקהילה שלך.
