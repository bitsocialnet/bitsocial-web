# Створіть власний клієнт Bitsocial

Bitsocial перемагає не завдяки одному офіційному застосунку на кожен випадок використання. Він
перемагає тоді, коли багато клієнтів спираються на той самий протокол, конкуруючи інтерфейсом,
культурою, механізмом відкриття контенту, налаштуваннями за замовчуванням і бізнес-моделлю.

5chan і Seedit — це ранні підтвердження концепції, а не стеля. Розробник має мати змогу випустити
новий іміджборд, форум, клієнт із профілями, соціальний застосунок із пріоритетом мобільних
пристроїв, інструмент для нішевої спільноти або централізований клієнт, який використовує Bitsocial
під капотом, не питаючи дозволу у власника платформи.

## Що розробники можуть змінювати

Клієнт Bitsocial може конкурувати продуктовими рішеннями, не відгалужуючи всю мережу:

- інтерфейс і візуальна мова
- процес онбордингу
- налаштування спільноти за замовчуванням
- поверхні модерації
- модель відкриття контенту
- робота з медіа
- обмеження мобільних, десктопних або низькошвидкісних середовищ
- монетизація та бізнес-модель

Спільним рівнем є протокол. Продуктовий рівень відкритий для конкуренції.

## Найшвидший спосіб розібратися

Почніть із застосунків, які вже існують:

- Спробуйте [5chan](https://5chan.app) для анонімних спільнот-іміджбордів.
- Спробуйте [Seedit](https://seedit.app) для обговорень у стилі Reddit.
- Прочитайте документацію [React-хуків Bitsocial](https://hooks.bitsocial.net/docs/quickstart/) щодо інтеграції на боці клієнта.
- Прочитайте документацію [Bitsocial CLI](/developer-tools/cli/) щодо операцій з вузлами та спільнотами.

Якщо хочете рухатися швидко, спершу зробіть внесок у наявний застосунок. Якщо потрібний вам
інтерфейс, культура чи модель спільноти туди не вписуються, створюйте окремий клієнт.

## Оберіть вузьку першу версію

Найкраща перша версія — це не універсальний соціальний застосунок. Це клієнт з однією чіткою
аудиторією та однією вагомою причиною існувати.

Хороші відправні точки:

- чистіший клієнт-іміджборд для однієї конкретної культури
- клієнт форуму з пріоритетом мобільних пристроїв
- застосунок для однієї спільноти зі суворими налаштуваннями за замовчуванням
- клієнт для спільнот авторів
- клієнт лише для читання та пошуку контенту
- консоль для модерації чи операторів
- клієнт, оптимізований під мову, регіон або клас пристроїв

Невеликі клієнти корисні, бо Bitsocial дозволяє їм зростати всередині тієї самої мережі, а не
замикати своїх користувачів у приватній базі даних.

## Шляхи реалізації

Є три практичні шляхи:

1. Відгалузити наявний клієнт, якщо ваша ідея близька до 5chan або Seedit.
2. Створити новий клієнт на React із [React-хуками Bitsocial](https://hooks.bitsocial.net/).
3. Побудувати власну інтеграцію поверх API вузла та загальнодоступної RPC-інфраструктури.

Загальнодоступний RPC має зробити третій шлях значно практичнішим. Користувач може почати з
розміщеного некастодіального RPC-провайдера, а згодом перейти на самостійний хостинг або до
конкурента.

## Принцип проєктування

Створіть клієнт, який має існувати для вашої спільноти, а потім дайте сумісним клієнтам змагатися
публічно.
