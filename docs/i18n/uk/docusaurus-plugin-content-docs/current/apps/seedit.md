# Seedit

Seedit — це повністю децентралізована альтернатива старого Reddit без сервера, адміністратора, побудована на протоколі Bitsocial. Це дає користувачам повне право власності на свої спільноти — будь-хто може створити одну, і кілька спільнот можуть конкурувати за той самий короткий маршрут, наприклад `/s/funny`.

## Завантаження

| Платформа    | Посилання                                           |
| ------------ | --------------------------------------------------- |
| Веб          | [seedit.app](https://seedit.app)                    |
| Веб (ENS)    | `seedit.eth` через браузер Brave або IPFS Companion |
| Робочий стіл | Доступно для Mac, Windows і Linux                   |
| Мобільний    | Доступно для Android                                |

## Як працюють спільноти

Seedit організовує вміст у спільнотах, подібних до субредітів. Кожна спільнота належить її творцю та діє без централізованого адміністрування. Кілька спільнот можуть змагатися за той самий маршрут [каталогу](/directories/), наприклад `/s/funny`, який відкриває поточного переможця. Підписки й посилання на дописи завжди вказують на конкретну спільноту.

### Створення спільноти

Створити нову спільноту можна двома способами:

1. **Настільний клієнт** — використовуйте вбудований графічний інтерфейс програми для настільного комп’ютера, щоб налаштувати та налаштувати свою спільноту.
2. **bitsocial-cli** — запустіть інструмент CLI для створення та керування спільнотами з командного рядка.

### Список спільноти за умовчанням

Нові облікові записи підписуються на список конкретних спільнот за замовчуванням, визначений у `seedit-default-subscriptions.json` у репозиторії [bitsocialnet/lists](https://github.com/bitsocialnet/lists). Кандидатів у каталоги перелічено у файлах `seedit-directories/seedit-<code>-directory.json` у тому самому репозиторії. Щоб додати свою спільноту до будь-якого з цих списків, надішліть пул-реквест із даними своєї спільноти.
