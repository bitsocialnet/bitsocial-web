# 5chan

5chan — це безсерверний іміджборд без адміністратора, повністю децентралізований і побудований на протоколі Bitsocial. Він зберігає звичну для іміджбордів структуру каталогу, але додає децентралізоване володіння: будь-хто може створити дошку, а кілька дощок можуть змагатися за той самий слот у каталозі через механізм голосування.

## Завантаження

| Платформа    | Посилання                         |
| ------------ | --------------------------------- |
| Веб          | [5chan.app](https://5chan.app)    |
| Робочий стіл | Доступно для Mac, Windows і Linux |
| Мобільні     | Доступно для Android              |

## Як працюють дошки

5chan упорядковує вміст у дошки за класичною схемою каталогу (наприклад, `/b/`, `/g/`). На відміну від традиційних іміджбордів, де центральний адміністратор контролює кожну дошку, 5chan дозволяє будь-якому користувачеві створити власну дошку й повністю нею володіти. Коли кілька дощок претендують на той самий слот у каталозі, вони змагаються за цю позицію; див. [Каталоги](/directories/).

### Створення дошки

Щоб створити нову дошку, потрібно запустити `bitsocial-cli` як одноранговий вузол. Так ваша дошка розміщується децентралізовано, без залежності від будь-якого центрального сервера.

### Призначення каталогу

Дошки-кандидати для кожного каталогу перелічено у файлі `5chan-directories/5chan-<code>-directory.json` у репозиторії [bitsocialnet/lists](https://github.com/bitsocialnet/lists), і дошка приєднується до каталогу через пул-реквест до цього файлу. Крім того, 5chan проводить голосування для кожного каталогу за допомогою [`@bitsocial/pubsub-voting`](https://github.com/bitsocialnet/pubsub-voting): кожен власник 5chan Pass має один голос, а голос за дошку, якої немає в списку, висуває її кандидатом. Наразі голосування проходять у тестовій мережі Base Sepolia, де результати відображаються, але не змінюють порядок списку.

## Внутрішня будова

Під капотом 5chan використовує спільний клієнтський рівень протоколу Bitsocial для взаємодії з
мережею. Вебзастосунок на 5chan.app за замовчуванням запускає вузол Helia прямо в браузері, тож
звичайна вкладка приєднується до мережі як рівноправний учасник: вона завантажує дошки від інших
вузлів і публікує через pubsub, без централізованого шлюзу IPFS у шляху контенту. Про те, що це
означає і чого браузерний вузол усе ще не вміє, читайте в розділі
[Одноранговий зв’язок у браузері](/browser-p2p/).
