# React Hooks

`@bitsocial/bitsocial-react-hooks`, React uygulamalarına Bitsocial protokolü için bir hook API'si sunar: akışlar, yorumlar, topluluklar, yazar profilleri, hesaplar ve yayımlama; hepsi merkezi bir sunucu olmadan. [5chan](/apps/5chan/) ve [Seedit](/apps/seedit/) bu kütüphane üzerine kurulmuştur.

Kütüphanenin her sürümle birlikte güncellenen kendi belge sitesi vardır: **[hooks.bitsocial.net](https://hooks.bitsocial.net/)**.

## Kurulum

```bash
npm install @bitsocial/bitsocial-react-hooks
```

Paket, React 16.8 ve sonraki sürümleri destekler.

## Nereden başlamalı

- [Hızlı başlangıç](https://hooks.bitsocial.net/docs/quickstart/): ilk topluluk akışınızı görüntüleyin.
- [Kavramlar](https://hooks.bitsocial.net/docs/concepts/): akışların, yerel hesapların, paylaşılan durumun ve yayımlamanın birbirine nasıl bağlandığı.
- [API referansı](https://hooks.bitsocial.net/docs/api/feeds-hooks/): seçenekleri ve dönüş değerleriyle birlikte her hook.
- [Deneme alanı](https://hooks.bitsocial.net/#playground): simüle edilmiş içerik üzerinde çalışan canlı örnekleri düzenleyin.
- [Yapay zekâ ile geliştirme](https://hooks.bitsocial.net/docs/ai/): kodlama ajanları için `llms.txt` ve her sayfanın Markdown sürümü.
