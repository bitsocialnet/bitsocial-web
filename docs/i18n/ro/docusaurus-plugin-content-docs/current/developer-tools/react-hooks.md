# React Hooks

`@bitsocial/bitsocial-react-hooks` oferă aplicațiilor React un API bazat pe hook-uri pentru protocolul Bitsocial: fluxuri, comentarii, comunități, profiluri de autori, conturi și publicare, fără un server central. [5chan](/apps/5chan/) și [Seedit](/apps/seedit/) se bazează pe această bibliotecă.

Biblioteca are propriul site de documentație, actualizat la fiecare versiune: **[hooks.bitsocial.net](https://hooks.bitsocial.net/)**.

## Instalare

```bash
npm install @bitsocial/bitsocial-react-hooks
```

Pachetul este compatibil cu React 16.8 și versiunile ulterioare.

## De unde să începi

- [Pornire rapidă](https://hooks.bitsocial.net/docs/quickstart/): randează primul tău flux de comunitate.
- [Concepte](https://hooks.bitsocial.net/docs/concepts/): cum se îmbină fluxurile, conturile locale, starea partajată și publicarea.
- [Referință API](https://hooks.bitsocial.net/docs/api/feeds-hooks/): fiecare hook, cu opțiunile și valorile returnate.
- [Playground](https://hooks.bitsocial.net/#playground): editează exemple live care rulează pe conținut simulat.
- [Dezvoltare cu AI](https://hooks.bitsocial.net/docs/ai/): `llms.txt` și versiuni Markdown ale fiecărei pagini pentru agenții de programare.
