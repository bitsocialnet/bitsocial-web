# स्वतःचा Bitsocial क्लायंट तयार करा

प्रत्येक वापरासाठी एकच अधिकृत ॲप असल्याने Bitsocial यशस्वी होत नाही. अनेक क्लायंट एकच प्रोटोकॉल
वापरत असतानाही इंटरफेस, संस्कृती, शोध, डीफॉल्ट सेटिंग्ज आणि व्यवसाय मॉडेलवर एकमेकांशी स्पर्धा करू
शकतात, तेव्हा ते यशस्वी होते.

5chan आणि Seedit ही सुरुवातीची उदाहरणे आहेत, मर्यादा नाहीत. कोणत्याही बिल्डरला नवीन इमेजबोर्ड,
फोरम, प्रोफाइल क्लायंट, मोबाइल-फर्स्ट सोशल ॲप, विशिष्ट समुदायासाठीचे साधन किंवा आतून Bitsocial
वापरणारा केंद्रीकृत क्लायंट — प्लॅटफॉर्म मालकाची परवानगी न घेता — प्रकाशित करता आला पाहिजे.

## बिल्डर काय बदलू शकतात

संपूर्ण नेटवर्क फोर्क न करता Bitsocial क्लायंट उत्पादनविषयक निर्णयांवर स्पर्धा करू शकतो:

- इंटरफेस आणि व्हिज्युअल भाषा
- ऑनबोर्डिंग प्रवाह
- समुदायाची डीफॉल्ट सेटिंग्ज
- मॉडरेशनसाठीचे इंटरफेस
- शोध मॉडेल
- मीडिया अनुभव
- मोबाइल, डेस्कटॉप किंवा कमी-बँडविड्थच्या मर्यादा
- कमाईचे आणि व्यवसायाचे मॉडेल

समान थर म्हणजे प्रोटोकॉल. उत्पादनाचा थर स्पर्धेसाठी खुला आहे.

## शिकण्याचा सर्वात जलद मार्ग

आधीपासून अस्तित्वात असलेल्या ॲप्सपासून सुरुवात करा:

- निनावी इमेजबोर्ड समुदायांसाठी [5chan](https://5chan.app) वापरून पहा.
- Reddit-शैलीच्या चर्चेसाठी [Seedit](https://seedit.app) वापरून पहा.
- क्लायंट-साइड एकत्रीकरणासाठी [Bitsocial React hooks](https://hooks.bitsocial.net/docs/quickstart/) दस्तऐवज वाचा.
- नोड आणि समुदाय संचालनासाठी [Bitsocial CLI](/developer-tools/cli/) दस्तऐवज वाचा.

तुम्हाला वेगाने पुढे जायचे असेल, तर आधी अस्तित्वात असलेल्या ॲपमध्ये योगदान द्या. तुम्हाला हवा असलेला
इंटरफेस, संस्कृती किंवा समुदाय मॉडेल त्यात बसत नसेल, तर वेगळा क्लायंट तयार करा.

## पहिली आवृत्ती मर्यादित ठेवा

सर्वोत्तम पहिली आवृत्ती म्हणजे सर्वसमावेशक सोशल ॲप नव्हे. तो असा क्लायंट असतो ज्याचा एकच स्पष्ट
प्रेक्षकवर्ग असतो आणि अस्तित्वात असण्याचे एकच भक्कम कारण असते.

चांगले प्रारंभबिंदू असे आहेत:

- एका विशिष्ट संस्कृतीसाठी अधिक नीटनेटका इमेजबोर्ड क्लायंट
- मोबाइल-फर्स्ट फोरम क्लायंट
- कठोर डीफॉल्ट सेटिंग्ज असलेले एकाच समुदायासाठीचे ॲप
- क्रिएटर समुदायासाठीचा क्लायंट
- फक्त-वाचनासाठीचा शोध क्लायंट
- मॉडरेशन किंवा ऑपरेटर कन्सोल
- एखादी भाषा, प्रदेश किंवा उपकरण-वर्गासाठी अनुकूल केलेला क्लायंट

लहान क्लायंटही उपयुक्त ठरतात, कारण Bitsocial त्यांच्या वापरकर्त्यांना खासगी डेटाबेसमध्ये
अडकवण्याऐवजी त्यांना त्याच नेटवर्कमध्ये वाढू देते.

## अंमलबजावणीचे मार्ग

तीन व्यावहारिक मार्ग आहेत:

1. तुमची कल्पना 5chan किंवा Seedit च्या जवळची असेल, तर अस्तित्वात असलेला क्लायंट फोर्क करा.
2. [Bitsocial React hooks](https://hooks.bitsocial.net/) वापरून नवीन React क्लायंट तयार करा.
3. नोड APIs आणि सार्वजनिक RPC पायाभूत सुविधांवर स्वतःचे एकत्रीकरण उभारा.

सार्वजनिक RPC मुळे तिसरा मार्ग बराच अधिक व्यवहार्य व्हायला हवा. वापरकर्ता होस्ट केलेल्या,
नॉन-कस्टोडियल RPC पुरवठादाराद्वारे सुरुवात करू शकतो आणि नंतर स्वतःच्या होस्टिंगकडे किंवा स्पर्धक
पुरवठादाराकडे जाऊ शकतो.

## रचनेचे तत्त्व

तुमच्या समुदायासाठी जो क्लायंट अस्तित्वात असायला हवा तो तयार करा, आणि मग सुसंगत क्लायंटना
जाहीरपणे स्पर्धा करू द्या.
