# Seedit

सीडीट हा बिटसोशियल प्रोटोकॉलवर तयार केलेला जुन्या-शैलीच्या रेडडिटचा सर्व्हरलेस, ॲडमिनलेस आणि पूर्णपणे विकेंद्रित पर्याय आहे. हे वापरकर्त्यांना त्यांच्या समुदायांवर संपूर्ण मालकी देते — कोणीही एक तयार करू शकतो आणि एकाधिक समुदाय `/s/funny` सारख्या एकाच छोट्या रूटसाठी स्पर्धा करू शकतात.

## डाउनलोड

| प्लॅटफॉर्म | लिंक                                                    |
| ---------- | ------------------------------------------------------- |
| वेब        | [seedit.app](https://seedit.app)                        |
| वेब (ENS)  | `seedit.eth` ब्रेव्ह ब्राउझर किंवा IPFS कंपेनियन द्वारे |
| डेस्कटॉप   | Mac, Windows आणि Linux साठी उपलब्ध                      |
| मोबाईल     | Android साठी उपलब्ध                                     |

## समुदाय कसे कार्य करतात

Seedit subreddits प्रमाणेच समुदायांमध्ये सामग्री आयोजित करते. प्रत्येक समुदाय त्याच्या निर्मात्याच्या मालकीचा असतो आणि केंद्रीकृत प्रशासनाशिवाय कार्य करतो. अनेक समुदाय `/s/funny` सारख्या एकाच [डिरेक्टरी](/directories/) रूटसाठी स्पर्धा करू शकतात, आणि तो रूट सध्याचा विजेता उघडतो. सदस्यत्वे आणि पोस्ट लिंक नेहमी अचूक समुदायाकडेच निर्देश करतात.

### समुदाय तयार करणे

नवीन समुदाय तयार करण्याचे दोन मार्ग आहेत:

1. **डेस्कटॉप क्लायंट** — तुमचा समुदाय सेट अप आणि कॉन्फिगर करण्यासाठी डेस्कटॉप ऍप्लिकेशनमध्ये अंगभूत GUI वापरा.
2. **bitsocial-cli** — कमांड लाइनवरून समुदाय तयार आणि व्यवस्थापित करण्यासाठी CLI टूल चालवा.

### डीफॉल्ट समुदाय सूची

नवीन खाती [bitsocialnet/lists](https://github.com/bitsocialnet/lists) रिपॉझिटरीमधील `seedit-default-subscriptions.json` मध्ये परिभाषित केलेल्या अचूक समुदायांच्या डीफॉल्ट यादीचे सदस्यत्व घेतात. डिरेक्टरी उमेदवार त्याच रिपॉझिटरीमधील `seedit-directories/seedit-<code>-directory.json` फाइल्समध्ये सूचीबद्ध आहेत. यापैकी कोणत्याही यादीत तुमचा समुदाय जोडण्यासाठी, तुमच्या समुदायाच्या तपशिलांसह एक पुल विनंती सबमिट करा.
