# 5chan

5chan हा Bitsocial प्रोटोकॉलवर चालणारा सर्व्हरलेस, ॲडमिनविरहित आणि पूर्णपणे विकेंद्रित इमेजबोर्ड आहे. तो इमेजबोर्डची परिचित डिरेक्टरी रचना कायम ठेवतो आणि त्यासोबत विकेंद्रित मालकी आणतो — कोणीही बोर्ड तयार करू शकतो, आणि एकाच डिरेक्टरी स्लॉटसाठी अनेक बोर्ड मतदान यंत्रणेद्वारे स्पर्धा करू शकतात.

## डाउनलोड

| प्लॅटफॉर्म | लिंक                               |
| ---------- | ---------------------------------- |
| वेब        | [5chan.app](https://5chan.app)     |
| डेस्कटॉप   | Mac, Windows आणि Linux साठी उपलब्ध |
| मोबाइल     | Android साठी उपलब्ध                |

## बोर्ड कसे काम करतात

5chan क्लासिक डिरेक्टरी रचनेचा वापर करून सामग्री बोर्डमध्ये मांडते (उदा. `/b/`, `/g/`). पारंपरिक इमेजबोर्डमध्ये प्रत्येक बोर्डवर एका केंद्रीय ॲडमिनचे नियंत्रण असते; याउलट 5chan मध्ये कोणताही वापरकर्ता स्वतःचा बोर्ड तयार करू शकतो आणि त्याची पूर्ण मालकी घेऊ शकतो. जेव्हा अनेक बोर्ड एकाच डिरेक्टरी स्लॉटसाठी प्रयत्न करतात, तेव्हा ते त्या स्थानासाठी स्पर्धा करतात; [डिरेक्टरी](/directories/) पहा.

### बोर्ड तयार करणे

नवीन बोर्ड तयार करण्यासाठी तुम्हाला `bitsocial-cli` पीअर-टू-पीअर नोड म्हणून चालवावे लागते. यामुळे तुमचा बोर्ड कोणत्याही केंद्रीय सर्व्हरवर अवलंबून न राहता विकेंद्रित पद्धतीने होस्ट होतो.

### डिरेक्टरी नेमणुका

प्रत्येक डिरेक्टरीचे उमेदवार बोर्ड [bitsocialnet/lists](https://github.com/bitsocialnet/lists) रिपॉझिटरीमधील `5chan-directories/5chan-<code>-directory.json` फाइलमध्ये सूचीबद्ध असतात, आणि बोर्ड त्या फाइलवर पुल रिक्वेस्ट पाठवून डिरेक्टरीत सामील होतो. 5chan प्रत्येक डिरेक्टरीसाठी [`@bitsocial/pubsub-voting`](https://github.com/bitsocialnet/pubsub-voting) वापरून मतदान स्पर्धाही चालवते: प्रत्येक 5chan Pass धारकाला एक मत मिळते, आणि यादीत नसलेल्या बोर्डला मत दिल्यास त्याचे नामांकन होते. या स्पर्धा सध्या Base Sepolia टेस्टनेटवर चालतात, जिथे मतमोजणी दाखवली जाते पण तिच्यामुळे यादीचा क्रम बदलत नाही.

## अंतर्गत रचना

आतून 5chan आपल्या नेटवर्क व्यवहारांसाठी सामायिक Bitsocial प्रोटोकॉल क्लायंट थराचा वापर करते.
5chan.app वरील वेब ॲप डीफॉल्टनुसार ब्राउझरमध्येच Helia नोड चालवते, त्यामुळे एक सामान्य टॅबही पीअर
म्हणून नेटवर्कमध्ये सामील होतो: तो इतर पीअरकडून बोर्ड लोड करतो आणि pubsub वरून प्रकाशित करतो, आणि
सामग्रीच्या मार्गात कोणताही केंद्रीकृत IPFS गेटवे नसतो. यात नेमके काय येते आणि ब्राउझर नोडला अजूनही
काय करता येत नाही यासाठी [ब्राउझर पीअर-टू-पीअर](/browser-p2p/) पहा.
