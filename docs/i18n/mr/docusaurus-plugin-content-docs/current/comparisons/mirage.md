# Bitsocial आणि Mirage

[Mirage](https://mirage.foundation/) हे समुदाय, थ्रेडमधील पोस्ट आणि मते असलेले Reddit-शैलीचे चर्चा
नेटवर्क आहे. कंपनीच्या डेटाबेसऐवजी ते स्वतःच्या ब्लॉकचेनवर चालते, जी CometBFT सहमती वापरणारी Cosmos
SDK चेन आहे. Bitsocial चे सर्वात जवळचे उत्पादन म्हणजे [Seedit](/apps/seedit/), Bitsocial नेटवर्कवरील
Reddit-शैलीचे ॲप, त्यामुळे ही तुलना मुख्यतः दोघे समुदाय कसे होस्ट करतात, त्यांची मालकी कशी ठेवतात
आणि त्यांचे मॉडरेशन कसे करतात याबद्दल आहे.

## Mirage कसे काम करते

- **नोड.** Mirage नोड म्हणजे एकच Docker कंटेनर, ज्यात व्हॅलिडेटर, PostgreSQL डेटाबेस, इंडेक्सर, HTTP
  API आणि वेब फ्रंटएंड असतात. प्रत्येक नोड व्हॅलिडेटरही असतो.
  [डिप्लॉय मार्गदर्शका](https://github.com/MirageFoundation/mirage-node/blob/dev/docs/guides/deploy.md)नुसार
  तो चालवण्यासाठी amd64 वरील Ubuntu सर्व्हर आणि ऑपरेटरच्या खात्यात 10,000,000 MIRAGE टोकन लागतात.
- **पोस्ट करणे.** ब्राउझर प्रत्येक कृतीवर वापरकर्त्याच्या secp256k1 कीने स्वाक्षरी करतो, आणि मोफत
  वापरकर्ते छोटा प्रूफ-ऑफ-वर्कही करतात. नोड ती कृती चेन व्यवहारात गुंडाळतो आणि शुल्क भरतो.
- **वाचन.** प्रत्येक नोडचा इंडेक्सर चेनचा डेटा स्वतःच्या डेटाबेसमध्ये कॉपी करतो आणि HTTP API वरून
  फीड पुरवतो. नोड साधारण एका आठवड्याचे ब्लॉक ठेवतात, त्यामुळे दीर्घकालीन पोस्ट इतिहास प्रत्येक
  नोडच्या डेटाबेसमध्ये राहतो, आणि नवीन नोड त्याच्या सिंक बिंदूपूर्वीच्या इतिहासाशिवाय सुरू होतो.
- **खाती.** खाते म्हणजे 12 शब्दांच्या सीड फ्रेजमधून काढलेली की, आणि तोच सीड कोणत्याही नोडवर चालतो.
  वापरकर्ता-नावे चेनवर नोंदवली जातात आणि संपूर्ण नेटवर्कमध्ये अद्वितीय असतात.
- **समुदाय.** प्रत्येक वैध नाव आधीपासूनच एक समुदाय असते, आणि त्याचा कोणीही मालक नसतो. जास्तीत जास्त
  दहा वापरकर्त्यांचे सशुल्क क्युरेटर संघ प्रत्येकी समुदायाचे एक मॉडरेट केलेले दृश्य सांभाळतात; वाचक
  एखाद्या संघाचे दृश्य, नोडचे डीफॉल्ट दृश्य किंवा सेन्सॉर न केलेले दृश्य निवडतात.
  [Mirage FAQ](https://mirage.talk/faq) पाहा.
- **टोकन.** MIRAGE टोकन सदस्यत्वासाठी पैसे भरते, लेखक आणि नोडना मोबदला देते, आणि व्हॅलिडेटरना
  कारभारात वजन देते. सदस्य प्रूफ-ऑफ-वर्क वगळतात आणि त्यांना जास्त मर्यादा मिळतात.

## फरक कुठे आहेत

### समुदायाचा मालक कोण

Seedit मध्ये समुदाय तयार करणाऱ्याकडे त्याची की-जोडी असते, तो त्याचा नोड चालवतो किंवा दुसऱ्याकडे
सोपवतो, आणि त्याचे मॉडरेशन करतो. Mirage मध्ये कोणत्याही समुदायाचा मालक कोणी नसतो: स्पर्धा करणारे
क्युरेटर संघ एकाच नावाची मॉडरेट केलेली दृश्ये देतात, आणि सर्वाधिक सशुल्क सदस्यांनी निवडलेल्या संघाचे
दृश्य डीफॉल्ट असते.

### स्पॅम नियंत्रण

Mirage संपूर्ण नेटवर्कला एकच नियम लावते: मोफत वापरकर्ते प्रूफ-ऑफ-वर्कने किंमत मोजतात, ज्याची
काठिण्यपातळी येणाऱ्या प्रमाणानुसार बदलते, आणि सदस्य ते वगळतात. Bitsocial मध्ये प्रत्येक समुदाय
captcha पासून परवानगी-याद्या आणि पेमेंटपर्यंत स्वतःचे चॅलेंज निवडतो.
[सानुकूल अँटी-स्पॅम चॅलेंजेस](/custom-challenges/) पाहा.

### पायाभूत सुविधा

Mirage ला ब्लॉकचेन लागतो. व्हॅलिडेटर प्रत्येक कृतीवर सहमती गाठतात, आणि प्रत्येक नोड संपूर्ण सर्व्हर
स्टॅक चालवतो आणि त्याच्याकडे मोठा टोकन स्टेक असावा लागतो. Bitsocial मध्ये चेन नाही: समुदाय नोड
डेस्कटॉप ॲपमधून किंवा `bitsocial-cli` मधून सामान्य ग्राहक हार्डवेअरवर चालतो, आणि वाचक सामग्री शेअर
करण्यास मदत करू शकतात.

### संपूर्ण नेटवर्कवरील नियंत्रण

Mirage मध्ये व्हॅलिडेटर स्टेकने भारित ऑनचेन कारभार आहे. तो काठिण्यपातळी, किमती आणि टोकन उत्सर्जन
बदलू शकतो, टोकन मिंट किंवा बर्न करू शकतो, आणि असे ॲडमिन नेमू शकतो ज्यांनी केलेली हटवणी संदर्भ
इंडेक्सर कोणत्याही पोस्टवर लागू करतो. चेनचा कोड कारभाराला
[खाती हटवण्याची](https://github.com/MirageFoundation/mirage-node/blob/142a2e4e2542b6a3c9cc6d71591c282e5e5a9503/blockchain/x/core/module/module.go#L2572-L2573)
आणि
[कोणत्याही पत्त्यावरून टोकन पाठवण्याची](https://github.com/MirageFoundation/mirage-node/blob/142a2e4e2542b6a3c9cc6d71591c282e5e5a9503/blockchain/x/core/module/module.go#L2656)
मुभाही देतो. ऑक्टोबर 2026 मध्ये चार व्हॅलिडेटर चेनचे ब्लॉक तयार करत होते, आणि प्रकल्पाच्या स्वतःच्या
रनबुक चारही व्हॅलिडेटर व्यवस्थापित करत होत्या.

Bitsocial मध्ये प्रोटोकॉल-स्तरावरील ॲडमिनिस्ट्रेटर नाही. समुदाय मालक आपापल्या समुदायांचे मॉडरेशन
करतात आणि काय दाखवायचे ते ॲप्स ठरवतात. [स्थानिक मॉडरेशन, ग्लोबल बॅन्स नाही](/local-moderation/)
पाहा.

### ब्राउझर

Mirage चा वेब क्लायंट हा नोडचा HTTP क्लायंट आहे: ब्राउझर कृतींवर स्वाक्षरी करतो, पण पीअर-टू-पीअर
नेटवर्कमध्ये सामील होत नाही. Bitsocial ॲप्स ब्राउझर टॅबमध्येच पीअर-टू-पीअर नोड चालवू शकतात.
[ब्राउझर पीअर-टू-पीअर](/browser-p2p/) पाहा.
