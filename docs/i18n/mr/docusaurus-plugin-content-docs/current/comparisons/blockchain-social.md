# Bitsocial आणि ब्लॉकचेन सोशल नेटवर्क

Lens, DeSo आणि Steem हे तिघेही सोशल क्रियाकलाप ब्लॉकचेनवर ठेवतात. खाती, फॉलो, पोस्ट किंवा
त्यांच्याभोवतीचे नियम हे व्यवहार बनतात, ज्यांचा क्रम व्हॅलिडेटर ठरवतात आणि जे ते साठवतात. Bitsocial
कोणताही ब्लॉकचेन वापरत नाही: सोशल मीडियाला प्रत्येक पोस्टसाठी जागतिक क्रमाची गरज नसते, त्यामुळे
Bitsocial सहमती, गॅस आणि स्टेकिंग वगळते. त्यामागचे तर्क
[पीअर-टू-पीअर प्रोटोकॉल](/peer-to-peer-protocol/) मध्ये पाहा.

## त्यांच्यात समान काय आहे

- **प्रत्येक लेखनासाठी कोणीतरी पैसे भरतो.** Lens गॅस आकारते, जो ॲप्स प्रायोजित करू शकतात; DeSo
  प्रत्येक कृतीवर शुल्क आकारते; Steem स्टेक केलेल्या टोकननुसार कृतींचे रेशनिंग करते.
- **चेन सर्वांसाठी एकच स्पॅम धोरण ठरवते.** शुल्क, स्टेक आणि खात्याचा खर्च प्रत्येक समुदायाने
  निवडण्याऐवजी संपूर्ण नेटवर्कवर लागू होतात.
- **ऑनचेन नोंदी कायमस्वरूपी असतात.** ॲप्स सामग्री लपवू शकतात, पण ती चेनवरून काढू शकत नाहीत.
- **ब्राउझर हे API क्लायंट असतात.** वेब ॲप्स व्यवहारांवर स्वाक्षरी करतात आणि दुसऱ्या कोणीतरी
  चालवलेल्या नोड, इंडेक्सर किंवा API मार्फत डेटा वाचतात.

## Lens

[Lens](https://lens.xyz/) हे Lens Chain वर चालते. Lens Chain हे ZKsync च्या ZK Stack ने बांधलेले
Ethereum लेयर 2 आहे, जे डेटा उपलब्धतेसाठी Avail वापरते.
[जानेवारी 2026 पासून Mask Network कडे Lens चे कारभारीपण आहे](https://lens.xyz/news/mask-network-to-steward-the-next-chapter-of-lens).

- **चेनवर:** खाती स्मार्ट कॉन्ट्रॅक्ट आहेत, वापरकर्ता-नावे नेमस्पेसमधील NFT आहेत, आणि ग्राफ, गट, फीड
  आणि त्यांचे नियमही कॉन्ट्रॅक्टच आहेत.
- **चेनबाहेर:** पोस्टचा मजकूर आणि मीडिया एका URI वरील JSON फाइलमध्ये असतो, सहसा Grove वर, जी IPFS
  च्या पुढे उभी असलेली Lens ची स्टोरेज सेवा आहे. प्रतिक्रिया आणि बुकमार्क Lens API कडे असतात, आणि
  ॲप्स त्याच API मार्फत डेटा वाचतात.
- **स्पॅम आणि प्रवेशद्वारे:** व्यवहारांसाठी GHO मध्ये गॅस लागतो, जो ॲप्स दर-मर्यादांसह प्रायोजित करू
  शकतात. फीड आणि गटांचे नियम टोकन बाळगणे किंवा पेमेंट आवश्यक करू शकतात.
- **चेनचे संचालन:** [L2BEAT](https://l2beat.com/scaling/projects/lens) Lens Chain ला Stage 0
  validium म्हणून गणते, ज्याचा केंद्रीकृत ऑपरेटर व्यवहार समाविष्ट करण्यास नकार देऊ शकतो.

## DeSo

[DeSo](https://docs.deso.org/) हा सोशल ॲप्ससाठी बांधलेला लेयर-1 ब्लॉकचेन आहे. जुलै 2024 मध्ये तो
प्रूफ-ऑफ-वर्ककडून प्रूफ-ऑफ-स्टेककडे वळला.

- **चेनवर:** प्रोफाइल, पोस्ट, लाइक, फॉलो आणि थेट संदेश हे सर्व व्यवहार आहेत, जे प्रत्येक फुल नोड
  साठवतो. प्रतिमा आणि व्हिडिओ चेनबाहेर होस्ट केले जातात; संदर्भ नोड Google Cloud Storage आणि
  Cloudflare Stream वापरतो.
- **स्पॅम:** प्रत्येक कृतीसाठी DESO मध्ये शुल्क भरावे लागते. नवीन वापरकर्त्यांना फोन पडताळणीनंतर
  सहसा एखाद्या नोडकडून सुरुवातीचे DESO मिळते.
- **मॉडरेशन:** प्रत्येक नोड ब्लॅकलिस्ट किंवा ग्रेलिस्ट करून काय दाखवायचे ते ठरवतो, पण
  [सामग्री चेनवरच राहते](https://docs.deso.org/deso-blockchain/content-moderation).
- **समुदाय:** दस्तऐवजांमध्ये कोणत्याही समुदाय किंवा फोरम प्रिमिटिव्हचे वर्णन नाही; "समुदाय" म्हणजे
  एखाद्या ॲपने निवडून मांडलेले फीड.
- **नोड चालवणे:**
  [व्हॅलिडेटर मार्गदर्शका](https://docs.deso.org/deso-validators/run-a-validator)नुसार व्हॅलिडेटरला
  किमान 32 GB RAM आणि 200 GB डिस्क लागते.

## Steem

[Steem](https://steem.com/) हा लेखक आणि क्युरेटरना टोकनमध्ये मोबदला देणारा सोशल ब्लॉकचेन आहे, आणि
[Steemit](https://steemit.com/) हे त्याचे मुख्य ब्लॉगिंग ॲप आहे. Hive 2020 मध्ये Steem मधून वेगळे
झाले; [Hive च्या व्हाइटपेपर](https://hive.io/whitepaper.pdf)नुसार हा फोर्क Steemit Inc. ची Justin
Sun यांना विक्री झाल्यानंतर झाला.

- **चेनवर:** मजकूर पोस्ट, टिप्पण्या, मते आणि त्यांचा संपादन इतिहास, ज्यांचा क्रम निवडून आलेले 21
  विटनेस दर तीन सेकंदाला एक ब्लॉक तयार करून ठरवतात. प्रतिमा चेनबाहेर होस्ट केल्या जातात.
- **स्पॅम:** कृतींमध्ये Resource Credits खर्च होतात, जे स्टेक केलेल्या STEEM सोबत वाढतात. खाते तयार
  करण्यासाठी STEEM लागते; ईमेल पत्ता आणि फोन नंबर पडताळणाऱ्या वापरकर्त्यांसाठी Steemit ते भरते.
- **समुदाय:** ते सहमतीच्या बाहेर
  [इंडेक्सरने अर्थ लावलेली कस्टम ऑपरेशन्स](https://github.com/steemit/hivemind/blob/master/docs/communities.md)
  आहेत. मॉडरेटर पोस्ट म्यूट करू शकतात, ज्यामुळे त्या ॲप्समध्ये लपतात पण चेनवर राहतात.
- **मोबदला:** चलनवाढीतून मोबदल्यांचा निधी येतो, आणि स्टेक-भारित मते त्यांची विभागणी ठरवतात, त्यामुळे
  मोठे धारक कशाकडे लक्ष जाईल ते घडवतात.
