# सर्व सोशल मीडियाचे विकेंद्रीकरण

अंतिम स्थिती म्हणजे एकच ॲप नव्हे. ती क्लायंट, नोड, सेवा आणि समुदायांची अशी बाजारपेठ आहे जी
प्लॅटफॉर्मच्या मालकीची जागा प्रोटोकॉलमधील स्पर्धेने घेऊ शकते.

पाचव्या टप्प्यात Bitsocial सुरुवातीच्या प्राधान्य श्रेणींच्या पलीकडे जाते आणि शक्य तितक्या सोशल
स्वरूपांना निधी द्यायला सुरुवात करते.

## अजून काय उभारायचे बाकी आहे

सुरुवातीचे टप्पे सर्वाधिक परिणाम देणाऱ्या श्रेणींवर लक्ष केंद्रित करतात: इमेजबोर्ड, फोरम, सार्वजनिक
RPC, Bitsocial Chain, प्रोफाइल नोड, तिसऱ्या टप्प्यातील Twitter/X चा पर्याय, आणि त्यांच्याभोवतीची
सेवा-अर्थव्यवस्था.

त्यानंतर नेटवर्कने लाँग टेलमध्ये विस्तारायला हवे:

- ब्लॉगिंग क्लायंट
- क्राउडफंडिंग ॲप्स
- क्रिएटर व्हिडिओ आणि विश्वासार्ह [YouTube पर्याय](https://github.com/bitsocialnet/wetube)
- क्रिएटर समुदाय
- शॉर्ट-फॉर्म मीडिया प्रयोग
- स्थानिक किंवा विशिष्ट भाषेसाठीची सोशल ॲप्स
- पहिल्या चार टप्प्यांसाठी फार लहान ठरणारे विशिष्ट कोनाड्यातील क्लायंट
- अस्तित्वात असलेले समुदाय चालवणे सोपे करणारी साधने

यांपैकी काही ॲप्स ओपन सोर्स असू शकतात. काही केंद्रीकृत क्लायंट असू शकतात. काही Bitsocial Forge
उभारू शकते, आणि बरीच स्वतंत्र विकसकांनी उभारायला हवीत.

## संशोधनाधीन कल्पना

यांपैकी काही कल्पनांसाठी आधीच कल्पना-टप्प्यातील रिपॉझिटरी आहेत. त्यांत अजून काहीही बांधलेले नाही.
प्रत्येक रिपॉझिटरी डिझाइन आणि खुले प्रश्न एकत्र ठेवते, जेणेकरून बिल्डर आणि निधी देणारे ते पुढे नेऊ
शकतील.

- [WeTube](https://github.com/bitsocialnet/wetube): YouTube चा एक पर्याय, ज्यात प्रत्येक चॅनेल हा
  त्याच्या निर्मात्याच्या मालकीचा समुदाय असतो.
- [विकेंद्रित GitHub](https://github.com/bitsocialnet/decentralized-github): Bitsocial वर बांधलेल्या
  GitHub च्या पर्यायासाठी संशोधन आणि आर्किटेक्चर.
- [Infinipedia](https://github.com/bitsocialnet/infinipedia): ज्याचा कोणीही मालक नाही असा ज्ञानकोश,
  जिथे संपादकीय गट स्पर्धक आवृत्त्या प्रकाशित करतात आणि वाचक निवड करतात.
- [Hopium](https://github.com/bitsocialnet/hopium): सोशल ट्रेडिंगसाठी Fomo चा पर्याय, जिथे प्रत्येक
  कॉलची तुलना ती पोस्ट करणाऱ्याच्या ऑन-चेन व्यवहारांशी केली जाते आणि प्रत्येक टोकनची एक खोली असते
  जिथे फक्त त्याचे धारक लिहू शकतात.

## अनेक बिल्डरना निधी

नवे सोशल क्लायंट प्लॅटफॉर्म-पातळीची लोकप्रियता मिळवण्याआधीच त्यांना निधीयोग्य बनवणे हे उद्दिष्ट आहे.

यात थेट गुंतवणूक, अनुदाने, सामुदायिक निधी, यशस्वी Bitsocial सेवांमधून मिळणारा महसूल किंवा विकेंद्रित
अनुदान कार्यक्रम असू शकतात, ज्यांत कोणत्या विकसकांना पाठिंबा मिळावा हे ठरवण्यात व्यापक Bitsocial
समुदाय मदत करतो.

महत्त्वाचा भाग म्हणजे बहुविधता. नेटवर्कने अनेक प्रयत्नांना निधी द्यावा; प्रत्येक श्रेणी व्यापणाऱ्या
एकाच अधिकृत ॲपची वाट पाहू नये.

## यश कसे दिसते

सोशल मीडियाचे बदलता येण्याजोग्या थरांमध्ये विभाजन करता येते, तेव्हा Bitsocial यशस्वी होते:

- प्रोटोकॉल
- समुदाय
- ओळख
- होस्टिंग
- शोध
- मॉडरेशन
- कमाई
- ॲप्स

एकदा हे थर बदलता येण्याजोगे झाले, की उत्पादन चालण्यासाठी संपूर्ण सोशल ग्राफची मालकी कोणत्याही एकाच
कंपनीकडे असण्याची गरज उरत नाही.

## मुख्य पैज

परिपक्व Bitsocial परिसंस्थेत सार्वजनिक RPCs, स्वतः होस्ट केलेले नोड, फीड अल्गोरिदमच्या बाजारपेठा,
मीडिया होस्ट, शोध सेवा, ओपन-सोर्स क्लायंट, व्यावसायिक क्लायंट आणि समुदाय-निधीवर चालणारे प्रयोग
असायला हवेत.

सोशल मीडियाला अखेर त्याचा समतोल सापडतो: पूर्णपणे विकेंद्रित, पीअर-टू-पीअर सोशल नेटवर्क ज्याची मालकी
कोणाकडेही नाही; Bitsocial.
